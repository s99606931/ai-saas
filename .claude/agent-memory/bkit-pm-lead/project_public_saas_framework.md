PRD generated for public-saas-framework on 2026-04-05. 
- Stack: k3s on WSL2, Gitea + Gitea Actions, external AI APIs (Claude/GPT-4)
- Target: SME IT companies (10-50 employees) entering Korean public sector SaaS market
- Key regulations: CSAP (standard 79 controls / simple 31 controls), N2SF (C/S/O grades), gov IT audit (MOIS)
- 7 modules: Dev Standards, CSAP Controls, N2SF, Audit Compliance, Tech Infra, AI Integration, Operations
- Beachhead: First-time public SaaS entrants among SMEs
- SOM estimate: ~135-150 billion KRW/year

**Why:** The project exists because Korean SME IT companies face 6-12 month prep and high costs to enter gov SaaS market due to CSAP/audit complexity. Framework aims to cut entry cost by 70%.

**How to apply:** All downstream PDCA phases should reference this PRD for strategic context. Plan/Design should align with the 7-module structure and CSAP/N2SF compliance requirements.
