# 증적 수집 가이드

## 증적 유형

| 유형 | 설명 | 수집 방법 |
|------|------|---------|
| IMPL | 시스템에 구현됨 | 시스템 시연 + 스크린샷 |
| TMPL | 템플릿 제공 | 기관에서 작성 + 서명 |
| GUIDE | 가이드 제공 | 기관에서 절차 수립 |

## OSCAL 호환

프레임워크는 OSCAL v1.1.3 형식의 Component Definition을 제공합니다. `scripts/oscal-validate.sh`로 검증할 수 있습니다.
