# CSAP 인증 개요

## CSAP이란?

CSAP(Cloud Security Assurance Program)은 클라우드 서비스 제공자의 보안 수준을 인증하는 제도입니다. 공공기관에 클라우드 서비스를 제공하려면 CSAP 인증이 필수입니다.

## 인증 등급

| 등급 | 통제항목 | 대상 |
|------|---------|------|
| 표준등급 | 79항목 | 일반 클라우드 서비스 |
| 중등급 | 추가 항목 | 중요 정보 처리 서비스 |
| 상등급 | 추가 항목 | 기밀 정보 처리 서비스 |

이 프레임워크는 **표준등급 79항목**을 기본 지원합니다.
