# ISMS-P 인증 개요

## ISMS-P란?

ISMS-P(정보보호 및 개인정보보호 관리체계)는 정보보호와 개인정보보호를 통합 관리하는 인증제도입니다. 2027년 7월부터 일정 규모 이상 사업자는 의무 취득해야 합니다.

## 의무화 대상 (2027-07 시행)

- 매출 300억원 이상
- 이용자 100만명 이상
- 정보통신서비스 제공자
