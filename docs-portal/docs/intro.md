# 프레임워크 소개

공공기관 SaaS 프레임워크는 공공기관의 클라우드 전환 사업에서 **CSAP 표준등급 79항목** 및 **ISMS-P 101항목** 인증을 효율적으로 취득할 수 있도록 설계된 오픈소스 플랫폼입니다.

## 왜 이 프레임워크인가?

### 문제

공공기관 SaaS 사업은 다음 인증을 요구합니다:

- **CSAP (클라우드 보안 인증)**: 클라우드 서비스 제공 시 필수 (79개 통제항목)
- **ISMS-P (정보보호 관리체계)**: 2027-07부터 의무화 (101개 인증항목)
- **감리 (행안부 기준)**: 정보화사업 감리기준 산출물 7종 필수

각각 별도로 준비하면 **중복 작업이 45%** 이상 발생합니다.

### 해결

이 프레임워크는:

1. CSAP 79항목과 ISMS-P 101항목의 **중복 45항목을 통합 관리**
2. 증적 자동 매핑으로 **심사 준비 공수 40% 절감**
3. 감리 산출물을 PDCA 워크플로우에 **내장**
4. 보안 기능을 코드 레벨에서 **내재화** (RBAC, 암호화, 감사 로그)

## 주요 기능

| 기능 | 설명 |
|------|------|
| 멀티테넌시 | 기관별 격리된 데이터 + RBAC 접근 통제 |
| 마이크로서비스 | 15개 독립 서비스 (Hono + TypeScript) |
| AI 연동 | LM Studio 로컬 LLM (N2SF 데이터 등급 준수) |
| CSAP 증적 자동화 | 79항목 증적 매핑 + OSCAL 호환 |
| ISMS-P 대응 | 101항목 체크리스트 + 증적 재활용 |
| 감리 대응 | T01~T07 산출물 7종 완비 |
| CI/CD | Gitea Actions 기반 자동화 |
| 컨테이너화 | Docker Compose 19종 + k3s 배포 |
