# 포스트모템 개선 조치 추적표

> Design Ref: MTU-N117 Design SS2.1
> Plan SC: FR-N117.4
> CSAP: D-06(침해사고 관리 -- 개선 조치 추적)
> 작성일: 2026-04-10

---

## 1. 추적표 사용 가이드

### 1.1 워크플로우

```
포스트모템 작성 완료
  --> 개선 조치 항목 식별
  --> 이 추적표에 등록
  --> Gitea 이슈 생성 (자동/수동)
  --> 주간 리뷰 시 상태 업데이트
  --> 완료 시 검증 후 종결
```

### 1.2 상태 정의

| 상태 | 설명 |
|------|------|
| 대기 | 조치 등록됨, 아직 착수하지 않음 |
| 진행 | 담당자가 작업 중 |
| 검토 | 구현 완료, 검증 대기 |
| 완료 | 검증 완료, 종결 |
| 보류 | 외부 의존성 또는 우선순위 변경으로 보류 |

### 1.3 우선순위 정의

| 우선순위 | 기한 | 기준 |
|---------|------|------|
| 긴급 | 24시간 이내 | P1 인시던트 재발 방지에 필수적 |
| 높음 | 1주일 이내 | P1/P2 인시던트 관련 개선 |
| 보통 | 1개월 이내 | 프로세스 개선, 자동화 |
| 낮음 | 분기 이내 | 장기 아키텍처 개선 |
