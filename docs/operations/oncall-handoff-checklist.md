## 1. 교대 시점

- 매주 월요일 09:00 KST
- 교대 30분 전 핸드오프 미팅 (08:30~09:00)

---

## 2. 핸드오프 체크리스트

### 2.1 퇴임 온콜 담당자 (인계)

- [ ] 현재 활성 인시던트 목록 공유
- [ ] 미해소 알림 현황 설명
- [ ] 진행 중인 유지보수 작업 인계
- [ ] 최근 변경 사항 (배포, 설정 변경) 공유
- [ ] 에러 예산 현황 보고 (위험 서비스 특별 언급)
- [ ] 알려진 이슈/불안정 요소 전달
- [ ] 온콜 기간 중 작성한 포스트모템 공유
- [ ] 특별 주의 사항 (예정된 작업, 이벤트) 전달

### 2.2 신임 온콜 담당자 (인수)

- [ ] 활성 인시던트 인수 확인
- [ ] 알림 수신 채널 확인 (이메일, 메시지)
- [ ] 에스컬레이션 연락처 최신화 확인
- [ ] 런북 위치 확인 (`docs/operations/runbooks/`)
- [ ] 모니터링 대시보드 접근 확인 (Grafana)
- [ ] kubectl 접근 및 권한 확인
- [ ] 온콜 스케줄 업데이트 확인 (ConfigMap)

### 2.3 공통

- [ ] 핸드오프 기록 감사 로그에 기록
- [ ] ConfigMap `current-oncall.yaml` 업데이트
- [ ] 팀 채널에 온콜 교대 공지

## 3. 핸드오프 미팅 의제

| 순서 | 항목 | 시간 |
|------|------|------|
| 1 | 지난 주 인시던트 요약 | 10분 |
| 2 | 미해소 이슈 인계 | 5분 |
| 3 | 에러 예산 및 SLO 현황 | 5분 |
| 4 | 예정된 작업/이벤트 | 5분 |
| 5 | 질의응답 | 5분 |

---

## 4. 비상 교대 절차

정기 교대 외 비상 교대가 필요한 경우:

1. 현 온콜 담당자가 팀 리더에게 교대 요청
2. 팀 리더가 대체 담당자 지정
3. ConfigMap 업데이트 + 팀 채널 공지
4. 감사 로그에 비상 교대 기록

---

## 5. 온콜 부담 관리

- 주당 온콜 시간 제한: 168시간 (1주) 이내
- 연속 온콜 금지: 최소 1주 이상 간격
- 인시던트 과다 발생 시 추가 인력 투입
- 월간 온콜 부하 리뷰 (SRE 회의)
