## 3. 문서 포털 메뉴 (Docusaurus)

> 대상: 개발자, 감리관, 보안 담당자, CTO/PM (역할별 사이드바)

### 3.1 개발자 사이드바

```
■ 빠른 시작
  └ 포크 가이드 (FORK-GUIDE.md)

■ 플랫폼 아키텍처
  ├ 전체 구조 개요
  ├ 마이크로서비스 목록
  └ API 게이트웨이 연동

■ 비즈니스 서비스 개발
  ├ 비즈니스 플러그인 SDK 사용법
  ├ 서비스 등록 방법
  ├ CSAP 준수 개발 가이드
  └ 바이브코딩 하네스 가이드

■ 개발 표준
  ├ 코딩 스타일 가이드
  ├ 요구사항 ID 체계
  └ 코드 리뷰 체크리스트

■ CSAP 구현 가이드
  ├ D08 접근 통제
  ├ D09 암호화
  └ D12 시스템 개발 보안

■ AI 연동
  ├ AI 보안 게이트웨이 패턴
  ├ N2SF 데이터 등급 분류
  └ MCP 통합 가이드

■ 인프라
  ├ k3s + WSL2 클러스터 설정
  ├ Gitea CI/CD 파이프라인
  ├ Flux GitOps + Harbor
  └ 네트워크 정책
```

### 3.2 감리관 사이드바

```
■ 감리 산출물 (T01~T07)
  ├ T01 사업계획서
  ├ T02 요구사항 정의서
  ├ T03 상세 설계서
  ├ T04 추적성 매트릭스
  ├ T05 시험 계획서
  ├ T06 시험 결과서
  └ T07 결함 관리대장

■ CSAP 체크리스트
  ├ 표준등급 (79항목)
  └ 간편등급 (31항목)

■ 감리 완료 체크리스트
```

### 3.3 보안 담당자 사이드바

```
■ CSAP 79항목
  ├ 마스터 체크리스트
  └ 구현 가이드 (D01~D13)

■ N2SF
  ├ 데이터 등급 분류 (C/S/O)
  ├ CSAP-N2SF 매핑
  └ N2SF 영역별 (N01~N06)

■ ISMS-P
  ├ 관리체계 (M01~M16)
  ├ 보호대책 (P01~P64)
  └ 개인정보 (I01~I21)
```

### 3.4 CTO/PM 사이드바

```
■ 프레임워크 개요
■ 감리 현황 요약
■ CSAP 준수 현황
■ ISMS-P 준수 현황
■ 로드맵
  ├ 문서 프레임워크 로드맵 (35 MTU)
  └ 플랫폼 구현 로드맵 (Phase P1~P6)
```

## 4. URL 구조 (라우팅 설계)

```
/                              → 랜딩 페이지 (포털 선택)
/admin/                        → 슈퍼 어드민 포털
  /admin/login
  /admin/dashboard
  /admin/tenants
  /admin/tenants/:id
  /admin/users
  /admin/services
  /admin/subscriptions
  /admin/billing
  /admin/crm
  /admin/ai
  /admin/audit
  /admin/csap
  /admin/n2sf
  /admin/isms-p
  /admin/compliance
  /admin/settings

/:tenantId/                    → 테넌트 포털 (테넌트별 격리)
  /:tenantId/login
  /:tenantId/dashboard
  /:tenantId/business/:serviceId   ← 동적 비즈니스 서비스
  /:tenantId/ai
  /:tenantId/users
  /:tenantId/menu
  /:tenantId/subscription
  /:tenantId/audit
  /:tenantId/settings

/docs/                         → 문서 포털 (Docusaurus)
  /docs/getting-started
  /docs/developer/...
  /docs/auditor/...
  /docs/security/...
  /docs/cto/...

/api/v1/                       → API 게이트웨이 (내부)
  /api/v1/auth/...
  /api/v1/users/...
  /api/v1/tenants/...
  /api/v1/services/...
  /api/v1/business/:serviceId/...  ← 비즈니스 서비스 플러그인
```
