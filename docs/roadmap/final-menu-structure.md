## 2. 테넌트 포털 메뉴

> 대상: 테넌트 고객사 (테넌트 어드민, 테넌트 사용자)
>
> **v1.1 변경사항**: 비즈니스 서비스 동적 증가 대응을 위해 좌측 레일 + 사이드바 스위처 패턴 적용.
> 서비스 수가 증가해도 레일 아이콘 구조가 유지되므로 UX 품질이 보장됨.

```
┌─ 테넌트 포털 (레일 + 사이드바 패턴) ───────────────────────────┐
│                                                              │
│  [레일 40px]  [사이드바 240px]  [메인 콘텐츠]                 │
│                                                              │
│  레일 (항상 표시):              사이드바 (선택된 레일 항목에 따라 동적 전환):
│  ┌──┐
│  │홈│   ─── 대시보드 선택 시 ────────────────────────────   │
│  ├──┤   ■ 전체 현황                                          │
│  │A │     └ 사용 서비스, 구독 상태, 사용량 요약              │
│  ├──┤   ■ 최근 서비스                                        │
│  │B │   ■ 구독 현황                                         │
│  ├──┤
│  │C │   ─── 비즈니스서비스A 선택 시 ──────────────────────  │
│  ├──┤   ■ 서비스A 홈                                        │
│  │⋮ │   ■ 서비스A 기능1                                      │
│  ├──┤   ■ 서비스A 기능2                                      │
│  │AI│   ■ 서비스A 기능3                                      │
│  ├──┤
│  │⚙ │   ─── AI 서비스 선택 시 ───────────────────────────  │
│  └──┘   ■ AI 채팅 (O등급 데이터만, N2SF 자동 차단)           │
│         ■ 문서 분석                                           │
│         ■ AI 사용량 현황                                      │
│
│         ─── 설정 선택 시 ──────────────────────────────    │
│         ■ 사용자 관리                                         │
│           ├ 테넌트 내 사용자 목록                             │
│           ├ 사용자 초대 / 등록                                │
│           ├ 역할 할당 (테넌트 어드민, 사용자, 조회자)          │
│           └ MFA 설정 현황                                    │
│         ■ 메뉴 구성                                           │
│           └ 드래그앤드롭 메뉴 편집기                          │
│              (비즈니스 서비스 메뉴 순서·표시 여부 설정)         │
│         ■ 구독 관리                                           │
│           ├ 현재 구독 플랜                                    │
│           ├ 서비스 추가/해지                                  │
│           ├ 사용량 현황                                       │
│           └ 인보이스 / 결제 이력                              │
│         ■ 파일 관리                                           │
│           ├ 파일 업로드 / 다운로드                            │
│           └ 공유 파일 관리                                    │
│         ■ 알림 설정                                           │
│           └ 수신 알림 채널 설정                               │
│         ■ 보안 현황                                           │
│           ├ 로그인 이력                                       │
│           ├ 이상 접근 알림                                    │
│           └ 세션 관리                                         │
│         ■ 감사 로그                                           │
│           └ 테넌트 내 활동 이력                               │
│         ■ 테넌트 설정                                         │
│           ├ 브랜딩 (로고, 테마 색상)                          │
│           ├ 도메인 설정                                       │
│           ├ 보안 정책 (비밀번호, 세션)                        │
│           └ 알림 채널                                         │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**레일 아이콘 상세 명세:**

| 레일 위치 | 아이콘 | 의미 | 항상 표시 여부 |
|-----------|--------|------|---------------|
| 상단 고정 | 홈(대시보드) | 전체 현황 | 항상 표시 |
| 동적 영역 | 서비스 A~N | 구독 중인 비즈니스 서비스 | 구독 시 표시 |
| 동적 하단 | ... (더 보기) | 10개 초과 서비스 팝오버 | 서비스 10개 초과 시 |
| 하단 고정 | AI | AI 서비스 | 항상 표시 |
| 하단 고정 | 설정(톱니) | 관리 메뉴 전체 | 항상 표시 |

## 3. 문서 포털 메뉴 (Docusaurus)

> 대상: 개발자, 감리관, 보안 담당자, CTO/PM (역할별 사이드바)

### 3.1 개발자 사이드바

```
■ 빠른 시작
  └ 포크 가이드 (FORK-GUIDE.md)

■ 플랫폼 아키텍처
  ├ 전체 구조 개요
  ├ 마이크로서비스 목록
  └ API 게이트웨이 연동

■ 비즈니스 서비스 개발
  ├ 비즈니스 플러그인 SDK 사용법
  ├ 서비스 등록 방법
  ├ CSAP 준수 개발 가이드
  └ 바이브코딩 하네스 가이드

■ 개발 표준
  ├ 코딩 스타일 가이드
  ├ 요구사항 ID 체계
  └ 코드 리뷰 체크리스트

■ CSAP 구현 가이드
  ├ D08 접근 통제
  ├ D09 암호화
  └ D12 시스템 개발 보안

■ AI 연동
  ├ AI 보안 게이트웨이 패턴
  ├ N2SF 데이터 등급 분류
  └ MCP 통합 가이드

■ 인프라
  ├ k3s + WSL2 클러스터 설정
  ├ Gitea CI/CD 파이프라인
  ├ Flux GitOps + Harbor
  └ 네트워크 정책
```

### 3.2 감리관 사이드바

```
■ 감리 산출물 (T01~T07)
  ├ T01 사업계획서
  ├ T02 요구사항 정의서
  ├ T03 상세 설계서
  ├ T04 추적성 매트릭스
  ├ T05 시험 계획서
  ├ T06 시험 결과서
  └ T07 결함 관리대장

■ CSAP 체크리스트
  ├ 표준등급 (79항목)
  └ 간편등급 (31항목)

■ 감리 완료 체크리스트
```

### 3.3 보안 담당자 사이드바

```
■ CSAP 79항목
  ├ 마스터 체크리스트
  └ 구현 가이드 (D01~D13)

■ N2SF
  ├ 데이터 등급 분류 (C/S/O)
  ├ CSAP-N2SF 매핑
  └ N2SF 영역별 (N01~N06)

■ ISMS-P
  ├ 관리체계 (M01~M16)
  ├ 보호대책 (P01~P64)
  └ 개인정보 (I01~I21)
```

### 3.4 CTO/PM 사이드바

```
■ 프레임워크 개요
■ 감리 현황 요약
■ CSAP 준수 현황
■ ISMS-P 준수 현황
■ 로드맵
  ├ 문서 프레임워크 로드맵 (35 MTU)
  └ 플랫폼 구현 로드맵 (Phase P1~P6)
```

```

  /admin/dashboard
  /admin/tenants
  /admin/tenants/:id
  /admin/users
  /admin/services
  /admin/services/categories
  /admin/services/marketplace
  /admin/services/bundles
  /admin/subscriptions
  /admin/billing
  /admin/crm
  /admin/ai
  /admin/audit
  /admin/csap
  /admin/n2sf
  /admin/isms-p
  /admin/compliance
  /admin/settings

/:tenantId/                    → 테넌트 포털 (테넌트별 격리)
  /:tenantId/login
  /:tenantId/dashboard
  /:tenantId/business/:serviceId        ← 동적 비즈니스 서비스
  /:tenantId/business/:serviceId/:page  ← 서비스 내 하위 페이지
  /:tenantId/ai
  /:tenantId/users
  /:tenantId/menu
  /:tenantId/subscription
  /:tenantId/audit
  /:tenantId/settings

/docs/                         → 문서 포털 (Docusaurus)
  /docs/getting-started
  /docs/developer/...
  /docs/auditor/...
  /docs/security/...
  /docs/cto/...

/api/v1/                       → API 게이트웨이 (내부)
  /api/v1/auth/...
  /api/v1/users/...
  /api/v1/tenants/...
  /api/v1/services/...
  /api/v1/services/categories/...
  /api/v1/business/:serviceId/...  ← 비즈니스 서비스 플러그인
```

## 6. 비즈니스 서비스 동적 증가 대응 — 전문가 설계 제안

> **배경**: 테넌트가 구독하는 비즈니스 서비스가 3개에서 시작해 50개 이상으로 증가할 수 있음.
> 단순 목록형 사이드바 메뉴는 서비스 15개 초과 시 UX가 무너짐. 이를 근본적으로 해결하는
> 레이아웃 전략이 필요함.

### 6.1 패턴 분석 (3가지 후보)

#### 패턴 A — 좌측 레일 서비스 스위처 (권장)

```
[플랫폼 로고]
[대시보드 아이콘]   ← 항상 표시
[서비스A 아이콘]    ← 구독 서비스 아이콘 목록 (최대 10개 직접 표시)
[서비스B 아이콘]
[서비스C 아이콘]
[더 보기 아이콘]   ← 10개 초과 시 "..." 클릭 → 서비스 검색 팝오버
[AI 아이콘]       ← 항상 하단 고정
[설정 아이콘]      ← 항상 하단 고정
```

- 레일 아이콘 클릭 시 오른쪽 사이드바(240px)가 해당 서비스의 하위 메뉴로 즉시 전환됨
- 서비스 콘텍스트 전환이 클릭 1회로 완료됨
- 레일 폭 40~48px 고정 — 서비스 수가 아무리 늘어도 레이아웃 변화 없음

#### 패턴 B — 상단 탭 + 검색

```
[홈] [서비스A] [서비스B] [서비스C] [▼ 더 보기] ... [검색창]
```

- 서비스 10개 이하: 상단 탭으로 직접 표시
- 서비스 10개 초과: 드롭다운 "더 보기" + Cmd+K 검색 결합
- 단점: 모바일 가로 탭이 좁아 현장 업무 환경에서 터치 오류 발생 가능

#### 패턴 C — 서비스 마켓플레이스 허브 페이지

```
대시보드 → "내 서비스" 허브 페이지에서 전체 서비스 그리드 표시
각 서비스 카드 클릭 → 해당 서비스 전용 페이지로 이동
```

- 서비스 수가 매우 많을 때 (50개 이상) 카테고리 + 검색으로 탐색
- 단점: 자주 쓰는 서비스 전환 시 클릭 수가 많아짐 (허브 경유 필수)

### 6.2 공공기관 SaaS 권장: 패턴 A (좌측 레일 스위처)

**채택 근거:**

| 기준 | 패턴 A (레일) | 패턴 B (탭) | 패턴 C (허브) |
|------|:---:|:---:|:---:|
| 서비스 50개 확장성 | ✅ 레일 구조 유지 | ❌ 탭 오버플로 | ✅ 그리드 확장 |
| 모바일 현장 업무 | ✅ 아이콘 터치 쉬움 | ❌ 탭 너무 작음 | ⚠ 카드 탐색 불편 |
| 공공기관 UI 표준 친화성 | ✅ 단순하고 직관적 | ⚠ 익숙하나 한계 있음 | ⚠ 새로운 패턴 |
| 서비스 전환 속도 | ✅ 1클릭 전환 | ✅ 1클릭 전환 | ❌ 2클릭 이상 |
| 서브메뉴 지원 | ✅ 사이드바 전환 | ❌ 구조적 한계 | ⚠ 별도 페이지 필요 |

**참조 사례**: GitHub (레포지토리 레일), Linear (팀 스위처), GitLab (좌측 아이콘 레일)

**KRDS(한국형 웹 콘텐츠 접근성 지침) 준수 사항:**
- 레일 아이콘에 반드시 `aria-label` 및 툴팁 텍스트 제공
- 키보드 포커스 순서: 레일 → 사이드바 → 메인 콘텐츠
- 색상 대비 4.5:1 이상 유지

### 6.3 서비스 규모별 UX 전환점

| 구독 서비스 수 | 레이아웃 전략 | 탐색 보조 기능 |
|--------------|-------------|--------------|
| 1 ~ 5개 | 레일 없이 좌측 사이드바에 직접 목록 표시 | 없음 (목록 자체가 탐색) |
| 6 ~ 15개 | 좌측 레일 아이콘 스위처 + 사이드바 전환 | 레일 툴팁 |
| 16 ~ 50개 | 레일 + "더 보기" 팝오버 + 서비스 검색 | Cmd+K 인라인 검색 |
| 50개 초과 | 레일 + 서비스 카테고리 그룹 + 태그 필터 + 검색 | 카테고리 필터 + 최근 사용 서비스 |

### 6.4 서비스 카테고리 표준 (공공기관)

공공기관 업무 특성에 맞춰 아래 6개 카테고리로 분류. 슈퍼 어드민이 카테고리 생성/편집 가능.

| 카테고리 | 포함 서비스 예시 | 아이콘 |
|---------|----------------|--------|
| 업무 관리 | Task, Calendar, Workflow, 결재 | 체크박스 |
| 문서 관리 | Docs, Forms, Reports, 전자문서 | 문서 |
| 고객/민원 관리 | CRM, Q&A, Feedback, 민원처리 | 사람 |
| 분석 & BI | Dashboard, Analytics, Compliance, 통계 | 차트 |
| AI 서비스 | AI 어시스턴트, 자동분류, 요약, OCR | 스파클 |
| 시스템 관리 | Settings, Users, Audit, 권한 | 톱니 |

### 6.5 "더 보기" 팝오버 설계 (서비스 10개 초과 시)

### 7.4 모바일 접근성 기준 (WCAG 2.1 AA)

- 스크린 리더: VoiceOver(iOS) / TalkBack(Android) 지원
