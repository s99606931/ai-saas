## 목적

2027년 7월 ISMS-P 의무화 시행에 대비한 공공기관 SaaS 서비스의 완성본 인증 취득 가이드를 제공합니다.
MTU-C6a·C6b에서 구축한 ISMS-P 체크리스트·자동 증적 수집 인프라를 기반으로,
실제 심사 대응 절차·이중 인증 전략·자동 보고서 생성 패턴을 완성합니다.

## 핵심 설계 내용

### 1. 2026~2027 준비 타임라인

```
2026-01  ISMS-P 의무화 예고 (과기정통부 고시 예정)
2026-04  MTU-C6a: ISMS-P 101항목 체크리스트 완성       ← 현재
2026-06  MTU-C6b: 자동 증적 수집 인프라 완성
2026-07  시범 운영 개시 (자가진단 + 내부 모의 심사)
2026-10  1차 내부 예비 점검 (갭 분석)
2027-01  본심사 신청 (한국인터넷진흥원 KISA)
2027-03  현장 심사 대응
2027-05  보완 조치 완료
2027-07  ISMS-P 인증서 발급 목표 (의무화 시행 동시)
```

### 2. ISMS-P 심사 단계별 대응 절차

```
[1단계] 서류 심사 (예비 심사)
    준비물: 정책/지침 문서, 위험 관리 계획서, 내부 감사 보고서
    자동화: audit.jsonl → ISMS-P 정책 준수 현황 보고서 자동 생성
         ↓
[2단계] 현장 심사 (인터뷰 + 실증)
    준비물: 담당자별 인터뷰 대본, 시스템 시연 환경, 증적 파일 묶음
    자동화: Gitea Actions 실행 이력 → 증적 PDF 일괄 생성
         ↓
[3단계] 보완 조치
    기한: 현장 심사 종료 후 최대 60일
    자동화: 결함 항목 → GitHub Issue 자동 생성 (MTU-A7 연동)
         ↓
[4단계] 인증서 발급
    유효기간: 3년 (연간 사후 심사 1회)
    갱신 자동화: 만료 180일 전 알림 워크플로우
```

### 3. ISMS-P ↔ CSAP 이중 인증 중복 항목 전략

| 분류 | 항목 수 | 대표 항목 |
|------|---------|---------|
| ISMS-P 전용 | 61개 | 개인정보 처리방침, 정보주체 권리 보장 |
| CSAP 전용 | 39개 | 클라우드 서비스 특화 통제 |
| 완전 중복 | 30개 | 접근 통제, 암호화, 취약점 관리, 감사 로그 |
| 부분 중복 (조정 필요) | 10개 | 위험 관리, 공급망 보안 |

**이중 인증 취득 순서**: CSAP 먼저 취득 → CSAP 증적을 ISMS-P 심사에 재활용
- CSAP D-08 접근 통제 증적 → ISMS-P 2.5 인증 및 권한 관리 자동 매핑
- CSAP D-09 암호화 증적 → ISMS-P 2.7 암호화 적용 자동 매핑
- CSAP D-06 감사 로그 증적 → ISMS-P 2.11 접근 기록 자동 매핑

```
CSAP 79항목 증적
    │
    ├── 완전 중복 30항목 → ISMS-P 자동 매핑 (추가 작업 불필요)
    ├── 부분 중복 10항목 → 보완 작업 필요 (약 20% 추가 노력)
    └── ISMS-P 전용 61항목 → 신규 증적 수집 필요
```

### 4. 자동 증적 수집 → ISMS-P 보고서 생성 파이프라인

```
Gitea Actions (CI/CD 파이프라인 실행)
    │
    ▼
audit.jsonl (append-only, CSAP D-06)
    │
    ├── [일간 스케줄러] ISMS-P 항목별 증적 집계
    │       → isms-p-evidence-{YYYY-MM-DD}.json
    │
    ├── [월간 보고서] ISMS-P 101항목 준수 현황
    │       → isms-p-monthly-report-{YYYY-MM}.md
    │
    └── [심사 대응 패키지] 현장 심사 D-30 자동 생성
            → isms-p-audit-package-{심사일}.zip
                ├── 정책 문서 목록 (PDF)
                ├── 시스템 운영 현황 (스크린샷)
                └── 증적 파일 인덱스 (Excel)
```

## 합격 기준

1. ISMS-P 심사 단계별 체크리스트 완비 (서류 심사·현장 심사·보완·인증 4단계 각각 세부 항목 포함)
2. 자동 증적 수집 → ISMS-P 보고서 자동 생성 패턴 문서화 (Gitea Actions 워크플로우 예시 포함)
3. CSAP+ISMS-P 이중 인증 중복 항목 매핑 최소 30개 (항목 번호 수준 명시)
4. 2027-07 의무화 준비 타임라인 명시 (월별 마일스톤 포함)
