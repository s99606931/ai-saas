| 관점 | 내용 |

## Context Anchor

- **WHY**: 공공기관 지식 문서 분산 관리로 중복/불일치 발생 → 자동화 필요
- **WHO**: 지식 관리 담당자, 업무 기획팀
- **RISK**: 대용량 문서 → 증분 인덱싱 방식
- **SUCCESS**: 문서 등록 → 자동 분류 → 중복 탐지 → 검색 결과 반환
- **SCOPE**: In — 분류, 중복 탐지, 검색. Out — 문서 자동 수정

## 요구사항

- **FR-R180.1**: 지식 문서 등록 (id, 제목, 내용, 카테고리, 키워드)
- **FR-R180.2**: 중복 문서 탐지 (Jaccard 유사도 기반)
- **FR-R180.3**: 키워드 기반 문서 검색
- **FR-R180.4**: 카테고리별 통계 생성
- **FR-R180.5**: N2SF guard, PII 마스킹, 감사 로그
- **NFR-R180.1**: TypeScript strict, 테스트 5개+
