# MTU-N258: AI 코파일럿 위젯 엔진

> **버전**: 1.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)
> **상태**: Plan 완료

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 관리자 포털에 AI 코파일럿 위젯을 삽입하여 컨텍스트 인식 도움말, 데이터 분석, 작업 자동화 제공 |
| 기술 | 위젯 등록/렌더링 엔진 + SSE 스트리밍 + 컨텍스트 수집 + 도구 실행 |
| 보안 | 위젯별 권한 관리, N2SF O등급만 AI 전송, XSS 방지 |
| 운영 | 위젯 활성/비활성 관리, 사용량 추적, A/B 테스트 |

---

## Context Anchor

| 항목 | 내용 |
|------|------|
| **WHY** | 관리자가 데이터 분석/보고서 작성/규정 검색 시 페이지를 떠나지 않고 AI 도움을 받을 수 있음 |
| **WHO** | 관리자 포털 사용자 (공공기관 담당자), 시스템 관리자 |
| **RISK** | 위젯 XSS, 민감 데이터 AI 전송, 과도한 API 호출 |
| **SUCCESS** | 위젯 등록/해제 동작, 컨텍스트 수집 정확도, SSE 스트리밍, 도구 실행 |
| **SCOPE** | 위젯 엔진 코어 + 내장 위젯 3종 + 컨텍스트 수집 + 도구 레지스트리 |
