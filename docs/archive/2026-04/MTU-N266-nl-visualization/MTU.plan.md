# MTU-N266: NL->Visualization (자연어 대시보드 생성)

> **버전**: 1.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 공공기관 담당자가 자연어로 질의하면 적합한 차트/대시보드 자동 생성 |
| 기술 | NL 파싱 → 의도 분석 → 데이터 매핑 → 차트 타입 선택 → 시각화 스펙 생성 |
| 보안 | 집계 데이터만 시각화 (N2SF O등급), 원본 데이터 접근 RBAC |
| 운영 | 대시보드 템플릿 관리, 사용 패턴 학습, 자동 개선 |
