# MTU-N77: AI 기반 CI/CD 파이프라인 통합 — Design

> **버전**: 1.0.0 | **작성일**: 2026-04-10

---

## 1. 아키텍처

```
빌드 실패 → Gitea Actions → 로그 수집 → PII 마스킹
  → LM Studio API (host.docker.internal:1234)
  → 원인 분석 → PR/이슈 댓글
```

### 1.1 LM Studio 연동

- 엔드포인트: `http://host.docker.internal:1234/v1/chat/completions`
- 모델: OpenAI 호환 API
- 타임아웃: 30초
- 재시도: 최대 3회
- N2SF: O등급 데이터만 전송 (C/S등급 절대 금지)

### 1.2 빌드 실패 분석 프롬프트

```
시스템: 당신은 CI/CD 빌드 실패 분석 전문가입니다.
사용자: 다음 빌드 로그를 분석하고 원인과 해결 방법을 제시하세요.
[마스킹된 빌드 로그]
```

### 1.3 PR 코드 리뷰 프롬프트

```
시스템: 당신은 보안 및 코드 품질 리뷰 전문가입니다. CSAP 기준으로 검토하세요.
사용자: 다음 코드 변경(diff)을 리뷰하세요. 보안 취약점, 코드 품질, 모범 사례를 점검하세요.
[마스킹된 코드 diff]
```
