# SVC-AI-ADV-R91 — SLA 위반 예측기 (SLA Violation Predictor)

> 작성일: 2026-04-12 | 작성자: PM Lead | 버전: 1.0.0

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | SLO 지표 추세 분석으로 SLA 위반을 48시간 전 예측 |
| 품질 | 예측 정확도 80%+, 거짓양성률 < 20% |
| 보안 | 메트릭만 사용, PII/C·S등급 데이터 미포함 |
| 비용 | 순수 통계 기반, LLM 호출 없음 — 거의 0원 |

## Context Anchor

- **WHY**: 사후 대응이 아닌 선제 대응. SLA 99.9% 유지를 위한 48시간 버퍼 확보
- **WHO**: SRE, 운영팀, 서비스 소유자
- **RISK**: 오경보로 인한 알림 피로 → 신뢰도 임계값 + 연속 위반 카운터
- **SUCCESS**: 에러버짓 소진율 기반 위반 시점 예측 + 스케일링 트리거 이벤트 발행
- **SCOPE**: 예측기 모듈 단일 (스케일러/알림은 기존 모듈 사용)

## 요구사항

- **FR-R91.1**: SLI 시계열 수신 → 추세선 계산 (선형 회귀)
- **FR-R91.2**: 에러버짓 소진율 계산 + 잔여 버짓 산출
- **FR-R91.3**: 위반 예측 시점 계산 (소진률 기반 외삽)
- **FR-R91.4**: 예측 결과 이벤트 발행 (ScaleUp/AlertOps)
- **FR-R91.5**: 감사 로그 기록
- **NFR-R91.1**: 1000개 시계열 포인트 100ms 이내 처리
- **NFR-R91.2**: TypeScript strict, 단위테스트 5개+
