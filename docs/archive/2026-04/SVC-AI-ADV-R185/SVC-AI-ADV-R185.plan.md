## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 공공 문서 자동 분류 (보안등급, 유형, 부서) 및 메타데이터 추출 |
| 품질 | 키워드 기반 분류 규칙, 신뢰도 점수, 수동 검토 대상 식별 |

## Context Anchor

- **WHY**: 공공기관 문서 분류 수작업으로 오분류 위험 → 자동화로 일관성 확보
- **WHO**: 문서 관리자, 보안 담당자
- **RISK**: 분류 규칙 불완전 → 신뢰도 낮은 항목 수동 검토 플래그
- **SUCCESS**: 분류 규칙 등록 → 문서 분류 → 신뢰도 점수 → 수동 검토 목록 반환
- **SCOPE**: In — 자동 분류, 메타데이터. Out — 문서 내용 수정
