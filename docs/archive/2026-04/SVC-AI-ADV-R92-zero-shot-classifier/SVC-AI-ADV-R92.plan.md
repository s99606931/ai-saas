# SVC-AI-ADV-R92 — Zero-Shot 공공도메인 분류기

> 작성일: 2026-04-12 | 작성자: PM Lead | 버전: 1.0.0

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 라벨 없는 공공문서를 임베딩 유사도 + LLM 검증으로 분류 |
| 품질 | Top-1 정확도 75%+ (공공 8개 카테고리 기준) |
| 보안 | O등급만 처리. PII 마스킹 필수 |
| 비용 | 임베딩 기반 1차 분류 → LLM은 경계값만 (월 1000원 이내) |

## Context Anchor

- **WHY**: 신규 업무 도입 시 학습데이터 없이도 즉시 분류 가능해야 함
- **WHO**: 민원 접수, 문서 분류, 업무 라우터
- **RISK**: 오분류 → top-k 후보 반환 + 신뢰도 낮을 시 수동 검토
- **SUCCESS**: 임의 카테고리 리스트 입력 → 정렬된 분류 결과 + 신뢰도 반환
- **SCOPE**: 분류 엔진 단일

## 요구사항

- **FR-R92.1**: 카테고리 라벨 + 설명 입력 받기
- **FR-R92.2**: 문서 임베딩 + 카테고리 임베딩 코사인 유사도
- **FR-R92.3**: Top-k 후보 반환 (점수순)
- **FR-R92.4**: 저신뢰(< 0.3 차이) 시 requiresManualReview 플래그
- **FR-R92.5**: PII 마스킹 (전화/이메일/주민번호)
- **NFR-R92.1**: 100개 카테고리 분류 200ms 이내
- **NFR-R92.2**: 테스트 5개+
