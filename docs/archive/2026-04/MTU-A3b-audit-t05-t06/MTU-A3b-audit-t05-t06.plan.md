## 목적

감리 T05(시험계획서)와 T06(시험결과서) 템플릿을 제공합니다.
T05는 CSAP 항목별 시험 방법을 사전에 정의하고, T06은 실제 시험 결과를 기록합니다.

## T05 핵심 섹션 설계

```
| CSAP-DXX-YY | 항목명 | 시험 방법 | 합격 기준 | 결과 | 비고 |
```

시험 방법 분류:
- **문서 검토**: 정책서, 계약서, 교육 이력, 감사 로그 확인
- **설정 검토**: 시스템 설정값, 네트워크 정책, 접근 통제 목록 직접 확인
- **기능 시험**: 실제 기능 동작 테스트 (정상/비정상 케이스 포함)
- **인터뷰**: 담당자 질의응답, 역할 인지도 확인
- **시연**: 보안 기능 실시간 시연 (RBAC, 암호화, 감사로그 생성)
- **기술 검토**: 코드·아키텍처 구조 검토 (SQL 주입 방지, TLS 설정)
- **재현**: 비인가 접근 시도 → 차단 확인 (시뮬레이션)
- **자동화 검증**: CI/CD 파이프라인 자동 체크 결과 검토 (CSAP-D12)

---

## 합격 기준

1. T05: CSAP 79항목 전수 시험 방법 기재 (방법 미기재 0건)
2. T05: 합격 기준이 수치로 명시 (예: "응답 시간 3초 이내")
3. T06: T05 항목과 1:1 대응 결과 기록
4. T06: 결함 목록 → 조치 계획 → 재시험 결과 흐름 완비
