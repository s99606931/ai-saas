# MTU-N263: API 자동 문서 생성 + AI 검색 — 설계 문서

> **버전**: 1.0 | **작성일**: 2026-04-12 | **Plan 참조**: MTU-N263

## Design Anchor

| 항목 | 결정 |
|------|------|
| 아키텍처 | OpenAPI 파서 → 마크다운 생성 → RAG 인덱싱 → AI 검색 |
| 패턴 | Builder (문서 생성), Registry (API 등록), Adapter (스펙 변환) |

## §1 OpenAPI 파싱: 경로/메서드/스키마/설명 추출
## §2 마크다운 렌더링: API 그룹별 문서 생성
## §3 AI 검색: 자연어 → API 엔드포인트 매칭 (시맨틱 검색)
## §4 변경 감지: 스펙 버전 비교, 추가/수정/삭제 diff
## §5 코드 예제: curl/JavaScript/Python 자동 생성
## §6 메트릭: 문서화율, 설명 비율, 예제 비율
