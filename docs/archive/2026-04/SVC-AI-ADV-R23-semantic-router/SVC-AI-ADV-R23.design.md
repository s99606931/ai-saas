# SVC-AI-ADV-R23: Semantic Router DESIGN

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead (Opus)

## 아키텍처 선택: Option B — Pragmatic Balance

임베딩 유사도 기반 의도 라우팅 + 규칙 폴백 + 메트릭 수집

---

## §1 의도 기반 라우팅 (FR-ADV23.1)

Route 정의: name, description, utterances (학습 예문), handler
매칭: 입력 쿼리 임베딩 ↔ 경로 임베딩 코사인 유사도
임계값: 0.75 이상 매칭, 미만 시 폴백

## §2 라우팅 규칙 관리 (FR-ADV23.2)

CRUD: 경로 추가/수정/삭제/비활성화
우선순위: 명시적 규칙 > 유사도 매칭 > 기본 경로

## §3 유사도 매칭 (FR-ADV23.3)

임베딩 캐시: 경로별 utterance 사전 임베딩
런타임: 입력 → 임베딩 → top-k 유사 경로 → 최고 점수 선택

## §4 폴백 체인 (FR-ADV23.4)

3단계: 유사도 매칭 → 키워드 매칭 → 기본 경로
에스컬레이션: 모든 경로 실패 시 관리자 알림

## §5 라우팅 메트릭 (FR-ADV23.5)

수집: 경로별 호출 수, 평균 신뢰도, 평균 지연, 폴백 비율
