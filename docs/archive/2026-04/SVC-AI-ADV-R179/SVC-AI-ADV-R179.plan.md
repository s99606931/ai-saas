## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 멀티클라우드 환경의 리소스 사용량 분석 및 비용 최적화 권고 |
| 품질 | 클라우드별 단가 비교, 워크로드 이전 권고, 비용 절감 시뮬레이션 |

## Context Anchor

- **WHY**: 공공기관 멀티클라우드 도입 확대로 비용 복잡도 증가 → AI 기반 자동 최적화 필요
- **WHO**: 클라우드 운영팀, 예산 담당자, IT 아키텍트
- **RISK**: 클라우드 단가 변동 → 단가 테이블 등록 방식으로 유연하게 대응
- **SUCCESS**: 리소스 등록 → 사용량 기록 → 비용 분석 → 최적화 권고 반환
- **SCOPE**: In — 비용 계산, 최적화 권고. Out — 실제 클라우드 API 호출
