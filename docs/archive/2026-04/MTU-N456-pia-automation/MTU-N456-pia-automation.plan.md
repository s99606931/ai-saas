# MTU-N456 — 개인정보영향평가(PIA) 자동화

## Executive Summary
| 관점 | 내용 |
|------|------|
| 비즈니스 | PIA 작성 시간 70% 단축 |
| 기술 | 위험 요소 자동 탐지 + 템플릿 엔진 |
| 규제 | 개인정보보호법 §33, 공공기관 PIA 의무 |
| 품질 | PIA 표준 템플릿 100% 커버 |

## Context Anchor
- **WHY**: 5만 건 이상 처리 공공 정보시스템 PIA 의무 자동화
- **WHO**: 개인정보 보호책임자, 시스템 운영자
- **RISK**: 위험 요소 누락, 보호대책 미비
- **SUCCESS**: 자동 탐지 20개 이상 위험 카테고리
- **SCOPE**: `packages/privacy-compliance/`

## 기능 요구사항
- **FR-PIA.1**: 처리 항목 기반 위험도 산정
- **FR-PIA.2**: 법적 근거 자동 매핑
- **FR-PIA.3**: 보호대책 추천 엔진
- **FR-PIA.4**: PIA 보고서 자동 생성
- **FR-PIA.5**: 재평가 주기 관리 (3년)
