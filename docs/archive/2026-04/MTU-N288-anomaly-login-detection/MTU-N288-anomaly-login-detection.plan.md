# MTU-N288: AI 기반 이상 로그인 탐지 — Plan

> **버전**: 1.0.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 행동 바이오메트릭 기반 이상 로그인 실시간 탐지 |
| 기술 | 로그인 패턴 분석 + 위험도 스코어링 + 적응형 인증 |
| 보안 | CSAP D-08 접근통제, 실시간 위협 대응, 감사 로그 |
| 운영 | 제로트러스트 아키텍처 강화, 무중단 운영 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | 계정 탈취/무단 접근 실시간 탐지 필요 |
| WHO | 보안 관리자, SOC 운영자, 시스템 관리자 |
| RISK | 오탐으로 인한 정상 사용자 차단 |
| SUCCESS | 이상 탐지율 95%+, 오탐률 5% 이하 |
| SCOPE | 로그인 패턴 분석, 위험 스코어링, 적응형 인증, 알림 |

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-N288.1 | 로그인 행동 패턴 수집 (IP/시간/디바이스/위치) | 필수 |
| FR-N288.2 | 이상 패턴 감지 (통계적 이상치 탐지) | 필수 |
| FR-N288.3 | 위험도 스코어링 (0~100) | 필수 |
| FR-N288.4 | 적응형 인증 트리거 (MFA 강제 등) | 필수 |
| FR-N288.5 | 실시간 보안 알림 | 필수 |
| FR-N288.6 | 감사 로그 전수 기록 | 필수 |

## 성공 기준 (SC)

- SC-1: 이상 탐지율 95%+
- SC-2: 오탐률 5% 이하
- SC-3: 탐지~알림 지연 < 3초
- SC-4: 감사 로그 전수 기록
