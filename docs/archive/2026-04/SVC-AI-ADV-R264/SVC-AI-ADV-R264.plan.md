## Context Anchor

- **WHY**: 저품질 데이터로 AI 모델 정확도 저하 → 자동 품질 개선 필요
- **WHO**: 데이터 엔지니어, AI 모델 담당자
- **RISK**: 자동 수정 오류 → 제안만 반환, 실제 적용은 사용자 승인
- **SUCCESS**: 품질 규칙 등록 → 데이터 검사 → 이슈 탐지 → 수정 제안 반환
- **SCOPE**: In — 탐지, 수정 제안. Out — 실제 데이터 수정
