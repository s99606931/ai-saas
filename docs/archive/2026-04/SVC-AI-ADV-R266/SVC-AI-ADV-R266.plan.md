## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 서비스 카탈로그 키워드 검색 + 의미 기반 순위 정렬 + 자동완성 |
| 품질 | TF-IDF 유사 점수, 동의어 처리, 결과 다양성 |

## Context Anchor

- **WHY**: 서비스 카탈로그 단순 키워드 검색으로 낮은 검색 정확도
- **WHO**: 서비스 이용자, 담당자
- **RISK**: 동의어 미처리 → 동의어 사전 등록 API 제공
- **SUCCESS**: 서비스 등록 → 검색 쿼리 → 순위 정렬 → 결과 반환
- **SCOPE**: In — 검색, 순위. Out — 전문 검색 엔진 연동

## 요구사항

- **FR-R266.1**: 서비스 카탈로그 항목 등록 (제목, 설명, 태그)
- **FR-R266.2**: 동의어 사전 등록
- **FR-R266.3**: 지능형 검색 (키워드 + 태그 + 동의어)
- **FR-R266.4**: 검색 결과 점수 기반 정렬
- **FR-R266.5**: N2SF guard, CSAP D-12, 감사 로그
- **NFR-R266.1**: TypeScript strict, 테스트 5개+
