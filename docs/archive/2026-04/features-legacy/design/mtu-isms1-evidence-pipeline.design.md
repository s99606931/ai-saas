## 2. CSAP ↔ ISMS-P 중복 매핑 설계

### 2.1 완전 중복 (30항목) — CSAP 증적 직접 재활용

| CSAP 분야 | CSAP 항목 수 | ISMS-P 대응 | 재활용 방법 |
|-----------|------------|------------|-----------|
| D01 정보보호 정책 | 4 | M01~M04 | 정책서 + 조직도 직접 활용 |
| D02 조직 보안 | 3 | M01~M04 | 조직 구성 + 책임 할당 |
| D03 인적 보안 | 2 | M05~M08 | 보안 교육 + 인사 관리 |
| D06 침해사고 관리 | 3 | P50~P55 | 사고 대응 절차 + 로그 |
| D08 접근 통제 | 8 | P01~P14 | RBAC + 세션 + 인증 |
| D09 암호화 | 4 | P15~P20 | AES-256 + TLS 1.3 |
| D10 네트워크 보안 | 3 | P30~P35 | 방화벽 + 네트워크 분리 |
| D12 시스템 개발 보안 | 3 | P45~P49 | 시큐어코딩 + 취약점 점검 |

### 2.2 부분 중복 (10항목) — 추가 보완 필요

| CSAP 분야 | ISMS-P 대응 | 추가 필요 증적 |
|-----------|------------|--------------|
| D04 자산 관리 | M05~M08 | 위험 분석 보고서 상세화 |
| D05 공급망 보안 | P56~P60 | 외주 업체 관리 절차 |
| D07 재해 복구 | P61~P64 | DR 테스트 결과 |
| D11 가상화 보안 | P36~P44 | 클라우드 보안 상세 |

## 3. 자동 증적 파이프라인 설계

### 3.1 일간 수집

```yaml
# 매일 자동 실행
- 소스: audit.jsonl, git log, 시스템 로그
- 분류: ISMS-P 항목별 자동 태깅
- 저장: isms-evidence/{YYYY-MM-DD}/
```

### 3.2 월간 보고서

```yaml
# 매월 1일 자동 생성
- 101항목 준수 현황 (준수/미준수/해당없음)
- 미준수 항목 상세 + 개선 계획
- CSAP 증적 재활용 현황
```

### 3.3 심사 대응 패키지

```yaml
# 심사 D-30 자동 생성
- 전체 101항목 증적 패키지 (ZIP)
- 자가진단 결과 보고서
- CSAP ↔ ISMS-P 매핑 증적
```
