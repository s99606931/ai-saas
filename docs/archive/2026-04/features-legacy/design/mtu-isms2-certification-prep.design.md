## 1. 아키텍처 선택

**선택안**: Pragmatic Balance
- 문서 기반 산출물 (코드 구현 없음)
- 기존 ISMS-P 문서 구조 확장
- 실무 적용 가능한 템플릿 + 가이드 형식

## 2. 산출물 설계

### 2.1 인증기관 신청 가이드 (FR-ISMS2.1)

```
docs/framework/03-isms-p/certification-prep/agency-selection-guide.md
├── 1. 국내 ISMS-P 인증 심사기관 목록
│   ├── KISA (한국인터넷진흥원) — 직접 심사
│   ├── 민간 인증기관 (한국정보통신기술협회 등) 목록
│   └── 기관별 장단점 비교표
├── 2. 인증기관 선정 기준
│   ├── 2.1 비용 (규모별 심사 비용 범위)
│   ├── 2.2 경험 (클라우드 SaaS 심사 실적)
│   ├── 2.3 일정 (심사 가능 시기)
│   └── 2.4 부가 서비스 (사전 컨설팅 여부)
├── 3. 심사 신청 절차
│   ├── 3.1 사전 준비 사항
│   ├── 3.2 신청 양식 작성
│   ├── 3.3 심사 계약 체결
│   └── 3.4 서류 심사 → 현장 심사 → 인증서 발급
└── 4. 예상 비용 산정표 (FR-ISMS2.4)
    ├── 소규모 (50인 미만): 2,000~3,000만원
    ├── 중규모 (50~200인): 3,000~5,000만원
    └── 대규모 (200인+): 5,000~8,000만원
```

### 2.2 심사 일정 템플릿 (FR-ISMS2.2)

```
docs/framework/03-isms-p/certification-prep/audit-schedule-template.md
├── D-180: 인증기관 선정 및 계약 체결
├── D-150: 인증 범위 확정 + 자가진단 착수
├── D-120: 101항목 증적 수집 80% 완료
├── D-90:  자가진단 완료 + 결함 보완 착수
├── D-60:  결함 보완 완료 + 예비 심사 (선택)
├── D-30:  증적 패키지 최종 제출
├── D-14:  현장 심사 일정 확정 + 사전 회의
├── D-0:   현장 심사 (3~5일)
├── D+14:  결함 보완 기한 (발견 시)
└── D+30:  인증서 발급
```
