# MTU-N154 CSAP 갱신 인증 준비 자동화 — Design

> **작성일**: 2026-04-10

## 아키텍처: 자동 스캔 + 증적 수집 + 일정 관리

### 핵심 구성요소
1. CSAP 준수 스캐너 (CronJob, 주간 실행)
2. 증적 자료 수집기 (13개 분야별 자동 매핑)
3. 갱신 일정 알림 (D-day 카운터)
4. 미비 항목 조치 계획 자동 생성

### 보안 설계
| CSAP | 구현 |
|------|------|
| D-01~D-13 | 전 분야 자동 준수 현황 스캔 |
| D-06 | 감사 로그 기반 증적 자동 추출 |
| D-08 | RBAC 설정 자동 검증 |
