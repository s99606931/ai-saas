## Context Anchor

- **WHY**: 정보공개 청구 연간 100만건+, 수동 심사 부담 경감
- **WHO**: 정보공개 담당자, 청구인, 감사관
- **RISK**: 비공개 대상 오판으로 민감 정보 유출, 공개 거부 남용
- **SUCCESS**: 자동 심사 정확도 85%+, 처리 시간 50% 단축
- **SCOPE**: 청구서 접수 -> 내용 분석 -> 비공개 사유 매칭 -> 심사 결과 생성
