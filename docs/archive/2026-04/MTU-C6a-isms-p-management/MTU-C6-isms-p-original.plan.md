## 목적

ISMS-P(정보보호 및 개인정보보호 관리체계) 101개 통제항목을 프레임워크에 추가합니다.

**시장조사 근거**:
- 2027년 7월부터 ISMS-P 의무화 대상 확대 확정
- 감사 방식 변화: "정책이 있는가?" → "운영 증적이 있는가?"
- 자동화된 증적 수집이 2026년 핵심 경쟁력

**CSAP와의 관계**: CSAP 79항목과 ISMS-P 101항목은 일부 중첩.
→ 중첩 항목은 CSAP 체크리스트를 primary로 사용하고 ISMS-P는 cross-reference

## 합격 기준

1. ISMS-P 101항목 전수 (관리체계 16 + 보호대책 64 + 개인정보 21)
2. CSAP 79항목과 중첩 항목 교차 참조 완비 (중복 작업 방지)
3. `evidence-automation-guide.md`: Gitea Actions → audit.jsonl 자동 기록 예시
4. 자가 진단으로 현황 점수(0~100) 계산 가능
5. Auditor 에이전트 검증 통과

## 자동 증적 수집 패턴 설계

```
배포 이벤트 발생
  → Gitea Actions 실행
  → audit.jsonl 자동 기록 (배포자, 시각, 대상, 결과)
  → ISMS-P-P-XX 관련 항목 자동 체크 업데이트
  → 월간 증적 리포트 자동 생성
```
