## Context Anchor

### WHY
- 이상감지(MTU-N83, N247)는 "문제 발생"만 감지하고 "원인"은 수동 분석 필요
- DORA MTTR 개선 위해 감지→진단→복구 전 과정 자동화 필요
- 감리 시 "인시던트 관리 프로세스 자동화" 증빙 필요

### SUCCESS (수용 기준)
| ID | 기준 |
|----|------|
| SC-1 | 상관관계 분석 Recording Rules (메트릭 간 상관관계 자동 계산) |
| SC-2 | RCA 추론 규칙 (증상→원인 자동 매핑, 10개+ 패턴) |

| SC-4 | RCA 자동 보고서 생성 스크립트 |
