## 1. 아키텍처

```
이상감지 알림 → 상관관계 분석 Rules → RCA 패턴 매칭 → 원인 후보 생성
                                                        ↓
                                        Grafana RCA 대시보드 + 알림 주석
```

## 2. 상세 설계

### 2.1 상관관계 Recording Rules (FR-N252.1)

메트릭 간 상관관계를 사전 계산하여 RCA 근거 제공:
- CPU↔메모리 상관관계
- 지연시간↔에러율 상관관계
- 네트워크↔지연시간 상관관계
- 디스크IO↔지연시간 상관관계
- 파드 재시작↔리소스 사용률 상관관계

### 2.2 RCA 패턴 매핑 (FR-N252.2)

10개+ 증상→원인 자동 매핑 패턴:

| # | 증상 | 자동 추론 원인 |
|---|------|--------------|
| 1 | 높은 CPU + 높은 지연 | CPU 병목 (수평 확장 필요) |
| 2 | OOM Kill + 메모리 증가 | 메모리 누수 (리소스 제한 조정) |
| 3 | 높은 에러율 + 정상 리소스 | 업스트림 의존성 장애 |
| 4 | 디스크IO 증가 + 높은 지연 | 디스크 병목 (스토리지 최적화) |
| 5 | 네트워크 에러 + 높은 지연 | 네트워크 문제 (DNS/MTU) |
| 6 | 파드 재시작 + CrashLoop | 앱 버그 (롤백 권고) |
| 7 | 노드 NotReady + 파드 Pending | 노드 장애 (노드 교체 필요) |
| 8 | PVC Pending + 파드 Pending | 스토리지 부족 (PV 확장) |
| 9 | 높은 에러율 + 최근 배포 | 최근 배포 문제 (롤백 권고) |
| 10 | DNS 지연 + 서비스 지연 | CoreDNS 병목 (캐시 조정) |

### 2.3 Grafana RCA 대시보드 (FR-N252.3)

패널 구성:
1. 활성 인시던트 + RCA 후보 (테이블)
2. 상관관계 히트맵 (메트릭 간 상관도)
3. 증상→원인 추론 타임라인
4. 리소스 이상 탐지 현황 (Stat)
5. RCA 패턴 매칭 히스토리
6. 의존성 맵 (토폴로지)

### 2.4 RCA 보고서 (FR-N252.4)

자동 보고서 내용:
- 인시던트 타임라인
- 감지된 이상 징후 목록
- 상관관계 분석 결과
- RCA 후보 (확률 순위)
- 권고 조치

### 2.5 알림 RCA 주석 (FR-N252.5)

기존 알림에 RCA 후보를 자동 주석으로 추가하여 온콜 엔지니어의 초기 진단 시간 단축.
