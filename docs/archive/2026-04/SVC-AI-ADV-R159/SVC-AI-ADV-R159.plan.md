## Context Anchor

- **WHY**: 공공 입찰 분석은 수작업 → AI 보조로 적격성 신속 판단 + 전략 수립
- **WHO**: 공공 조달 담당자, 입찰 참가 기업
- **RISK**: 자격 요건 오판 → 필수 요건은 100% 명시 확인 필요
- **SUCCESS**: 공고 등록 → 적격성 분석 → 전략 추천 → 리포트 반환
- **SCOPE**: In — 공고 분석, 적격성, 전략 추천. Out — 실제 입찰 제출
