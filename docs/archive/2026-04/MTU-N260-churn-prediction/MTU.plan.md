# MTU-N260: 고객 이탈 예측 엔진

> **버전**: 1.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)
> **상태**: Plan 완료

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | SaaS 테넌트 이탈 징후를 사전 감지하여 자동 경고/액션 트리거. 이탈률 감소, 고객 생애 가치(LTV) 향상 |
| 기술 | 사용 패턴 분석 + 통계 모델(가중치 점수) + 트리거 엔진 + 자동 액션 |
| 보안 | 테넌트 사용 데이터 N2SF O등급, 집계 데이터만 분석, PII 미포함 |
| 운영 | 이탈 위험 대시보드, 알림, 자동 리텐션 캠페인 트리거 |

---

## Context Anchor

| 항목 | 내용 |
|------|------|
| **WHY** | SaaS 이탈률 평균 5~7%. 사전 감지로 1~2% 감소 시 연간 수억원 매출 방어 |
| **WHO** | SaaS 운영팀, 고객 성공(CS) 팀, 관리자 |
| **RISK** | 오탐(false positive) 과잉 경고, 프라이버시 우려 |
| **SUCCESS** | 이탈 예측 정확도 80%+, 2주 사전 감지, 자동 알림 발송 |
| **SCOPE** | 사용 패턴 수집 + 위험 점수 계산 + 자동 알림 + 리텐션 액션 + 대시보드 메트릭 |
