# PRD: SVC-USER-R1 -- 사용자 서비스 고도화 라운드 1

> 작성일: 2026-04-09 | 버전: 1.0 | 작성자: PM Lead

---

## WHY (목적)

user-service는 사용자 CRUD, 역할 관리, 비밀번호 관리를 담당하는 핵심 서비스입니다. 현재 기본 기능은 구현되어 있으나, 운영 환경에서 필요한 검색/필터링, 비활성 계정 정리, Rate Limiting, 서비스 간 인증이 누락되어 있습니다. CSAP D-08-10(계정 비활성화 관리)과 D-08-07(비밀번호 정책 강화)의 완전 준수를 위해 고도화가 필요합니다.

## WHO (이해관계자)

- 테넌트 관리자: 사용자 검색, 비활성 계정 확인 및 정리
- 시스템 관리자: 전체 사용자 현황 파악, 보안 정책 적용
- 보안 감사관: 비활성 계정 관리 증적, 비밀번호 이력 관리

## RISK (위험 요소)

| 위험 | 영향 | 대응 |
|------|------|------|
| 비활성 계정 방치 | CSAP D-08-10 감리 지적 | 90일 비활성 자동 감지 + 관리자 알림 |
| 비밀번호 재사용 | CSAP D-08-07 비밀번호 정책 위반 | 최근 5개 비밀번호 이력 비교 |
| 서비스 간 무인증 호출 | 내부 API 위장 호출 가능 | HMAC-SHA256 서비스 토큰 |
| API 무차별 대입 | 계정 열거, DoS | Rate Limiting 적용 |

## SUCCESS (성공 기준)

- FR-USR.1~FR-USR.6 전체 구현 + 테스트 통과
- 기존 테스트 30건 유지 + 신규 테스트 40건 이상
- TypeScript 빌드 PASS
- CSAP D-08-07, D-08-10 완전 준수

## SCOPE (범위)

### 포함

- 사용자 검색/필터링 API
- 비활성 계정 감지 API
- Rate Limiting 미들웨어
- 서비스 간 HMAC 인증 (auth-service 연동)
- 비밀번호 이력 관리
- 사용자 프로필 메타데이터 확장

### 제외

- 비밀번호 재설정 토큰 Redis 마이그레이션 (별도 MTU)
- 대량 사용자 가져오기/내보내기 (Phase 2)
- SSO/SAML 연동 (별도 MTU)
