# MTU-P18: 비즈니스 플러그인 SDK — Design 문서

> **문서 ID**: DESIGN-MTU-P18 | **복잡도**: HIGH | **작성일**: 2026-04-05
> **Plan 참조**: PLAN-MTU-P18 | **의존**: MTU-P04

## 1. Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 비즈니스 서비스 등록 API, CSAP 자동 준수 훅 |
| 기술 | TypeScript SDK 패키지, API Gateway 연동 |
| 보안 | CSAP 가드 자동 적용, 감사 훅 자동 등록 |
| 운영 | 서비스 매니페스트 + 자동 메뉴 등록 |

## 2. SDK API 설계

### 핵심 모듈

| 모듈 | 설명 |
|------|------|
| `registerService()` | 서비스 매니페스트 등록 → 카탈로그 + 메뉴 자동 반영 |
| `ServiceManifest` | 서비스 메타데이터 타입 (이름, 버전, 라우트, 권한) |
| `csapGuard()` | CSAP 자동 준수 미들웨어 (D-08 RBAC, D-06 감사, D-09 암호화) |
| `auditHook()` | 감사 로그 자동 기록 훅 |
