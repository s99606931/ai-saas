## 1. 아키텍처 개요

### 1.1 LGTM+B 모니터링 스택

```
┌───────────────────────────────────────────────────────────────┐
│                    Grafana (시각화 통합)                       │
│  ┌─────────────┬──────────────┬────────────────┬───────────┐  │
│  │ 메트릭 패널 │ 로그 탐색기  │ 분산 추적 뷰어 │ 알림 관리 │  │
│  └──────┬──────┴──────┬───────┴───────┬────────┴─────┬─────┘  │
│         │             │               │              │         │
│   Prometheus     Loki           Tempo         AlertManager    │
│   (메트릭)     (로그)       (분산 추적)      (알림)           │
└────────┬──────────┬──────────────┬──────────────┬─────────────┘
         │          │              │              │
    ┌────┴────┐  ┌──┴──┐    ┌─────┴─────┐  ┌────┴────┐
    │Exporters│  │OTel  │    │  Promtail │  │Blackbox │
    │(PG,Redis│  │Coll. │    │  (로그)    │  │Exporter │
    │Node)    │  │(계측) │    │           │  │(외부URL)│
    └─────────┘  └──────┘    └───────────┘  └─────────┘
```

### 1.2 기존 인프라 코드 활용

기존 `infra/monitoring/` 디렉토리에 이미 상당한 코드가 있음.
이번 MTU는 기존 코드를 **강화 + 통합 + 사용자 가이드 작성**에 집중.

| 기존 파일 | 강화 내용 |
|-----------|----------|
| loki/values.yaml | 이미 완전 — 유지 |
| tempo/values.yaml | 이미 완전 — 유지 |
| otel-collector.yaml | 이미 완전 — 유지 |
| dashboards/*.yaml | 추가 대시보드 생성 |
| setup-observability.sh | 강화 → setup-monitoring.sh |

## 2. 신규 산출물 설계

### 2.1 kube-prometheus-stack values.yaml (FR-N36.1)

기존 setup-observability.sh에서 Helm 인라인으로 설정하던 것을 values 파일로 분리.

### 2.2 Blackbox Exporter (FR-N36.6)

외부 URL(Gitea, Harbor, API Gateway) 가용성 모니터링.

### 2.3 서비스 RED 대시보드 (FR-N36.5)

Rate, Error, Duration 메트릭을 시각화하는 Grafana 대시보드.

### 2.4 사용자 가이드 3종 (FR-N36.8~10)

- 통합 가이드: 설치 ~ 대시보드 사용법
- SQL 가이드: 슬로우쿼리, 인덱스, 커넥션 모니터링
- 트래픽 가이드: RED 메트릭, 서비스 맵, 분산 추적
