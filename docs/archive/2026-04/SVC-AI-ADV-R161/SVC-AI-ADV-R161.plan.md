## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 업무 프로세스 병목 자동 탐지 + 처리시간 통계 + 개선 제안 |
| 품질 | 통계 기반 결정적 병목 탐지 (z-score + 대기 시간) |
| 보안 | C/S 등급 차단, PII 마스킹, 감사 로그 |

## Context Anchor

- **WHY**: 공공 업무 프로세스는 특정 단계에서 지연이 집중 → 자동 탐지로 개선 우선순위 결정
- **WHO**: 업무 혁신 담당자, BPM 관리자
- **RISK**: 정상 변동을 병목으로 오인 → z-score 임계값 설정으로 통제
- **SUCCESS**: 단계 등록 → 이벤트 기록 → 병목 분석 → 개선 제안 반환
- **SCOPE**: In — 단계 등록, 이벤트 기록, 병목 탐지, 개선 제안. Out — 실제 프로세스 변경

## 요구사항

- **FR-R161.1**: 워크플로우 단계 등록
- **FR-R161.2**: 단계별 처리 이벤트 기록 (시작/종료 시간)
- **FR-R161.3**: 처리 시간 통계 (평균, p95, z-score)
- **FR-R161.4**: 병목 탐지 (z-score 기반 이상 단계)
- **FR-R161.5**: 개선 제안 생성
- **FR-R161.6**: N2SF guard, PII 마스킹, 감사 로그
- **NFR-R161.1**: TypeScript strict, 테스트 5개+
