# SVC-AI-ADV-R24: Embedding Pipeline Manager (임베딩 파이프라인 관리)

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 문서 → 청크 → 임베딩 → 벡터 저장 전 파이프라인을 표준화하여 RAG 품질 보장 |
| 기술 | 파이프라인 DAG + 청크 전략 선택 + 임베딩 모델 관리 + 증분 업데이트 |
| 보안 | CSAP D-09 벡터 암호화, N2SF 등급별 임베딩 격리 |
