# SVC-AI-ADV-R24: Embedding Pipeline DESIGN

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead (Opus)

## 아키텍처 선택: Option B — Pragmatic Balance

단계별 파이프라인 + 청크 전략 어댑터 + 증분 처리

---

## §1 파이프라인 정의 (FR-ADV24.1)

5단계: ingest → preprocess → chunk → embed → store
각 단계: 입력/출력 타입, 오류 처리, 메트릭 수집

## §2 청크 전략 (FR-ADV24.2)

- fixed: 고정 크기 (토큰 수 기준)
- semantic: 의미 단위 (문단/섹션 경계)
- recursive: 재귀 분할 (큰 → 작은 단위로)
전략 선택: 문서 유형에 따라 자동 결정

## §3 임베딩 모델 관리 (FR-ADV24.3)

모델 레지스트리: 이름, 차원, 최대 토큰, 성능 지표
활성 모델 전환: 새 모델 등록 → 벤치마크 → 전환

## §4 증분 업데이트 (FR-ADV24.4)

해시 기반: 문서 내용 SHA-256 해시 비교
변경 감지: 새 문서/수정/삭제 → 해당 임베딩만 재생성

## §5 파이프라인 모니터링 (FR-ADV24.5)

메트릭: 문서 처리량, 평균 처리 시간, 실패율, 큐 깊이
