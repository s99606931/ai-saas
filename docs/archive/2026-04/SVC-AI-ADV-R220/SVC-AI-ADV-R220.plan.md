## Context Anchor

- **WHY**: 멀티클라우드 환경에서 데이터 일관성 보장 필요
- **WHO**: 데이터 엔지니어, 클라우드 운영팀
- **RISK**: 충돌 해결 오류 → last-write-wins / merge 전략 선택 가능
- **SUCCESS**: 데이터소스 등록 → 변경 기록 → 충돌 탐지 → 동기화 계획 반환
- **SCOPE**: In — 상태 관리, 충돌 탐지, 동기화 계획. Out — 실제 클라우드 API 호출
