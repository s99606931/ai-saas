# MTU-N123: 서비스 의존성 자동 탐지 및 토폴로지 맵

> 버전: 1.0.0 | 작성일: 2026-04-10

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 서비스 간 의존성을 자동 탐지하여 장애 영향 범위 신속 파악 |
| 기술 | Prometheus 메트릭/Linkerd ServiceProfile 기반 의존성 그래프 자동 생성 |

| 운영 | Grafana 토폴로지 대시보드 + CLI 의존성 조회 스크립트 |
