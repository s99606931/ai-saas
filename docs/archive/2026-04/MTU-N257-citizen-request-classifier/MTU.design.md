## §1 민원 카테고리 분류 (FR-N257.1)

20개 공공기관 표준 카테고리:
- 건축/도시, 교통/도로, 교육/학교, 국방/보훈, 노동/고용
- 농림/축산, 문화/관광, 보건/의료, 복지/연금, 산업/경제
- 세금/재정, 소방/안전, 수도/하수, 에너지/환경, 여성/가족
- 정보통신, 주민등록, 지역개발, 청소/환경, 기타/일반

분류 방식:
1. LLM 구조화 출력으로 카테고리 + 신뢰도 반환
2. 신뢰도 0.7 미만 시 수동 분류 대기열로 이동
3. 다중 레이블 지원 (최대 3개 카테고리)

## §2 담당 부서 라우팅 (FR-N257.2)

- 카테고리→부서 매핑 테이블 (설정 가능)
- 우선순위 기반 라우팅 (업무 분장, 현재 부하)
- 에스컬레이션 경로 포함

## §3 긴급도 판별 (FR-N257.3)

4단계 긴급도:
- **critical**: 인명 피해, 재난, 긴급 안전 위협
- **high**: 법적 기한 임박, 대규모 영향
- **medium**: 일반 민원, 표준 처리 기한
- **low**: 건의사항, 칭찬, 문의

판별 방식: 키워드 사전 + LLM 맥락 분석 하이브리드

## §4 유사 민원 검색 (FR-N257.4)

- 임베딩 벡터 생성 후 코사인 유사도 검색
- 유사도 0.8+ 기존 민원의 처리 이력 참조
- 자동 답변 초안 생성 (유사 사례 기반)

## §5 피드백 루프 (FR-N257.5)

- 담당자가 분류 결과 수정 시 기록
- 정확도 = 수정 없이 통과된 비율
- 일별/주별 정확도 추이 제공

## §6 감사 로그 (FR-N257.6)

모든 분류 행위 감사:
- 분류 요청 (원문 해시, PII 마스킹 후)
- AI 분류 결과 (카테고리, 신뢰도, 긴급도)
- 수동 수정 내역
- 라우팅 결과
