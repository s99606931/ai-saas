## Context Anchor

- **WHY**: 공공기관 정책 문서 개정 시 연관 문서를 누락하면 업무 일관성 파괴 → 자동 영향 분석
- **WHO**: 정책 담당자, 문서 관리자, 법령 개정 팀
- **RISK**: 의존성 등록 누락 → 문서 키워드 기반 자동 추론 보조 기능 제공
- **SUCCESS**: 문서 등록 → 변경 알림 → 영향 문서 탐지 → 검토 목록 반환
- **SCOPE**: In — 문서 등록, 의존성 분석, 변경 영향. Out — 문서 자동 수정
