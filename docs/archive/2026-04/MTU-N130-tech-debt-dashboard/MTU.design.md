# MTU-N130: 기술 부채 추적 대시보드 -- 설계 문서

> 작성일: 2026-04-10

## Design Anchor

| 항목 | 내용 |
|------|------|
| 패턴 | 셸 스크립트 + 파일 분석 + 히스토리 비교 |
| 의존성 | 프로젝트 소스 코드, package.json |
| 산출물 | 대시보드 스크립트, E2E 테스트 |

## 컴포넌트

| 컴포넌트 | 경로 | 역할 |
|---------|------|------|
| 부채 대시보드 스크립트 | `scripts/tech-debt-dashboard.sh` | 부채 종합 분석 + 보고서 |
| E2E 테스트 | `scripts/test-tech-debt-dashboard.sh` | 검증 |

## 부채 카테고리

| 카테고리 | 측정 항목 | 가중치 |
|---------|---------|--------|
| 코드 부채 | TODO/FIXME/HACK 수, 대형 함수, 중복 코드 | 30% |
| 의존성 부채 | 오래된 패키지, 미사용 의존성 | 20% |
| 문서 부채 | 미문서화 API, 오래된 README | 20% |
| 테스트 부채 | 미테스트 모듈, 깨진 테스트 | 30% |
