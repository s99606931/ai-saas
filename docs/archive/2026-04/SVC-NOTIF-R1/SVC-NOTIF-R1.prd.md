# PRD: SVC-NOTIF-R1 -- 알림 서비스 고도화 라운드 1

> 작성일: 2026-04-09 | 버전: 1.0 | 작성자: PM Lead

---

## WHY

notification-service는 이메일, 인앱, 웹훅 알림을 처리하는 서비스입니다. 핵심 기능은 구현되어 있으나, 운영에 필요한 Rate Limiting, 읽지 않은 알림 카운트, 일괄 읽음 처리, 발송 통계, 테넌트 격리가 부족합니다. 특히 발송 이력 조회에 테넌트 격리가 없어 CSAP D-08-05 위반 가능성이 있습니다.

## WHO

- 서비스 관리자: 발송 통계, 실패 재시도
- 일반 사용자: 읽지 않은 알림 확인, 일괄 읽음
- 보안 감사관: 알림 발송 이력 테넌트별 격리 확인

## RISK

| 위험 | 영향 | 대응 |
|------|------|------|
| 알림 무제한 발송 | DoS, 비용 증가 | Rate Limiting |
| 테넌트 격리 부재(이력) | CSAP D-08-05 위반 | 이력 조회 테넌트 필터 추가 |
| 실패 웹훅 방치 | 서비스 신뢰도 저하 | 실패 알림 재시도 API |

## SUCCESS

- FR-NOTIF.1~FR-NOTIF.5 전체 구현 + 테스트 통과
- 기존 테스트 유지 + 신규 30건 이상
- CSAP D-08-05 테넌트 격리 완전 준수

## SCOPE

### 포함
- Rate Limiting (알림 발송, 템플릿 CRUD)
- 읽지 않은 알림 카운트 API
- 일괄 읽음 처리 API
- 발송 이력 테넌트 격리 강화
- 알림 통계 API

### 제외
- 실시간 WebSocket 푸시 (별도 MTU)
- SMS 게이트웨이 연동 (별도 MTU)
