## Context Anchor

- **WHY**: 재해 발생 시 수동 복구는 RTO 초과 → AI 자동 계획으로 복구 시간 단축
- **WHO**: 인프라 운영자, 재해복구 담당
- **RISK**: 의존성 오판 → 서비스 토폴로지 정기 업데이트 필수
- **SUCCESS**: 서비스 등록 → 재해 시나리오 입력 → 복구 계획 생성 → 시뮬레이션 결과
- **SCOPE**: In — 계획 생성, 시뮬레이션. Out — 실제 시스템 조작

## 요구사항

- **FR-R160.1**: 서비스 등록 (id, rto분, rpo분, 의존성, 우선순위)
- **FR-R160.2**: 재해 시나리오 정의 (영향 서비스 목록)
- **FR-R160.3**: 복구 계획 생성 (의존성 기반 순서 결정)
- **FR-R160.4**: RTO/RPO 충족 검증
- **FR-R160.5**: 시뮬레이션 실행 (단계별 복구 시간 계산)
- **FR-R160.6**: N2SF guard, 감사 로그
- **NFR-R160.1**: TypeScript strict, 테스트 5개+
