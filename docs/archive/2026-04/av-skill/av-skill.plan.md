## 1. 기능 개요

### 1.1 정의

`/av` (Auto-Vibe Plugin Advisor)는 Claude Code CLI 글로벌 스킬(`~/.claude/skills/av/SKILL.md`)로,
사용자의 자연어 요구사항을 받아 최적의 플러그인 구성요소를 자동 선택·실행하는 **지능형 라우터**다.

### 1.2 핵심 동작 흐름

```
[사용자] /av 로그인 기능 만들어줘
    │
    ▼
[컨텍스트 수집] 프로젝트 레벨 / 기술 스택 / PDCA 상태 감지
    │
    ▼
[의도 분류] 6-의도 체계 → IMPLEMENT (신뢰도 95%)
    │
    ▼
[구성요소 선택] intent-map.md 참조 → pdca+plan, bkend-auth, implementer, reviewer
    │
    ▼
[실행 계획 미리보기]
  📋 실행 계획
  1. /pdca plan user-auth  (직렬)
  2. /bkend-auth            (직렬)
  3. implementer 에이전트   (직렬)
  4. reviewer 에이전트      (직렬)
  실행하시겠습니까? [Y/n]
    │
    ▼ (사용자 확인)
[자동 실행] 순차·병렬 실행
    │
    ▼
[결과 요약 + 다음 단계 제안] → /pdca analyze 권장
```

### 1.3 지원 의도 (6-의도 체계)

| 의도 | 키워드 예시 | 주요 구성요소 |
|------|-----------|-------------|
| **IMPLEMENT** | 만들어줘, 구현, 추가, 개발 | pdca, bkend-auth, implementer, phase-N |
| **REVIEW** | 리뷰, 검사, 분석, 확인 | typescript-reviewer, security-reviewer, code-analyzer |
| **DESIGN** | 설계, 계획, 아키텍처, PRD | pdca plan/design, plan-plus, enterprise-expert |
| **DEPLOY** | 배포, 릴리즈, 인프라, CI/CD | phase-9-deployment, deploy, infra-architect |
| **SECURITY** | 보안, CSAP, 취약점, 감리 | audit, security-architect, security-reviewer |
| **LEARN** | 배워줘, 설명, 온보딩, 가이드 | starter-guide, pipeline-guide, docs-lookup |

```markdown
---
name: av

  - pattern: "/av"
  - pattern: "/auto-vibe"
```
