## 2. Context Anchor
- **WHY**: 공무원 순환근무로 지식 손실 빈번
- **WHO**: 조직 관리자, HR
- **RISK**: PII 노출 - 마스킹 필수
- **SUCCESS**: 조직도 + 업무관계 자동 시각화
- **SCOPE**: 엔티티 추출 → 관계 → 그래프
