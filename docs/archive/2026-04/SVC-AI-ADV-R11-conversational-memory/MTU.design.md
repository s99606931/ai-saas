# SVC-AI-ADV-R11: Conversational Memory — Design

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead

---

## Design Anchor

**선택: 3계층 인메모리 아키텍처**
- 단기: 슬라이딩 윈도우 (최근 20턴)
- 장기: 요약 + 임베딩 벡터 (시맨틱 검색)
- 작업: 엔티티 맵 (키-값)

---

## §1 단기 메모리 (Buffer)
- 최근 N턴 (기본 20) 원본 보존
- 토큰 한도 초과 시 오래된 턴부터 요약으로 압축

## §2 장기 메모리 (Summary + Vector)
- 세션 종료 시 자동 요약 생성 (LLM)
- 요약 텍스트를 임베딩하여 벡터 저장
- 새 질문과 유사한 과거 요약 검색 (코사인 유사도)

## §3 작업 메모리 (Entity)
- 대화 중 핵심 엔티티 자동 추출
- 엔티티 맵으로 현재 상태 추적 (이름, 건명, 날짜 등)

## §4 컨텍스트 주입
- 시스템 프롬프트에 관련 메모리 주입
- 토큰 예산 내 최대 메모리 포함
