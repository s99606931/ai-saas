## Context Anchor

### WHY
17개 마이크로서비스가 상호 의존하는 환경에서 하나의 서비스 장애가 전체로 전파됩니다 (캐스케이딩 실패). Circuit Breaker 패턴으로 장애를 격리하고, 자동 복구를 지원해야 합니다.

### WHO
- 모든 마이크로서비스 (서비스 간 HTTP 호출)
- SRE 팀 (서킷 상태 모니터링)

### RISK
- 서킷 임계값 설정 오류 시 과도한 차단 (완화: 합리적 기본값 + 설정 가능)
- 반개방 상태 프로빙 실패 시 복구 지연 (완화: 점진적 복구 전략)

### SUCCESS
- SC-1: 3-상태 서킷 브레이커 (닫힘/열림/반개방)
- SC-2: 지수 백오프 재시도 (최대 횟수 + 지터)
- SC-3: 실패율 기반 자동 열림 (임계값 설정 가능)
- SC-4: 반개방 상태에서 점진적 복구
- SC-5: 상태 모니터링 메트릭

### SCOPE
- 포함: circuit-breaker 패키지, 단위 테스트
- 제외: 분산 서킷 브레이커 (별도 MTU)
