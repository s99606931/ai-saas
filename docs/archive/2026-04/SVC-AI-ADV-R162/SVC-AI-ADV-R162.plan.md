## Context Anchor

- **WHY**: 마이크로서비스 증가로 API 의존성 파악이 어려움 → 자동 분석으로 취약점 조기 발견
- **WHO**: 아키텍트, DevOps 엔지니어, 플랫폼 운영팀
- **RISK**: 의존성 등록 누락 → 실제 트래픽 기반 자동 수집 권장
- **SUCCESS**: API 등록 → 의존성 등록 → 순환/단일장애점 탐지 → 영향도 분석
- **SCOPE**: In — 그래프 분석, 순환 탐지, 영향도. Out — 실시간 트래픽 수집
