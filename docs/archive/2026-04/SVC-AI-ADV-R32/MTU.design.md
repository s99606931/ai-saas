규칙 기반 레이아웃 분석 + LLM 구조 해석 하이브리드. 온프레미스 추론 지원.

---

## §1 레이아웃 분석 (FR-ADV32.1)

문서 영역 분류:
- title: 제목/소제목 (폰트 크기, 볼드 기반)
- body: 본문 텍스트
- table: 표 (격자선/정렬 패턴)
- image: 이미지/도형
- header: 머리글
- footer: 바닥글/각주
- list: 목록 (번호, 불릿)
- signature: 서명/직인 영역

분석 파이프라인:
1. 텍스트 블록 추출 (좌표 기반)
2. 블록 간 관계 분석 (인접성, 정렬)
3. 영역 분류 (규칙 + ML)
4. 읽기 순서 결정

## §2 테이블 추출 (FR-ADV32.2)

표 인식 알고리즘:
1. 격자선 기반 셀 탐지
2. 텍스트 정렬 기반 열/행 추론 (격자선 없는 표)
3. 병합 셀 감지 (rowspan, colspan)
4. 헤더 행/열 자동 식별
5. JSON/CSV 변환 출력

## §3 문서 구조 트리 (FR-ADV32.3)

계층 구조 자동 생성:
- 레벨 1: 문서 제목
- 레벨 2: 장 (1., 제1장, I.)
- 레벨 3: 절 (1.1, 제1절, A.)
- 레벨 4: 항 (1.1.1, 가., (1))
- 리프: 본문 텍스트, 표, 이미지

## §4 OCR 후처리 (FR-ADV32.4)

한글 오류 교정:
- 자모 분리/결합 오류 교정
- 한자→한글 변환 옵션
- 숫자/특수문자 오인식 교정
- 공공 용어 사전 기반 교정

## §5 메타데이터 추출 (FR-ADV32.5)

자동 추출 필드:
- documentTitle, author, date, documentNumber
- department, classification, version
- 패턴 매칭 + LLM 보조

## §6 배치 처리 (FR-ADV32.6)

대량 문서 처리:
- 큐 기반 비동기 처리
- 진행률 콜백
- 오류 문서 건너뛰기 + 보고
