## Context Anchor

- **WHY**: 공공기관 SaaS 서비스 증가로 적합 서비스 탐색 비용 증가 → 자동화 추천
- **WHO**: IT 조달 담당자, 업무 기획팀
- **RISK**: 카탈로그 노후화 → 서비스 등록/업데이트 API 제공
- **SUCCESS**: 서비스 등록 → 요구사항 입력 → 매칭 서비스 추천 → 비교표 반환
- **SCOPE**: In — 카탈로그 관리, 추천. Out — 실제 구독 처리
