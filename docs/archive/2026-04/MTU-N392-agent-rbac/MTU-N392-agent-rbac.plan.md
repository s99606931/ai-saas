# MTU-N392: AI 에이전트 RBAC

## Executive Summary
| 관점 | 목표 | KPI |
|------|------|-----|
| 비즈니스 | 에이전트별 세밀 권한 | 권한위반 0 |
| 기술 | 역할·스코프·리소스 정책 | 평가 <1ms |
| 보안 | 최소권한 원칙 | D-08 |
| 운영 | 정책 버저닝 | 롤백 1클릭 |

## Context Anchor
- WHY: 에이전트 오남용 방지 (데이터/도구 접근 세분화)
- WHO: 플랫폼 보안관리자
- RISK: 과도한 권한 부여, 권한 누락
- SUCCESS: 정책 평가 일관/감사 가능
- SCOPE: 역할/스코프/리소스/조건부 정책

## FR
- FR-N392.1 역할 정의
- FR-N392.2 에이전트↔역할 바인딩
- FR-N392.3 정책 평가 (allow/deny)
- FR-N392.4 조건부 ABAC (시간·IP·테넌트)
- FR-N392.5 감사 로그
