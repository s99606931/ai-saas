# MTU-N127: SRE 성숙도 자가 평가 -- 설계 문서

> 작성일: 2026-04-10

## Design Anchor

| 항목 | 내용 |
|------|------|
| 패턴 | 셸 스크립트 + 파일 존재 탐지 + 점수 계산 |
| 의존성 | 프로젝트 내 인프라/모니터링/보안 산출물 |
| 산출물 | 평가 스크립트, E2E 테스트 |

## 컴포넌트

| 컴포넌트 | 경로 | 역할 |
|---------|------|------|
| SRE 성숙도 평가 스크립트 | `scripts/sre-maturity-assess.sh` | 8개 영역 자동 평가 + 보고서 생성 |
| E2E 테스트 | `scripts/test-sre-maturity.sh` | 검증 |

## 평가 알고리즘

각 영역별 5개 평가 항목, 항목당 0~1점 (존재/구현 여부).
영역 점수 = 항목 합계 / 5 * 100%.
Level: 0~20% L1, 21~40% L2, 41~60% L3, 61~80% L4, 81~100% L5.
종합: 8개 영역 평균.
