## 1. 아키텍처 옵션 평가

### Option A: 수동 모니터링
- 장점: 즉시 시작 가능
- 단점: 담당자 부재 시 누락 위험

### Option B: 반자동 모니터링 (선택)
- 장점: 주간 RSS/알림 자동 수집 + 수동 영향 분석 조합
- 단점: 완전 자동화 대비 인력 소요
- **선택 근거**: 국정원 사이트 API 미제공 → 완전 자동화 불가, 실현 가능한 최적 방안

### Option C: 완전 자동화
- 장점: 인력 최소화
- 단점: 규정 변경은 자연어 해석 필요 → 현재 기술로 자동화 한계

**최종 선택: Option B (반자동 모니터링)**

## 3. 프로세스 설계

```
Phase 1: 탐지 (주간)
  국정원/KISA/법제처 공지 확인 → 변경 이벤트 로그

Phase 2: 영향 분석 (5일 이내)
  변경 사항 → CSAP/N2SF 매핑 테이블 대조 → 영향 범위 산정

Phase 3: 업데이트 (30일 이내)
  문서 수정 → Reviewer 검증 → Auditor 재검증 → 배포

Phase 4: 이력 관리
  버전 격리 + 변경 이력 테이블 + audit.jsonl 기록
```
