# SVC-AI-ADV-R13: Autonomous Document Generation — Design

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead

---

## Design Anchor

**선택: 템플릿 엔진 + LLM 하이브리드**
- 양식 구조는 템플릿 엔진으로 보장
- 본문 내용은 LLM이 생성
- 검증 레이어로 서식 규정 준수 확인

## §1 양식 템플릿
- Mustache-like 변수 치환: {{발신기관}}, {{수신기관}}
- 조건부 섹션: {{#첨부파일}}...{{/첨부파일}}
- 표준 양식: 협조전, 보고서, 회의록, 기안문, 공고문

## §2 AI 내용 생성
- 지시사항(instruction) + 컨텍스트(참조 자료)를 LLM에 전달
- 공공기관 문체(~합니다/~됩니다) 유지

## §3 검증
- 필수 필드 누락 확인
- 문서번호 형식 검증
- 금칙어/비표준 용어 감지
