## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 감사 이벤트 자동 수집 + 감사 항목별 체크 + 감사 보고서 생성 |
| 품질 | 감사 항목 체크리스트, 준수율 계산, 미흡 항목 우선순위화 |

## Context Anchor

- **WHY**: 공공기관 정기 감사 준비 수작업 부담 → 자동화로 효율화
- **WHO**: 감사 담당자, 정보보호 책임자
- **RISK**: 감사 항목 변경 → 항목 등록/업데이트 API 제공
- **SUCCESS**: 감사 항목 등록 → 이벤트 수집 → 체크 → 보고서 반환
- **SCOPE**: In — 자동 체크, 보고서. Out — 실제 감사 수행

## 요구사항

- **FR-R221.1**: 감사 체크리스트 항목 등록
- **FR-R221.2**: 감사 이벤트 기록
- **FR-R221.3**: 항목별 준수 여부 자동 체크
- **FR-R221.4**: 감사 보고서 생성 (준수율, 미흡 항목)
- **FR-R221.5**: N2SF guard, CSAP D-06, 감사 로그
