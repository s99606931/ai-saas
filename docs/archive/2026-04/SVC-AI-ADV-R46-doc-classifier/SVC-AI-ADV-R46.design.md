# SVC-AI-ADV-R46 — 설계

## 분류 라벨
- 보안등급: O / C / S (N2SF)
- 부서: 민원/기획/감사/재무/정보화/총무/...
- 유형: 공문/회의록/보고서/계약서/법령/매뉴얼
- 처리기한: 긴급(24h)/일반(7d)/장기(30d)

## 모듈
- document-classifier.ts: 규칙 + 키워드 점수 기반 멀티레이블 분류기
- classification-pipeline.ts: 배치 처리, 에스컬레이션 큐

## 흐름
```
문서 입력
→ 전처리 (clean, tokenize)
→ 라벨 그룹별 분류 (4개 그룹 병렬)
→ 신뢰도 계산 (softmax 유사)
→ 신뢰도 < 0.7 → 인간 검토 큐
→ 결과 반환 (라벨 + 신뢰도 + reasoning)
```
