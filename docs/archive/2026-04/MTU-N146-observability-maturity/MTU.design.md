## SS1. 축별 점수 계산 로직

### 메트릭 축 (infra 커버리지)
- PrometheusRule 수 / 목표(50) → 0~1
- Sloth SLO 커버리지 (정의된 서비스 수 / 전체 서비스 수)

### 로깅 축
- Loki 로그 수집률 (ingested / expected)
- 구조화 로그 비율 (JSON 파싱 성공률)

### 트레이싱 축
- OTel span 생성률 > 0 여부
- 서비스별 trace 커버리지

### 알림 축
- AlertRule 수 / 목표(100)
- 알림 노이즈 비율 (suppressed / total)

### 대시보드 축
- 대시보드 수 / 목표(30)
- 패널 커버리지

## SS2. 성숙도 레벨 결정

| 레벨 | 종합 점수 | 설명 |
|------|----------|------|
| L1 (초기) | 0~0.2 | 기본 인프라 모니터링만 존재 |
| L2 (반복) | 0.2~0.4 | 서비스별 모니터링 시작 |
| L3 (정의) | 0.4~0.6 | SLO 기반 모니터링 체계 |
| L4 (관리) | 0.6~0.8 | 자동화된 분석 + 대응 |
| L5 (최적화) | 0.8~1.0 | 예측적 관측 + 자가 치유 |
