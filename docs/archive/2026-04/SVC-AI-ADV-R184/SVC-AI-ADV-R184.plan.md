## Context Anchor

- **WHY**: 권한 과부여(over-privilege)로 보안 위험 증가 → 최소 권한 자동 분석
- **WHO**: 보안 담당자, IAM 운영팀
- **RISK**: 권한 축소 시 업무 차질 → 권고 방식으로 제공, 강제 적용 없음
- **SUCCESS**: 권한 기록 → 사용 분석 → 미사용 탐지 → 축소 권고 반환
- **SCOPE**: In — 권한 분석, 권고. Out — 실제 권한 변경
