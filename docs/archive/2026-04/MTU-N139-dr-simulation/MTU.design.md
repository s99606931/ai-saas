## 2. 복구 절차 단계

```
1단계: 장애 탐지 (모니터링 알림)
2단계: 영향 범위 확인 (대시보드)
3단계: 인시던트 선언 (온콜 호출)
4단계: 격리 조치 (장애 확산 방지)
5단계: 복구 실행 (백업/롤백/재시작)
6단계: 검증 (헬스체크/E2E)
7단계: 포스트모템 (사후 분석)
```
