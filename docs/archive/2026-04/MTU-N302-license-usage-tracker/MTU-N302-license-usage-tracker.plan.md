## Context Anchor

- **WHY**: SaaS 라이선스 초과 사용 시 법적 리스크, 자동 추적으로 준수 보장
- **WHO**: SaaS 운영자, 테넌트 관리자, 재무팀
- **RISK**: 라이선스 초과 미감지, 과금 분쟁
- **SUCCESS**: 사용량 추적 정확도 99%+, 초과 예측 정확도 80%+
- **SCOPE**: 라이선스 등록 -> 사용량 추적 -> 초과 감지 -> 리포트
