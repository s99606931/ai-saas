## 1. 설계 개요

### 1.1 설계 목적

CSAP 표준등급 79개 통제항목을 기계 판독 가능한 단일 마스터 체크리스트로 정의합니다. 이 파일은 프레임워크 전체의 **보안 요건 원천 레이어(Single Source of Truth)**로, 후속 7개 MTU가 이 파일의 CSAP-DXX-YY ID를 직접 참조합니다.

### 1.2 설계 원칙

1. **완전성**: 13개 분야 79개 항목 전수 수록, 누락 0개
2. **기계 판독성**: CSAP-DXX-YY 정규식 패턴으로 자동 검증 가능
3. **OSCAL 호환**: NIST OSCAL 표준의 control.id, control.title, control.props 매핑 사전 설계
4. **자가진단 지원**: 기술 PM이 5일 이내 전체 항목 자가진단 가능한 확인 방법 제공
5. **역참조 지원**: 후속 MTU에서 앵커 링크(`#csap-dxx-yy`)로 직접 참조 가능

### 1.3 아키텍처 선택: Option C (실용적 균형)

MTU-C1은 문서형 산출물(코드 아닌 Markdown)이므로 3가지 설계안 비교 후 Option C를 선택합니다.

| 비교 항목 | Option A (최소) | Option B (최대) | **Option C (실용)** |
|---------|---------------|---------------|------------------|
| 파일 수 | 1 (단일 테이블) | 13 (분야별 분리) | **1 (분야별 섹션)** |
| 검색성 | 낮음 (단일 거대 테이블) | 높음 (파일 분리) | **높음 (앵커+섹션)** |
| 유지보수 | 쉬움 | 어려움 (13개 파일) | **쉬움 (단일 파일)** |
| OSCAL 호환 | 제한적 | 최적 | **충분 (필드 매핑)** |
| 후속 MTU 참조 | 단순 | 복잡 (다중 파일) | **단순 (앵커 링크)** |

**선택 근거**: 단일 파일에 13개 분야를 섹션으로 구분하고, 각 항목에 HTML 앵커를 부여하여 검색성과 유지보수성을 모두 확보합니다.

## 2. 파일 설계

### 2.1 checklist-master.md 구조

```
# CSAP 표준등급 마스터 체크리스트
  ## 메타데이터 (문서 ID, 버전, FR 매핑)
  ## 사용 방법
  ## D01 정보보호 정책 (4개 항목)
    테이블: CSAP-D01-01 ~ CSAP-D01-04
  ## D02 조직 보안 (3개 항목)
    테이블: CSAP-D02-01 ~ CSAP-D02-03
  ... (13개 분야 반복)
  ## D13 공공기관 추가 보호조치 (10개 항목)
    테이블: CSAP-D13-01 ~ CSAP-D13-10
  ## 자가진단 결과 요약 (13개 분야별 통과율)
  ## 추적성 매트릭스 (CSAP ID -> MTU -> 산출물 매핑)
  ## 변경 이력
```

### 2.2 항목별 테이블 설계

각 분야의 테이블은 동일한 7개 필드를 포함합니다:

| 필드명 | 설명 | OSCAL 매핑 | 예시 |
|-------|------|-----------|------|
| CSAP ID | `CSAP-DXX-YY` 형식 | `control.id` | CSAP-D08-03 |
| 항목명 | 한글 통제항목명 | `control.title` | 특권 계정 관리 |
| 구분 | 필수/권고 | `control.props[requirement]` | 필수 |
| 중요도 | 상/중/하 | `control.props[priority]` | 상 |
| 통제 유형 | 기술/관리/운영 | `control.props[type]` | 기술 |
| 확인 방법 | 설정 확인/문서 확인/인터뷰 | `control.props[method]` | 설정 확인 |
| 증거 자료 | 필요 문서/로그 목록 | `control.props[evidence]` | 계정 목록 + 승인 이력 |

### 2.3 HTML 앵커 규칙

각 항목에 다음 형식의 앵커를 부여합니다:

```html
<a id="csap-d08-03"></a>
```

후속 MTU에서 참조 시:
```markdown
[CSAP-D08-03 특권 계정 관리](../02-csap/standard-grade/checklist-master.md#csap-d08-03)
```

### 2.4 OSCAL 호환 설계

MTU-A4(OSCAL 호환성 레이어)에서 이 파일을 자동 변환할 수 있도록 다음 규칙을 적용합니다:

1. CSAP-DXX-YY ID가 OSCAL `control.id`로 직접 매핑
2. 분야 코드(D01~D13)가 OSCAL `control-group.id`로 매핑
3. 7개 필드가 OSCAL `control.props[]`로 매핑
4. 테이블 형식이 파싱 가능한 일관된 Markdown 표 형식 유지
