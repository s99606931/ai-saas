## 항목별 필수 필드 설계

각 79개 항목은 다음 필드를 포함해야 합니다:

```
| CSAP-D08-03 | 특권 계정 관리 | 필수 | 중요 | 운영 | 설정 확인 | 계정 목록 + 승인 이력 |
```

| 필드 | 내용 | OSCAL 매핑 |
|------|------|-----------|
| CSAP ID | `CSAP-DXX-YY` | `control.id` |
| 항목명 | 한글 통제항목명 | `control.title` |
| 구분 | 필수/권고 | `control.props[requirement]` |
| 중요도 | 상/중/하 | `control.props[priority]` |
| 통제 유형 | 기술/관리/운영 | `control.props[type]` |
| 확인 방법 | 설정 확인/문서 확인/인터뷰 | `control.props[method]` |
| 증거 자료 | 필요 문서/로그 목록 | `control.props[evidence]` |

1. `CSAP-D01-01` ~ `CSAP-D13-10` 전체 79개 항목 수록
