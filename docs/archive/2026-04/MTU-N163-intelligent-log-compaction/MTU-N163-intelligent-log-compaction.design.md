# MTU-N163: 지능형 로그 압축 정책 — Design

> **버전**: 1.0.0 | **작성일**: 2026-04-10 | **작성자**: PM Lead

---

## 1. Design Anchor

| 항목 | 결정 |
|------|------|
| 로그 저장 | Loki + 계층화 스토리지 |
| 압축 방식 | gzip (핫) → snappy (웜) → zstd (콜드) |
| 보존 정책 | 감사: 365일, 보안: 180일, 운영: 30일, 디버그: 7일 |
| 모니터링 | Prometheus 스토리지 메트릭 + 알림 |

---

## 2. 로그 등급 체계

| 등급 | 설명 | 보존 기간 | 스토리지 계층 | CSAP |
|------|------|---------|------------|------|
| AUDIT | 감사 로그 (인증, 데이터 접근) | 365일 | Hot 30d → Warm 90d → Cold | D-06 |
| SECURITY | 보안 이벤트 (침입 탐지, 정책 위반) | 180일 | Hot 14d → Warm 60d → Cold | D-06 |
| OPERATION | 운영 로그 (배포, 스케일링) | 30일 | Hot 7d → Warm 23d | - |
| DEBUG | 디버그 로그 (상세 추적) | 7일 | Hot 7d | - |
