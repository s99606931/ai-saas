# PRD: MTU-N08 보안 강화 심화

> 작성일: 2026-04-08 | 작성자: PM Lead | 버전: 1.0

## WHY (목적)

CSAP 중/상 등급 인증 대비 전체 플랫폼 서비스의 OWASP Top 10 항목별 보안 취약점을 체계적으로 식별하고 즉시 수정한다. 현재 코드베이스에서 발견된 6개 범주의 보안 취약점(보안 헤더 미적용, 에러 정보 노출, 테넌트 격리 부재 등)을 모두 해결하여 CSAP D-08, D-10, D-12 통제항목 100% 충족을 달성한다.

## WHO (이해관계자)

- **직접 이해관계자**: 플랫폼 운영팀, 보안 감사팀
- **간접 이해관계자**: 테넌트 사용자, CSAP 인증심사관
- **승인자**: 프로젝트 총괄 PM

## RISK (위험)

| ID | 위험 | 영향도 | 대응 |
|----|------|--------|------|
| R1 | 에러 메시지 통한 내부 정보 노출 | HIGH | 안전한 에러 응답 패턴 적용 |
| R2 | 테넌트 격리 미비로 교차 접근 | HIGH | JWT 클레임 기반 강제 격리 |
| R3 | 보안 헤더 부재로 XSS/클릭재킹 | MEDIUM | @fastify/helmet 전역 적용 |
| R4 | 개별 서비스 직접 접근 시 rate limit 부재 | MEDIUM | 서비스별 rate limit 또는 NetworkPolicy |

## SUCCESS (성공 기준)

- SC-1: 전체 서비스 보안 헤더 적용률 100%
- SC-2: 에러 응답에서 내부 정보 노출 0건
- SC-3: CRM/Billing 서비스 테넌트 격리 적용 완료
- SC-4: 기존 751개 테스트 전체 PASS 유지
- SC-5: matchRate >= 90%

## SCOPE (범위)

### In-Scope
- OWASP Top 10 기반 전체 서비스 코드 스캔
- 발견된 취약점 즉시 수정
- 보안 헤더 표준화
- 에러 응답 안전화
- 테넌트 격리 강화

### Out-of-Scope
- 침투 테스트 (별도 MTU)
- WAF 설정 (인프라 레이어)
- 외부 보안 감사 도구 도입
