# SVC-AI-ADV-R21: AI Context Window Manager (컨텍스트 윈도우 관리자)

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 대규모 문서(법령, 규정집)를 LLM 컨텍스트에 효율적으로 배치. 토큰 비용 최적화 |
| 기술 | 컨텍스트 압축 + 청크 우선순위 + 동적 윈도우 관리 + 토큰 예산 할당 |
| 보안 | CSAP D-09 민감 컨텍스트 암호화, N2SF 등급별 컨텍스트 격리 |

---

## 기능 요구사항

| FR ID | 요구사항 | 우선순위 |
|-------|---------|---------|
| FR-ADV21.1 | 토큰 예산 관리 — 시스템/사용자/컨텍스트/생성 영역별 할당 | P0 |
| FR-ADV21.2 | 컨텍스트 압축 — Map-Reduce 요약으로 긴 문서 압축 | P0 |
| FR-ADV21.3 | 청크 우선순위 — 관련성/최신성/중요도 기반 동적 정렬 | P0 |
| FR-ADV21.4 | 슬라이딩 윈도우 — 대화 진행에 따른 컨텍스트 자동 조정 | P1 |
| FR-ADV21.5 | 오버플로우 처리 — 토큰 한도 초과 시 우아한 절삭 전략 | P1 |
| FR-ADV21.6 | 컨텍스트 캐시 — 반복 참조 문서의 압축 결과 캐싱 | P2 |
