# SVC-AI-ADV-R26: Fine-Tuning Data Pipeline (파인튜닝 데이터 파이프라인)

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 공공기관 도메인 특화 학습 데이터 수집/정제/검증 자동화 |
| 기술 | 대화 로그 → 정제 → 레이블링 → QA 검증 → 학습 포맷 변환 |
| 보안 | CSAP D-09 학습 데이터 PII 완전 제거, N2SF C/S등급 절대 배제 |

---

## 기능 요구사항

| FR ID | 요구사항 | 우선순위 |
|-------|---------|---------|
| FR-ADV26.1 | 데이터 수집 — 대화 로그/피드백/문서에서 학습 데이터 추출 | P0 |
| FR-ADV26.2 | 정제 파이프라인 — PII 제거, 중복 제거, 품질 필터링 | P0 |
| FR-ADV26.3 | 데이터 포맷 — SFT/DPO/PPO 학습 포맷 자동 변환 | P0 |
| FR-ADV26.4 | 품질 검증 — 데이터셋 분포 분석, 편향 검사, 독성 필터 | P1 |
| FR-ADV26.5 | 버전 관리 — 데이터셋 버전 + 재현 가능한 스냅샷 | P1 |
| FR-ADV26.6 | 데이터 통계 — 항목 수, 토큰 분포, 카테고리 분포 보고 | P2 |
