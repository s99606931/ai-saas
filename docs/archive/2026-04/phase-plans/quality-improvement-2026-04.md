## 9. 학습 및 교훈

### 9.1 잘 수행된 점 (What Went Well)

1. **병렬 분석 전략**: 갭 감지기, 코드 분석가, 감사인 3팀의 병렬 수행으로 5일 내 전수 검증 완료 (순차 수행 대비 2.5배 시간 단축)
2. **체계적 갭 분류**: Critical/Important/Minor 구분 + 권고사항 우선순위 명확화로 산출물 우선순위 의사결정 가속화
3. **아카이브 구조 정립**: PDCA 단계별 산출물 분류 + _INDEX.md 중앙 관리로 다음 사이클(Phase 2) 부팀 진입 용이
4. **CSAP 100% + N2SF 100% 달성**: 79+6개 항목 전수 문서화로 감리 준비도 확보
5. **Tester 에이전트 검증**: 샘플링 기반 검증으로 수정 정확도 97.6% 확보 (보정 후)

### 9.2 개선 필요 영역 (Areas for Improvement)

1. **Design 문서 일관성 부족**: 일부 MTU(C2b, C5, C7)에서 Design 문서 누락 또는 Context Anchor 미포함 → 다음 사이클부터 Plan 단계 완료 전 Design 문서 필수 확인
2. **N2SF 행내 매핑 누락**: CSAP 체크리스트 설계 시 N2SF 매핑을 분야 수준(별도 테이블)으로 분리 → 향후 행 단위로 통합 권고
3. **감사 로그 상세도 부족**: audit.jsonl 존재하나 session-start 누락, action 상세 기록 미흡 → Phase 2 구현 시 구체적 포맷 확정 필수
4. **av-skill 런타임 검증 미실행**: NFR-AV-3/4 기준이 설정되었으나 실제 TC 실행 보류 → 다음 스프린트 최우선 과제

### 9.3 다음 사이클에 적용할 사항 (To Apply Next Time)

1. **Pre-Archival Checklist**: Phase 완료 전에 Design 문서 확인, Context Anchor 포함 여부, N2SF 매핑 행내 명시 등을 자동 체크
