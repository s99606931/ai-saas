# MTU-N144: 규정 준수 대시보드 종합 — Design

> **문서 ID**: MTU-N144.design
> **버전**: 1.0.0 | **작성일**: 2026-04-10
> **작성자**: PM Lead (claude-opus-4-6)
> **Plan 참조**: MTU-N144.plan

---

## Executive Summary

| 관점 | 설계 결정 |
|------|----------|
| 아키텍처 | Grafana 단일 종합 대시보드, CSAP 13개 도메인 x 준수율 게이지 |
| 메트릭 | Kyverno + Gatekeeper + Falco + SLO + 감사로그 + 네트워크 정책 통합 |
| 알림 | 도메인별 준수율 < 90% → Warning, < 80% → Critical |
| 데이터 소스 | Prometheus (Recording Rules 사전 집계), Loki (로그 기반 지표) |

## Design Anchor

| 항목 | 결정 |
|------|------|
| WHY | CSAP 79개 항목 전체 가시성을 단일 대시보드로 제공 |
| WHAT | 13개 도메인별 준수율 + 전체 종합 점수 + N2SF 6영역 매핑 |
| HOW | 기존 모니터링 메트릭을 CSAP 도메인에 매핑하는 Recording Rules + 대시보드 |

## SS1. CSAP 도메인별 메트릭 매핑

| CSAP 도메인 | 항목 수 | 측정 메트릭 소스 |
|------------|---------|----------------|
| D-01 정보보호정책 | 4 | 정책 문서 존재 (정적 = 1.0) |
| D-02 조직 및 인력 | 3 | RBAC 역할 정의 수 |
| D-03 자산관리 | 5 | ConfigMap/Secret 관리 상태 |
| D-04 물리적 보안 | 3 | 정적 (인프라 설정 = 1.0) |
| D-05 인증 및 접근 | 8 | Kyverno 인증 정책 + RBAC |
| D-06 침해사고 관리 | 5 | 감사 로그 기록률 + SLO 위반 감지 |
| D-07 재해복구 | 4 | DR 테스트 성공률 + 백업 상태 |
| D-08 접근통제 | 12 | Kyverno/Gatekeeper 정책 준수율 |
| D-09 암호화 | 4 | TLS 인증서 상태 + Secret 암호화 |
| D-10 네트워크 보안 | 8 | NetworkPolicy 적용률 |
| D-11 시스템 보안 | 7 | Falco 이벤트 + Trivy 스캔 |
| D-12 개발 보안 | 10 | 코드 스캔 결과 + SBOM 상태 |
| D-13 보안 감사 | 6 | 감사 로그 무결성 + 보존 상태 |

## SS2. 대시보드 레이아웃

### 경영진 뷰 (상단)
```
Row 1: [전체 준수율 게이지] [위반 항목 수] [최근 변화 추이] [N2SF 등급]
Row 2: [D-01~D-04 게이지] [D-05~D-08 게이지] [D-09~D-13 게이지]
```

### SRE 상세 뷰 (하단)
```
Row 3: [도메인별 위반 항목 테이블] [위반 트렌드 (30일)]
Row 4: [N2SF 6영역 준수 현황] [ISMS-P 연계 상태]
Row 5: [최근 정책 위반 로그] [자동 조치 이력]
```

## SS3. N2SF 6영역 매핑

| N2SF 영역 | CSAP 도메인 | 측정 지표 |
|----------|-----------|----------|
| N-01 관리체계 | D-01, D-02 | 정책 + 조직 준수율 |
| N-02 물리보안 | D-04 | 물리 보안 설정 상태 |
| N-03 격리영역 | D-10 | NetworkPolicy 적용률 |
| N-04 접근통제 | D-05, D-08 | 인증 + RBAC 준수율 |
| N-05 데이터보호 | D-09, D-13 | 암호화 + 감사 상태 |
| N-06 운영관리 | D-06, D-07, D-11, D-12 | 침해사고 + DR + 보안 |
