# MTU-N241: 전자정부 표준프레임워크 호환성 -- Design

> **버전**: 1.0 | **작성일**: 2026-04-10

## 호환성 범위

전자정부 표준프레임워크 v4.2 기준 호환성 항목:

### 1. 실행환경 호환
- 공통기반 레이어: 인증/인가, 세션 관리, 파일처리
- 화면처리 레이어: REST API 호환 (MVC 패턴 대체)
- 데이터처리 레이어: 데이터 접근 표준 인터페이스
- 연계통합 레이어: 행정 데이터 연계 표준 메시지

### 2. 개발환경 호환
- 빌드/배포: CI/CD 파이프라인 (Gitea Actions 대체)
- 테스트: 자동화 테스트 프레임워크

### 3. 운영환경 호환
- 모니터링: Prometheus/Grafana (표준 모니터링 대체)
- 배포: Helm/k3s (WAS 배포 대체)

## 호환성 전략

표준프레임워크 전면 채택이 아닌 **인터페이스 호환성** 확보:
- REST API 레벨에서 데이터 교환 호환
- 인증/인가 프로토콜 호환 (OAuth2/OIDC)
- 행정 데이터 연계 표준 메시지 지원
