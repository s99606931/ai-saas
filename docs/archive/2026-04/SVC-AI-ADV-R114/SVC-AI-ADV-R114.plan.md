# SVC-AI-ADV-R114 — Agent Memory Consolidator

> 작성일: 2026-04-12 | 버전: 1.0.0 | 작성자: PM Lead
> 원 요청 번호: R109 (충돌로 재배정)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 복수 AI 에이전트 메모리 중복 제거 + 공통 지식 통합 + 충돌 해결 |
| 품질 | 중복률 95%+ 제거, 의미 손실 5% 이내 |
| 보안 | 에이전트 간 데이터 등급 상승 시 전파 차단 |
| 비용 | 로컬 벡터 연산 기반 |

## Context Anchor

- **WHY**: 다중 에이전트 환경에서 동일 정보가 여러 메모리에 중복 저장 → 토큰 낭비 + 모순 발생
- **WHO**: Multi-agent orchestrator, 메모리 저장소 관리자
- **RISK**: 통합 과정에서 중요 컨텍스트 손실 → 신뢰도 가중 병합 + 원본 보존
- **SUCCESS**: 중복 제거 후 단일 권위 있는 통합 지식 베이스 생성
- **SCOPE**: In — 메모리 파싱, 중복 탐지, 병합, 충돌 해결. Out — 메모리 수집, 저장

## 요구사항

- **FR-R114.1**: 복수 에이전트 메모리 입력 (MemoryEntry[])
- **FR-R114.2**: 의미 기반 중복 탐지 (텍스트 유사도 ≥ 0.85)
- **FR-R114.3**: 신뢰도 가중 병합 — 고신뢰도 우선, 저신뢰도 보조
- **FR-R114.4**: 충돌 해결 — 타임스탬프 + 신뢰도 + 출처 다양성 기반
- **FR-R114.5**: 통합 결과 리턴 (ConsolidatedMemory)
- **FR-R114.6**: N2SF 등급 상승 탐지 — 하위 등급 에이전트가 상위 등급 정보 접근 차단
- **FR-R114.7**: 감사 로그 `getAuditLog()` 필수
- **NFR-R114.1**: TypeScript strict 0 에러, 테스트 80%+
- **NFR-R114.2**: 1000 엔트리 통합 50ms 이내
