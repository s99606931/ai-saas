## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 외국인 민원 대응용 다국어 NLP 파이프라인: 언어 감지 + 키워드 추출 + 의도 분류 + 정규화 |

## Context Anchor

- **WHY**: 외국인 민원 증가 → 다국어 자동 분류 및 정규화 필요
- **WHO**: 민원 상담사, 외국인 민원팀, 번역팀
- **RISK**: 민원 내용에 개인정보 포함 가능 → 마스킹 필수
- **SUCCESS**: 원문 입력 → 언어 감지 + 의도 분류 + 키워드 추출 + 정규화
- **SCOPE**: In — 언어감지·의도분류. Out — 실제 번역(외부 MT 서비스)

## 요구사항

- **FR-R257.1**: 지원 언어 등록 (언어코드·정규식 사전)
- **FR-R257.2**: 의도 카테고리 등록 (intent·keywords·language)
- **FR-R257.3**: 언어 감지 (문자셋 비율 기반: 한글·한자·라틴·키릴·아랍)
- **FR-R257.4**: 키워드 추출 (공백 분리 + 불용어 제거 + 빈도 top N)
- **FR-R257.5**: 의도 분류 (키워드 매칭 점수화 → 최고 점수 intent 반환)
- **FR-R257.6**: 텍스트 정규화 (공백 정리·특수문자 제거·소문자화)
- **FR-R257.7**: 파이프라인 처리 (`process(text)` → 전체 결과 반환)
- **FR-R257.8**: C/S 차단, 민원인 ID 마스킹, CSAP D-06 감사 로그, getAuditLog()
- **NFR-R257.1**: TypeScript strict, 테스트 10개+
