# SVC-AI-ADV-R255 — 스마트 계약 유효성 검사 엔진

> 작성일: 2026-04-13 | 버전: 1.0.0 | 작성자: PM Lead (자율 생성)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 공공기관 스마트 계약 조항 파싱 + 필수 조항 검증 + 위험 조항 탐지 + 유효성 판정 |
| 품질 | 규칙 기반 조항 매칭, 점수화, 8개+ 테스트 |
| 보안 | C/S 등급 차단, 계약당사자 ID 마스킹, CSAP D-06 감사 로그 |
| 비용 | 로컬 규칙 엔진, 외부 AI 호출 없음 |

## Context Anchor

- **WHY**: 공공계약 수작업 검토의 누락·오류 → 자동 유효성 검증 필요
- **WHO**: 계약 담당 공무원, 법무팀, 감사팀
- **RISK**: 계약 금액·당사자 식별정보는 S등급 → AI 전송 불가, 로컬 규칙만 허용
- **SUCCESS**: 계약 입력 → 필수 조항 검증 → 위험 점수 → VALID/WARN/INVALID
- **SCOPE**: In — 조항 검증·위험 탐지. Out — 법적 구속력 판단

## 요구사항

- **FR-R255.1**: 계약 등록 (계약번호·조항 목록·계약당사자·금액, O등급 한정)
- **FR-R255.2**: 필수 조항 카탈로그 등록 (clauseId·keyword·category·required)
- **FR-R255.3**: 계약 파싱 → 필수 조항 매칭 (keyword 포함 여부)
- **FR-R255.4**: 위험 조항 탐지 (금지 키워드: 독점·면책·무제한 등)
- **FR-R255.5**: 유효성 판정 (VALID: 필수 100% + 위험 0, WARN: 필수 100% + 위험 존재, INVALID: 필수 누락)
- **FR-R255.6**: N2SF C/S 차단, 당사자 ID 마스킹, CSAP D-06 감사 로그, getAuditLog()
- **NFR-R255.1**: TypeScript strict, 테스트 9개+
