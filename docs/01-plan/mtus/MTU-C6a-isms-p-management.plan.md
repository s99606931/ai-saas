## 목적

ISMS-P(정보보호 및 개인정보보호 관리체계) 관리 분야 16개 항목 구현 가이드를 제공합니다.
정보보호 관리체계 수립·운영에 필요한 정책·조직·자원 통제를 다룹니다.

**ISMS-P 의무화 일정**:
- 2026년: 공공기관 대상 시범 운영 시작
- 2027년 7월: 의무화 대상 전면 확대 시행
- 감사 패러다임 변화: "정책이 있는가?" → "운영 증적이 있는가?" (자동화 증적 필수)

**CSAP와의 관계**:
- CSAP D01~D07 분야와 ISMS-P 관리 분야는 다수 중첩
- 중첩 항목은 CSAP 체크리스트를 primary로 사용, ISMS-P는 cross-reference
- 이중 작업 방지: CSAP 증거 자료 → ISMS-P 증거로 활용 가능

## 핵심 설계 — PDCA 관리 체계

```
Plan (계획)                      Do (실행)
─────────────────────            ─────────────────────
M-01 범위 설정              →    M-09 운영 계획 실행
M-02 책임자 지정            →    M-10 법적 요건 준수
M-03 조직 구성              →    M-11 내부 감사 실시
M-04 정책 수립              →    M-12 감사 결과 처리
M-05 정책 공표              →
M-06 위험 관리 절차         →
M-07 위험 식별/평가         →
M-08 위험 처리 계획         →

Check (점검)                     Act (개선)
─────────────────────            ─────────────────────
M-11 내부 감사              →    M-13 개선 활동
M-12 감사 결과 처리         →    M-14 시정 조치
M-15 경영진 검토/보고        →    M-16 재검토 주기 조정
```

## CSAP 중첩 항목 처리 원칙

```
CSAP 항목이 있는 경우 (primary CSAP)
─────────────────────────────────────
CSAP 증거 자료 → ISMS-P 증거 자료 겸용
예: CSAP-D02-01 정보보호 조직 구성 문서
    → ISMS-P-M-02 최고책임자 증거로 활용 가능

ISMS-P 전용 항목 (CSAP 미대응)
─────────────────────────────────────
ISMS-P-M-06, M-07, M-08 위험 관리
ISMS-P-M-10 법적 요건 준수 검토
→ 별도 문서화 필요
```

## 합격 기준

1. ISMS-P 관리 분야 16항목 전수 수록 (ISMS-P-M-01~16, 누락 0개)
2. CSAP와 중첩되는 9개 항목에 CSAP-DXX-YY 교차 참조 링크 완비
3. 2027년 7월 ISMS-P 의무화 대비 준비 타임라인 포함
4. 각 항목: 증거 자료 목록 + 구현 방법 + CSAP 중첩 여부 표시
5. MTU-C6b (ISMS-P 보호 분야) 참조 링크 포함
6. Auditor 에이전트 Q-GATE G6 통과
