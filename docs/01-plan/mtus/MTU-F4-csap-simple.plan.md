## 목적

CSAP 인증을 처음 준비하는 공공 SaaS 사업자가 일반등급(간편등급)부터 시작하여 표준등급(MTU-C1)으로 업그레이드하는 경로를 명확히 제시합니다. 기술 배경이 없는 PM도 3일 이내 자가진단을 완료할 수 있는 최소 요건 체크리스트를 제공합니다.

**위치**: CSAP 등급 체계에서 MTU-F4(일반등급)는 MTU-C1(표준등급)의 전 단계입니다. 일반등급 인증 없이 표준등급 직접 신청도 가능하나, 일반등급 자가진단을 먼저 수행하면 표준등급 준비 기간이 단축됩니다.

### checklist-simple.md 구성

일반등급 30개 핵심 항목을 다음 영역별로 분류하여 체크리스트를 작성합니다.

**영역 분류** (일반등급 30개 항목):

| 영역 | CSAP 분야 매핑 | 항목 수 | 핵심 확인 사항 |
|------|-------------|---------|-------------|
| A. 정보보호 정책 | D01~D02 | 5 | 정보보호 정책서 존재, 조직 보안 담당자 지정 |
| B. 인적·자산 보안 | D03~D04 | 5 | 보안 서약서, 자산 대장 관리 |
| C. 접근 통제 기본 | D08 (핵심 5개) | 5 | 계정 관리, 비밀번호 정책, 원격 접속 통제 |

### quick-start-guide.md 구성

**섹션 1: CSAP 인증 로드맵** — 신청 절차 플로우차트 (텍스트 기반)
**섹션 2: 등급별 비교표** — 위 비교표 포함
**섹션 3: 일반등급 자가진단 3일 계획**

| 일차 | 활동 | 산출물 |
|------|------|--------|
| 1일차 | 영역 A~C (정책·인적·접근통제) 자가진단 | 체크리스트 A~C 완료 |
| 2일차 | 영역 D~F (암호화·침해사고·네트워크) 자가진단 | 체크리스트 D~F 완료 |
| 3일차 | 영역 G (개발 보안) + 갭 분석 + 개선 계획 수립 | 갭 분석 보고서 초안 |

**섹션 4: 표준등급(MTU-C1) 업그레이드 경로**

일반등급 자가진단 완료 후 표준등급으로 업그레이드하는 3단계 경로를 정의합니다.

```
일반등급 자가진단 완료
    ↓
갭 분석: 일반등급 30개 → 표준등급 79개 추가 49개 식별
    ↓
MTU-C1 착수: 49개 추가 항목 구현 계획 수립
    ↓
MTU-C2~C3 구현 완료
    ↓
KISA 표준등급 인증 신청
```

추가 49개 항목의 분야별 분포와 구현 난이도를 안내합니다.

## 합격 기준 (Acceptance Criteria)

1. 일반·표준·중요등급 3등급 비교표 완비 (항목 수·심사 기간·대상 서비스 등 8개 비교 항목)
2. 일반등급 체크리스트 30개 항목 전수, CSAP-DXX-YY 형식 ID 사용
3. 각 항목에 확인 방법 및 증거 자료 명시
4. PM이 기술 배경 없이 3일 이내 자가진단 완료 가능한 설명 수준
5. 표준등급(MTU-C1) 업그레이드 경로 명시 (추가 항목 수 49개, 분야별 분포 포함)
6. 변경 이력 섹션 존재
