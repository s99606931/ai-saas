| 관점 | 내용 |
|------|------|
| 비즈니스 | 프론트엔드 화면별 최적 API 자동 생성, 네트워크 라운드트립 절감 |
| 기술 | TypeScript strict, OpenAPI 스펙 분석, 쿼리 병합 |

- **WHY**: 공공기관 포털 화면당 API 호출 N개 → 1개로 통합 필요
- **WHO**: 프론트엔드 개발자, 플랫폼 팀
- **RISK**: 권한 우회 - BFF 레이어가 원본 권한 유지해야 함
- **SUCCESS**: 화면 1개당 API 호출 1회로 수렴
- **SCOPE**: 스펙 분석 → BFF 코드 생성 → 권한 전파
