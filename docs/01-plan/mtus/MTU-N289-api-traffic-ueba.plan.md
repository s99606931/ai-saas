# MTU-N289: 실시간 API 이상 트래픽 탐지 (UEBA) — Plan

> **버전**: 1.0.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | API 계층 실시간 UEBA로 악의적 사용/DDoS 자동 차단 |
| 기술 | API 호출 패턴 분석 + 행동 기준선 + 이상 탐지 |
| 보안 | CSAP D-08, D-06 감사, 실시간 위협 대응 |
| 운영 | 자동 속도 제한, IP 차단, 보안팀 연계 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | API 계층 공격(DDoS, 스크래핑, 무작위 대입) 실시간 대응 |
| WHO | API 소비자, 보안 관리자, 플랫폼 운영자 |
| RISK | 오탐으로 정상 API 사용 차단 |
| SUCCESS | 이상 탐지율 90%+, 오탐률 3% 이하 |
| SCOPE | API 패턴 분석, 행동 기준선, 자동 대응, 리포팅 |

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-N289.1 | API 호출 패턴 수집 (엔드포인트/빈도/페이로드크기) | 필수 |
| FR-N289.2 | 사용자/테넌트별 행동 기준선 구축 | 필수 |
| FR-N289.3 | 실시간 이상 탐지 (기준선 이탈) | 필수 |
| FR-N289.4 | 자동 대응 (속도 제한/차단/MFA) | 필수 |
| FR-N289.5 | 위협 인텔리전스 리포트 생성 | 권장 |
| FR-N289.6 | 감사 로그 전수 기록 | 필수 |

## 성공 기준 (SC)

- SC-1: 이상 탐지율 90%+
- SC-2: 오탐률 3% 이하
- SC-3: 탐지~대응 < 5초
- SC-4: 감사 로그 전수 기록
