## Context Anchor

- **WHY**: 공공기관 팀 협업 시 작업 부하 편중·병목 빈번 → 객관적 배분 필요
- **WHO**: 팀 리더, 프로젝트 관리자, 부서장
- **RISK**: 주관적 배분 → 정량 부하 지표 기반 점수화
- **SUCCESS**: 팀원 등록 → 태스크 등록 → 부하 분석 → 배분 권고 → 병목 리포트
- **SCOPE**: In — 부하 분석, 배분 권고, 병목 탐지. Out — 실제 태스크 할당 실행

## 요구사항

- **FR-R250.1**: 팀원 프로필 등록 (역할, 스킬, 가용 시간, 현재 부하)
- **FR-R250.2**: 태스크 등록 (우선순위, 필요 스킬, 예상 시간, 마감일)
- **FR-R250.3**: 부하 분석 (팀원별 가용 대비 할당 비율 계산)
- **FR-R250.4**: 태스크 자동 배분 권고 (스킬 매칭 + 부하 균형)
- **FR-R250.5**: 협업 병목 탐지 (과부하·스킬 갭·지연 위험)
- **FR-R250.6**: N2SF C/S 차단, CSAP D-06 감사 로그, getAuditLog()
- **NFR-R250.1**: TypeScript strict, 테스트 8개+, 커버리지 80%+
