# SVC-AI-ADV-R23: Semantic Router (의미 기반 라우팅)

> 버전: 1.0.0 | 작성일: 2026-04-11 | 작성자: PM Lead

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 사용자 질문의 의도를 분류하여 최적 처리 경로로 라우팅. 비용 50~65% 절감 |
| 기술 | 임베딩 기반 의도 분류 + 규칙 기반 폴백 + 동적 경로 관리 |
| 보안 | CSAP D-08 라우팅 정책 기반 접근 통제, D-06 라우팅 결정 감사 |

---

## 기능 요구사항

| FR ID | 요구사항 | 우선순위 |
|-------|---------|---------|
| FR-ADV23.1 | 의도 기반 라우팅 — 질문 의도별 처리 에이전트/모델 자동 선택 | P0 |
| FR-ADV23.2 | 라우팅 규칙 관리 — 경로 정의 CRUD + 우선순위 설정 | P0 |
| FR-ADV23.3 | 유사도 매칭 — 코사인 유사도 기반 가장 가까운 경로 선택 | P0 |
| FR-ADV23.4 | 폴백 체인 — 매칭 실패 시 기본 경로 + 에스컬레이션 | P1 |
| FR-ADV23.5 | 라우팅 메트릭 — 경로별 적중률/지연/비용 모니터링 | P1 |
| FR-ADV23.6 | 동적 경로 학습 — 피드백 기반 라우팅 정확도 자동 개선 | P2 |
