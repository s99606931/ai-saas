# MTU-N441: 온프레미스 LLM 라우터

## WHY
- 공공기관 데이터 민감도 + 비용 최적화 위해 클라우드/로컬 LLM 자동 선택 필요
- N2SF C/S 등급 강제 로컬, O 등급만 클라우드 허용

## FR
- FR-N441.1 데이터 등급 기반 라우팅 정책
- FR-N441.2 로컬/클라우드 모델 능력 프로필
- FR-N441.3 비용/지연시간 최적화 스코어링
- FR-N441.4 폴백 체인 (1차 실패 시 다음)
- FR-N441.5 라우팅 결정 감사 로그

## Success Criteria
- C/S 등급 → 클라우드 0회 (100% 차단)
- 라우팅 결정 지연 <= 5ms
