# MTU-N266: 연합 학습 (Federated Learning) 프레임워크

> **버전**: 1.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 공공기관 간 데이터를 이동하지 않고 AI 모델 공동 학습. 데이터 주권 보장 |
| 기술 | 연합 학습 코디네이터 + 클라이언트 에이전트 + 모델 집계 알고리즘 |
| 보안 | 원본 데이터 전송 금지 (N2SF C/S등급 보호), 차분 프라이버시 적용 |
| 운영 | 라운드별 학습 현황 모니터링, 참여 기관 관리, 모델 성능 추적 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | 공공기관 데이터는 기관 외 반출 금지. 연합 학습으로 모델 가중치만 교환하여 공동 AI 학습 달성 |
| WHO | 다수 공공기관 (참여자), 중앙 코디네이터 (플랫폼 운영자) |
| RISK | 모델 역전 공격, 비잔틴 참여자, 통신 장애, 데이터 비균일성 |
| SUCCESS | 중앙 집중 대비 모델 성능 95%+, 원본 데이터 0건 전송, 참여 기관 3+ |
| SCOPE | 연합 학습 코디네이터, 클라이언트 에이전트, 집계 알고리즘, 프라이버시 보호 |
