## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | 17개 서비스 공통 캐시 계층 필요. DB 부하 감소 + 응답 시간 개선 |
| WHO | 서비스 개발자 (캐시 연동), SRE (적중률 모니터링) |
| RISK | 캐시 없이 매 요청 DB 조회 → 높은 지연, DB 과부하 |
| SUCCESS | LRU + TTL 캐시, 테넌트 격리, 적중률 90%+ 목표 |
| SCOPE | In-memory LRU 캐시 (Phase 1). Redis 연동은 Phase 2 |

## 기능 요구사항

| ID | 요구사항 | 우선순위 | 검증 방법 |
