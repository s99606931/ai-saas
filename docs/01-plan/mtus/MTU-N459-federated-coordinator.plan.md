# MTU-N459 — 기관 간 연합학습 조정자

## Executive Summary
| 관점 | 내용 |
|------|------|
| 비즈니스 | 기관 간 데이터 공유 없이 AI 모델 공동 학습 |
| 기술 | Federated Averaging + 라운드 관리 |
| 규제 | 개보법, N2SF C등급 데이터 보호 |
| 품질 | 라운드별 수렴성 검증 |

## Context Anchor
- **WHY**: 원본 데이터 이동 없이 기관 간 AI 협력
- **WHO**: 데이터 과학자, 연구기관
- **RISK**: 중앙 서버 공격, 모델 파라미터 유출
- **SUCCESS**: 5개 기관 연합, 라운드 10회 이상 수렴
- **SCOPE**: `packages/federated-learning/`

## 기능 요구사항
- **FR-FL.1**: 참여 기관 등록 + 인증
- **FR-FL.2**: 라운드 관리자 (글로벌 모델 배포/수집)
- **FR-FL.3**: FedAvg 집계 알고리즘
- **FR-FL.4**: 수렴성 모니터링
- **FR-FL.5**: 라운드 감사 로그
