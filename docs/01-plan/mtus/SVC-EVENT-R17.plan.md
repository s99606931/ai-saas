## 기능 요구사항

### FR-EVT.1: @public-saas/event-bus 패키지

**모듈 구조**:
- `EventBus`: 타입 안전 이벤트 발행/구독 (pub/sub)
- `RetryQueue`: 실패 이벤트 재시도 큐 (지수 백오프)
- `eventBusPlugin`: Fastify 플러그인

### FR-EVT.2: 이벤트 발행/구독

- 이벤트명 + 페이로드 타입 안전 바인딩
- 다중 리스너 등록/해제
- 와일드카드 구독 (패턴 매칭)
- 동기/비동기 핸들러 지원

### FR-EVT.3: 재시도 + 데드레터 큐

- 실패 시 지수 백오프 재시도 (최대 3회)
- 최대 재시도 초과 시 데드레터 큐 이동
- 데드레터 큐 조회/재처리 기능

### FR-EVT.4: 이벤트 통계

- 발행/소비/실패 카운트
- 평균 처리 시간
- 데드레터 큐 크기

## 검증 기준

- 이벤트 발행/구독 정상 동작
- 와일드카드 패턴 매칭 확인
- 재시도 지수 백오프 동작
- 데드레터 큐 이동 확인
- 전체 테스트 PASS
