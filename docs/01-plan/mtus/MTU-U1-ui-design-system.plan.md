## Context Anchor

### WHY (왜 필요한가)

1. **공공기관 디지털 전환 가속**: 행안부 KRDS(범정부 UI/UX 디자인 시스템) 2025년 정식 공개로 공공 서비스 UI 표준화 요구 증가
2. **멀티테넌시 시각 분리**: MTU-E2에서 설계한 다중 기관 아키텍처에서 각 기관의 시각적 정체성(CI) 유지 필수
3. **AI 기반 업무 효율화**: 2026년 SaaS UI 트렌드로 contextual AI assistant가 핵심 차별화 요소로 부상
4. **접근성 법적 의무**: 장애인차별금지법 + 지능정보화기본법에 따른 웹 접근성 준수 의무
5. **다중 플랫폼 지원**: 공공기관 현장 업무용(모바일) + 사무실(데스크탑) + 회의실(대형 화면) 동시 지원 요구

### SCOPE (범위)

**In Scope**:
- 디자인 토큰 시스템 (CSS Custom Properties 기반)
- 기본 테마 5종 + 다크모드
- 반응형 레이아웃 시스템 (모바일/태블릿/데스크탑/대형)
- 테넌트별 테마 커스터마이제이션 설계
- AI 어시스턴트 UI 컴포넌트 설계
- 동적 레이아웃 커스터마이제이션 설계
- KWCAG 2.2 접근성 준수 가이드
- 컴포넌트 카탈로그 (Atomic Design)
- Storybook 8 설정 가이드
- KRDS (범정부 디자인 시스템) 참조 매핑

**Out of Scope**:
- 실제 React 컴포넌트 코드 구현 (설계 문서만)
- 백엔드 API 구현
- 실제 AI 모델 통합 (MTU-A1 범위)
- 네이티브 모바일 앱 (웹 브라우저 기반만)
- 피그마/스케치 디자인 파일 제작
