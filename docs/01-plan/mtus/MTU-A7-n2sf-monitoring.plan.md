## Executive Summary

| 관점 | 내용 |
|------|------|
| WHY | N2SF는 국정원이 연 1~2회 가이드라인을 업데이트 — 미반영 시 CSAP 인증 유지 불가 및 감리 결함 위험 |
| WHO | 보안 담당자 (주간 모니터링), 아키텍트 (영향 분석), 팀장 (30일 이내 업데이트 승인) |
| RISK | 규정 변경 미탐지 → 30일 경과 → 구 버전 기준 운영 → CSAP NFR-7 위반 |
| SUCCESS | 변경 탐지부터 문서 업데이트 완료까지 30일 이내 SLA 준수, 버전 격리 전략으로 이력 추적 완비 |
| SCOPE | 모니터링 채널 정의 + 변경 탐지 프로세스 + 영향 분석 절차 + 버전 격리 전략 문서; 실제 모니터링 실행은 운영 단계 |

---

## 목적

N2SF 국정원 가이드라인이 연중 업데이트되는 리스크를 관리합니다.
변경 발생 시 30일 이내 프레임워크 반영을 보장하는 프로세스를 정의합니다.

## 모니터링 프로세스 설계

```
[주간 확인] 국정원 공지사항 + N2SF 공식 채널
    → 변경 없음: 로그만 기록
    → 변경 있음: [영향 분석] (5일 이내)
         → 영향 없음: 로그 기록
         → 영향 있음: [업데이트 계획 수립] (10일 이내)
              → [문서 업데이트] (30일 이내)
              → [Auditor 재검증]
              → 변경 이력 기록
```

**버전 격리 전략**:
- 기준 변경 시 기존 파일 보존 + 신규 버전 파일 생성
- 각 N2SF 파일 상단에 "적용 기준일: YYYY-MM-DD" 메타데이터 필수

**모니터링 자동화 지원**:

| 자동화 항목 | 도구/방법 | 주기 |
|-----------|---------|------|
| RSS 피드 수집 | 국정원 공지사항 RSS (있는 경우) | 일간 |
| 키워드 알림 | N2SF, 클라우드 보안 관련 공식 채널 | 주간 |
| 체크리스트 상태 | `.claude/audit.jsonl` N2SF 항목 변경 추적 | 월간 |
| 자동 보고서 | Gitea Actions weekly-n2sf-check.yml | 주간 |

**모니터링 채널 (최소 2개 공식 채널)**:
1. **국가정보원 공식 사이트** (nis.go.kr) — 클라우드 보안 가이드 공지
2. **KISA 인터넷보호나라** (boho.or.kr) — 클라우드 보안 권고사항
3. CSAP 인증 기관 (KISA-K-ISMS 클라우드 분야) — 인증 기준 업데이트

---

## 합격 기준

1. 모니터링 채널 목록 명시 (국정원 공식 채널 최소 2개)
2. 변경 탐지 → 영향 분석 → 업데이트 완료 SLA (30일) 명시
3. 버전 격리 전략 섹션 포함
4. NFR-7 (30일 이내 규정 변경 반영) 직접 참조
