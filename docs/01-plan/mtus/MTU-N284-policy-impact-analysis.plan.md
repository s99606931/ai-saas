# MTU-N284: 정책 영향 분석 AI — Plan

> **버전**: 1.0.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 입법예고/정책 변경 시 영향 범위 자동 분석으로 의사결정 지원 |
| 기술 | LLM 기반 법령 비교 분석 + 이해관계자 영향도 매핑 |
| 보안 | N2SF O등급, PII 마스킹, 감사 로그 |
| 운영 | 국가법령정보센터 연동 표준 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | 정책 변경 영향 분석의 수작업 부담 해소 |
| WHO | 정책 담당자, 법률 자문관, 의사결정자 |
| RISK | 법령 해석 오류, 영향도 과소/과대 추정 |
| SUCCESS | 영향 범위 식별 정확도 85%+, 분석 시간 60% 단축 |
| SCOPE | 법령 변경 비교, 영향 범위 분석, 이해관계자 매핑, 리포트 생성 |

## 기능 요구사항

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-N284.1 | 법령/정책 변경 사항 자동 감지 | 필수 |
| FR-N284.2 | 변경 전후 비교 분석 (diff) | 필수 |
| FR-N284.3 | 영향 범위 자동 식별 | 필수 |
| FR-N284.4 | 이해관계자 영향도 매핑 | 필수 |
| FR-N284.5 | 영향 분석 리포트 자동 생성 | 필수 |
| FR-N284.6 | 감사 로그 전수 기록 | 필수 |

## 성공 기준 (SC)

- SC-1: 영향 범위 식별 정확도 85%+
- SC-2: 분석 시간 60% 단축
- SC-3: PII 마스킹 100%
- SC-4: 감사 로그 전수 기록
