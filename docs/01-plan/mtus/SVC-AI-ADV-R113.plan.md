# SVC-AI-ADV-R113 — Retrieval Quality Scorer

> 작성일: 2026-04-12 | 버전: 1.0.0 | 작성자: PM Lead
> 원 요청 번호: R108 (충돌로 재배정)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | RAG 검색 결과의 정확도/다양성/신선도를 자동 채점하여 품질 게이트 제공 |
| 품질 | 채점 정확도 ±0.05 이내, 5ms 이내 응답 |
| 보안 | 문서 본문 AI 전송 전 N2SF 등급 확인, C/S 차단 |
| 비용 | 순수 계산 기반, 외부 API 호출 없음 |

## Context Anchor

- **WHY**: RAG 파이프라인에 품질 게이트 부재 → 저품질 검색 결과가 LLM으로 직접 전달되어 환각률 상승
- **WHO**: AI Service RAG Engine, 검색 후처리 레이어
- **RISK**: 점수 조작 시 저품질 결과 통과 → 다중 메트릭 가중 평균으로 단일 지표 의존 회피
- **SUCCESS**: 정확도/다양성/신선도 3지표 합산 0~1 스칼라 + 카테고리별 세부 점수
- **SCOPE**: In — 스코어링 알고리즘, 임계값 관리, 감사 로그. Out — 검색 자체, 재순위화

## 요구사항

- **FR-R113.1**: 정확도 점수 — 쿼리-문서 코사인 유사도 기반 가중 평균
- **FR-R113.2**: 다양성 점수 — 결과 간 중복도 계산 (MMR 역수)
- **FR-R113.3**: 신선도 점수 — 문서 타임스탬프 기반 시간 가중 감쇠
- **FR-R113.4**: 통합 점수 — 3지표 가중 합산 (기본 0.5/0.3/0.2)
- **FR-R113.5**: 임계값 게이트 — 점수 미만 시 차단 신호 발행
- **FR-R113.6**: N2SF 등급 검증 — C/S 등급 차단 guard
- **FR-R113.7**: 감사 로그 `getAuditLog()` — 모든 채점 이벤트 append-only
- **NFR-R113.1**: TypeScript strict 0 에러, 테스트 커버리지 80%+
- **NFR-R113.2**: 5ms 이내 100개 결과 채점 완료
