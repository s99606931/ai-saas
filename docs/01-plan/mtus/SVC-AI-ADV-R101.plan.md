# SVC-AI-ADV-R101 — 그래프 이상 전파 탐지기 (Graph Anomaly Propagator)

> 작성일: 2026-04-12 | 버전: 1.0.0

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 서비스 의존성 그래프에서 이상 신호를 이웃 노드로 전파하여 연쇄 위험 탐지 |
| 품질 | PageRank 유사 알고리즘, 200 노드 100ms 이내 |
| 보안 | 메트릭/메타데이터만 사용 |
| 비용 | 순수 계산, LLM 없음 |

## Context Anchor

- **WHY**: 단일 노드 이상탐지는 존재하나, 연쇄 영향은 미탐
- **WHO**: SRE, 인시던트 대응팀
- **SUCCESS**: 노드 이상 점수 입력 → 이웃 전파 후 위험 노드 랭킹

## 요구사항

- **FR-R101.1**: 노드/에지 등록 (의존성 그래프)
- **FR-R101.2**: 초기 이상 점수 설정
- **FR-R101.3**: propagate(iterations) — 반복 평균화
- **FR-R101.4**: top-k 위험 노드 반환
- **FR-R101.5**: 수렴 탐지 (점수 변화 < epsilon)
- **NFR-R101.1**: 테스트 5개+
