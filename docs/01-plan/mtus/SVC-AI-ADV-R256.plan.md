# SVC-AI-ADV-R256 — AI 기반 예산 배분 최적화

> 작성일: 2026-04-13 | 버전: 1.0.0 | 작성자: PM Lead (자율 생성)

## Executive Summary

| 관점 | 내용 |
|------|------|
| 기능 | 사업별 우선순위·형평성·집행률 기반 예산 배분 최적화 + 부서별 형평성 점수 |
| 품질 | 가중치 기반 스코어링, greedy 배분, 형평성 보정 |

## Context Anchor

- **WHY**: 공공 예산 배분의 주관성 → 데이터 기반 형평성 보정 필요
- **WHO**: 기획재정부, 지자체 예산팀, 기관 재무팀
- **RISK**: 예산 정보 = S등급 → AI 전송 불가, 로컬 계산만
- **SUCCESS**: 사업 목록 + 총예산 → 우선순위 점수 + 배분 결과
- **SCOPE**: In — 배분 계산·형평성 평가. Out — 실제 집행

## 요구사항

- **FR-R256.1**: 사업 등록 (사업ID·부서·요청금액·우선순위·긴급도·집행률, O등급 한정)
- **FR-R256.2**: 총예산 설정 및 유효성 검사 (>0)
- **FR-R256.3**: 스코어 계산 (우선순위 40 + 긴급도 30 + 집행률 30, 0~100)
- **FR-R256.4**: greedy 배분 (스코어 내림차순, 총예산 한도 내)
- **FR-R256.5**: 형평성 보정 (부서별 배분 편차 > threshold 시 상위 10% 차감)
- **FR-R256.6**: 부서별 형평성 점수 계산 (Gini 계수 기반)
- **FR-R256.7**: N2SF C/S 차단, 부서명 마스킹, CSAP D-06 감사 로그, getAuditLog()
- **NFR-R256.1**: TypeScript strict, 테스트 9개+
