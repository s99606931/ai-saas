## Context Anchor

### WHY
현재 AI 서비스는 세션 단위로 대화가 초기화되어 이전 상담 내용을 기억하지 못합니다. 공공기관 민원 처리에서 "어제 문의한 주민등록 발급 건 진행 상황"과 같은 연속 상담을 처리하려면 다중 세션 메모리가 필수입니다.

### SUCCESS
- SC-1: 단기 메모리 — 세션 내 최근 N턴 유지 (윈도우 버퍼)
- SC-2: 장기 메모리 — 대화 요약을 벡터 저장하여 과거 대화 검색
- SC-3: 작업 메모리 — 대화 중 추출된 핵심 엔티티(이름, 건명 등) 추적
- SC-4: 메모리 보존 정책 — TTL, 사용자 삭제 요청
