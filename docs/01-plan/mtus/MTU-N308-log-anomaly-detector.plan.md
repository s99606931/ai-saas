| 비즈니스 | 시스템 로그에서 이상 패턴 자동 탐지로 장애 사전 예방 |

## Context Anchor

- **WHY**: 로그 볼륨 증가로 수동 분석 한계, AI 기반 자동 탐지 필요
- **WHO**: SRE, 보안 관리자, 시스템 관리자
- **RISK**: 오탐으로 알림 피로, 미탐지로 장애 확대
- **SUCCESS**: 이상 탐지율 85%+, 오탐률 15% 이하, 장애 사전 탐지율 70%+
- **SCOPE**: 로그 수집 -> 패턴 학습 -> 이상 탐지 -> 알림 -> 상관 분석
