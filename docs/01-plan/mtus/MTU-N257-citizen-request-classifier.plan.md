# MTU-N257: AI 기반 민원 자동 분류/라우팅

> **버전**: 1.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)
> **상태**: Plan 완료

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 공공기관 민원 접수 시 AI로 자동 분류(카테고리/부서/긴급도)하여 담당 부서에 자동 라우팅. 처리 시간 단축 및 민원인 만족도 향상 |
| 기술 | LLM 기반 다중 분류 + 시맨틱 유사도 + 규칙 기반 하이브리드. 신뢰도 점수 기반 자동/수동 라우팅 결정 |
| 보안 | 민원 내용 PII 마스킹 후 AI 처리 (N2SF O등급), 분류 결과 감사 로그 전수 기록 |
| 운영 | 분류 정확도 모니터링, 피드백 루프로 지속 개선, A/B 테스트 지원 |

---

## Context Anchor

| 항목 | 내용 |
|------|------|
| **WHY** | 민원 수동 분류는 평균 30분 소요, 오분류율 15%. AI 자동화로 3초 이내 분류, 오분류율 5% 이하 목표 |
| **WHO** | 민원 접수 담당자, 부서별 처리 담당자, 민원인, 시스템 관리자 |
| **RISK** | 오분류로 인한 민원 지연, PII 유출, LLM 환각(hallucination) |
| **SUCCESS** | 분류 정확도 90%+, 처리 시간 <3초, PII 마스킹률 100%, 감사 추적 100% |
| **SCOPE** | 분류 엔진 + 라우팅 규칙 + 긴급도 판별 + 피드백 루프 + 감사 로그 |
