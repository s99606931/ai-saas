# MTU-N137: 운영 런북 인덱스 — Plan

> 버전: 1.0 | 작성일: 2026-04-10 | 작성자: PM Lead

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | 분산된 런북을 통합 인덱싱하여 인시던트 대응 시간 단축 |
| 기술 | 런북 자동 탐색 + 알림 패턴 매칭 기반 런북 추천 |
| 보안 | CSAP D-06 인시던트 대응 체계 준수 |
| 운영 | 인시던트 발생 시 관련 런북 즉시 안내 |

## Context Anchor

| 항목 | 내용 |
|------|------|
| WHY | 런북이 분산 관리되어 인시던트 시 적절한 런북 탐색에 시간 소요 |
| WHO | SRE 팀, 온콜 엔지니어 |
| RISK | 런북 분류 정확도 |
| SUCCESS | 알림명 또는 증상으로 관련 런북 즉시 조회 |
| SCOPE | 런북 인덱스 스크립트 + 검증 테스트 |

## 기능 요구사항

| FR ID | 요구사항 | 검증 기준 |
|-------|---------|----------|
| FR-N137.1 | 런북 자동 탐색 및 목록화 | scripts/runbook-* 전수 탐색 |
| FR-N137.2 | 알림-런북 매핑 | 알림명으로 관련 런북 추천 |

| FR-N137.4 | 런북 상태 검증 | 실행 가능 여부 + 최근 갱신 확인 |
