# MTU-N259: ML 피처 스토어

> **버전**: 1.0 | **작성일**: 2026-04-12 | **작성자**: PM Lead (자율)
> **상태**: Plan 완료

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| 비즈니스 | ML 모델 학습/추론에 사용되는 피처를 중앙 관리. 피처 재사용률 향상, 학습-추론 편향(skew) 방지 |
| 기술 | 오프라인 피처(배치 계산) + 온라인 피처(실시간 서빙) 이중 저장소 + 피처 버저닝 |
| 보안 | 피처 데이터 N2SF O등급만 저장, 테넌트 격리, 접근 감사 |
| 운영 | 피처 신선도 모니터링, 스키마 진화, 피처 계보(lineage) 추적 |

---

## Context Anchor

| 항목 | 내용 |
|------|------|
| **WHY** | ML 팀이 동일 피처를 반복 계산 → 비효율. 학습 vs 추론 피처 불일치 → 모델 성능 저하 |
| **WHO** | ML 엔지니어, 데이터 사이언티스트, AI 서비스 (추론 시 피처 조회) |
| **RISK** | 피처 신선도 저하, 스키마 변경 시 모델 호환성 깨짐 |
| **SUCCESS** | 피처 CRUD, 온라인/오프라인 서빙, 버전 관리, 계보 추적 |
| **SCOPE** | 피처 정의 + 저장소 + 서빙 레이어 + 피처 그룹 + 메트릭 |
