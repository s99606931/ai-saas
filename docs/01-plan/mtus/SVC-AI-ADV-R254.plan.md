| 기능 | 시민 프로파일 기반 맞춤 공공서비스 추천 + 자격 판정 + 순위 정렬 |

## Context Anchor

- **WHY**: 시민이 받을 수 있는 공공서비스 파악 어려움 → 자동 추천 필요
- **WHO**: 시민, 민원 상담사, 지자체 복지팀
- **RISK**: 개인정보 민감 → PII 마스킹·O등급 한정
- **SUCCESS**: 프로파일 입력 → 자격 판정 → 맞춤 추천 반환
- **SCOPE**: In — 추천·자격 판정. Out — 실제 신청 대행
