# MTU-N455 — 마이데이터 동의 관리 플랫폼 AI

## Executive Summary
| 관점 | 내용 |
|------|------|
| 비즈니스 | 개인정보 자기결정권 강화, 마이데이터 사업 대응 |
| 기술 | 동의 수명주기 관리 + 동적 범위 제어 |
| 규제 | 개인정보보호법, 마이데이터 표준 API |
| 품질 | 동의 추적 100%, 철회 즉시 처리 |

## Context Anchor
- **WHY**: 마이데이터 시대 정보주체 동의 관리 자동화
- **WHO**: 개인정보 보호책임자, 서비스 이용자
- **RISK**: 동의 범위 초과 처리, 철회 미반영
- **SUCCESS**: 동의 이력 append-only, 철회 10초 이내 반영
- **SCOPE**: `packages/mydata-consent/`

## 기능 요구사항
- **FR-MD.1**: 목적별 동의 수집 (필수/선택 구분)
- **FR-MD.2**: 동의 수명주기 관리 (생성/수정/철회/만료)
- **FR-MD.3**: 동적 범위 제어 (항목별 on/off)
- **FR-MD.4**: 동의 이력 감사 로그 (append-only)
- **FR-MD.5**: 정보주체 권리 요청 라우팅
