## Context Anchor

- **WHY**: 공공 통계 데이터(KOSIS) 자동 분석 수요 증가 → 수작업 한계
- **WHO**: 통계청, 정책 분석관, 지자체 기획부서
- **RISK**: 오분석 → Z-score·추세 계수 기반 정량화
- **SUCCESS**: 시계열 등록 → 추세 분석 → 이상치 탐지 → 인사이트 반환
- **SCOPE**: In — 시계열 분석, 이상치, 인사이트. Out — 원본 KOSIS API 호출

- **FR-R251.1**: 통계 시계열 등록 (지표 ID, 연도별 값, 단위)
