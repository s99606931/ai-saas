## 핵심 결정 사항

1. **R158 Content Policy**: LLM 분류기 대신 규칙 기반 RegExp 선택 — 결정성·지연 0·외부 의존 없음. 런타임 addRule/removeRule 로 확장성 확보.
2. **R159 Semantic Cache**: HNSW 대신 선형 스캔 코사인 — 1000 항목 이하 테넌트별 스토리지에 충분. TTL(1시간) + LRU 이중 만료로 메모리 상한 보장.
3. **R160 Hallucination Scorer**: NLI 모델 대신 토큰 일치도 + hedge 휴리스틱 — 빠른 결정적 실행, 감리 설명 가능. citations 없음 → 0.9 자동 high 정책.
4. **R161 Prompt Registry**: previousActive 1단계만 유지 — 롤백 거버넌스 단순화, 다중 롤백은 상위 책임. 최초 register 자동 활성화로 UX 개선.
5. **R162 SLA Tracker**: 슬라이딩 윈도우 100 샘플 + minSamples 10 — HdrHistogram 외부 의존 회피, p50/p95/p99 기본 제공.
