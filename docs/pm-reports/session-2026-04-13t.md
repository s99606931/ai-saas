## 핵심 설계 결정

1. **공통 데이터 가드 함수화**: `DATA_GRADE_BLOCK` 튜플과 `blockClassifiedData` 함수를 각 모듈에 동형 복제하여 C/S등급 차단 일관성 확보 (N2SF N-05).
2. **append-only 감사 로그**: 각 클래스 `private auditLog: AuditEntry[]`, `getAuditLog()`은 defensive copy(`[...this.auditLog]`)로 반환하여 외부 변조 방지.
3. **noUncheckedIndexedAccess 대응**: 배열 인덱스 접근 시 `?? 0`, `!` non-null assertion, `.at()` 패턴 사용. 특히 `agricultural-price-predictor-ai.ts`의 `prices[0]`, `school-violence-prevention-ai.ts`의 학급 정규화 등에서 엄격 처리.
4. **PII 마스킹 — R530**: `admin-petition-classifier-ai.ts`에서 주민등록번호(`[RRN_MASKED]`), 휴대폰(`[PHONE_MASKED]`), 이메일(`[EMAIL_MASKED]`) 자동 마스킹을 제출 단계에서 수행하여 CSAP D-12 + 개인정보보호법 준수.
5. **동적 가중치 엔진**: 각 위험 평가 모듈(R521, R526, R528)은 하드코딩된 가중치 대신 `Record<Type, number>` 맵 기반 곱셈으로 계산하여 향후 튜닝 용이성 확보.
6. **정규화 점수**: R528 학교폭력 예방은 학급 크기에 따라 신호 점수를 `students/25` 기준으로 정규화하여 대규모 학급이 자동으로 불리해지는 편향 제거.
