## 주요 결정 및 설계

### R118 Policy-Aware Response Filter
- 정책 규칙 사전 컴파일(regex pre-compile) + block/mask/flag 3액션
- 첫 `block` 발생 시 즉시 종료 (early exit)
- 기본 7규칙: PII(이메일/RRN/전화), SYS-PATH, 허위광고, 비속어, 정치편향
- `policyVersion` 필드로 정책 버전 추적

### R119 AI Load Balancer
- 5가지 전략 패턴 (round-robin / weighted / least-loaded / cost-optimal / latency-optimal)
- `inFlight` 카운터 기반 동시성 제어, maxConcurrency 초과 시 자동 제외
- p95 레이턴시 윈도우(최근 20), 실패율 과반(최근 10) → degraded 자동 전환
- `tag` hint로 백엔드 서브셋 선택 (예: premium/vision)
- 전 백엔드 불가 시 `NoBackendAvailableError`

### R120 Document Intelligence Pipeline
- Stage 인터페이스 기반 Chain of Responsibility
- 기본 4스테이지: OCR → Classify(4카테고리) → Extract(4엔티티) → Structure
- `skipOnFailure` + `retries` 재시도 옵션
- structured 결과 재귀적 PII 마스킹 (중첩 객체/배열 대응)
- 단계별 신뢰도(confidence) + 스킵 목록 + 총 소요시간 기록

### R121 Feedback Loop Optimizer
- variant별 1~5 rating + signal(thumbs-up/down/report/neutral)
- 95% 신뢰구간 (1.96·std/√n) 기반 승격·강등 결정
- 승격: ciLower > promoteThreshold(4.0)
- 강등: ciUpper < demoteThreshold(2.5) 또는 reports > reportTolerance(5)
- minSamples(30) 미달 시 `insufficient`로 보류
- comment 필드 PII 자동 스크럽
- 기존 `ai-feedback-loop.ts`와 모듈 분리 (수집 vs 최적화)

### R122 Compliance Report Generator
- 3프레임워크(CSAP/N2SF/MOIS) 통합 레지스트리
- 상태 4종: compliant/partial/non-compliant/not-applicable
- `coverageRate` = compliant / totalRequired (not-applicable 제외)
- Markdown 리포트: 요약 테이블 + 미흡 항목 목록 + 증적 전수
- JSON summary로 대시보드 연동 가능
