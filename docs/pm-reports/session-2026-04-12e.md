## Key Decisions & Outcomes

### R59 Semantic Firewall
- 룰+휴리스틱+콘텐츠분류 3단 구조 채택 (LLM 분류기 옵션은 비용 이슈로 보류)
- `combo` 부스트 로직: injection과 jailbreak 동시 발생 시 score에 +0.2 가산 (명백한 공격 강력 탐지)
- 정책 핫리로드로 운영 중 키워드 목록 교체 가능

### R60 Federated RAG
- Hub-Spoke 연합 방식 채택 (데이터 주권 보존, 허브 장애는 서킷브레이커로 완화)
- RRF(k=60) + 노드별 weight 결합
- 실패율 50% 초과 시 자동 브레이커 오픈 (최소 표본 4개 이후)

### R61 Tool-Use Planner
- DAG 기반 계획 + 대체 도구 백트래킹
- Depth 계산은 선행 의존(deps) 체인의 최장 경로 DFS + 메모이제이션
- admin 롤은 모든 도구 권한 암시적 보유 (RBAC 간편화)

### R62 Retrieval Fallback Chain
- 순차 폴백 (Parallel fan-out은 비용 문제로 제외)
- `external: boolean` 플래그로 C/S 등급일 때 자동 제거
- 품질 조기 종료(`scoreThreshold`)로 일반 요청은 첫 단계에서 완료

### R63 Prompt Cache-Aware Router
- Consistent sticky hash: `{tenantId}::{sha256(prefix).slice(0,32)}` 키로 테넌트 격리
- TTL 기반 만료 + 수동 `invalidate`/`invalidateTenant`
- 노드 해제 시 해당 노드 캐시 자동 제거

## 발견된 이슈 및 해결

1. **R59 초기 score 계산**: `ignore previous + DAN mode` 프롬프트가 block 임계값 미달로 review 판정 → 인젝션·탈옥 동시 발생 시 +0.2 콤보 부스트 추가하고 단독 가중치도 0.55/0.45로 상향 조정.
2. **R61 assertDagAndDepth 방향 오류**: `adj`를 `current → deps`로 구성하여 체인 시작 노드에서 자식이 없어 depth가 증가하지 않음 → deps 체인을 역추적하는 최장 경로 DFS + 메모이제이션으로 재작성. 순환 탐지 유지.
