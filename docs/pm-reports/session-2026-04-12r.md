## 주요 결정

### R148: Prompt Injection Defender v2
- 기존 `prompt-injection-detector`(LLM 판정)와 차별화 위해 **컨텍스트 분리(system/user/context)** + **3레이어 정적 검증**으로 설계
- Layer1(delimiter 0.4) → Layer2(키워드 0.5) → Layer3(control char 0.3) 가중 누적
- `buildProtectedPrompt()` 16자 hex nonce 경계로 섹션 충돌 방지

### R149: Model Fallback Chain
- 단순 try/catch 루프를 넘어서 **cooldown circuit breaker** 패턴 적용
- 실패 시 자동 `markUnhealthy` (기본 60초) → 다음 호출에서 skip → 경과 후 자동 복구
- `localeCompare` tiebreaker로 결정론적 우선순위

### R150: Sentiment-Based Router
- 초기 `neg*0.6 + urg*0.4` 공식은 단일 약한 신호(실망 0.3 등) 반영 부족 → 테스트 실패
- **`max(neg,urg) + min(neg,urg)*0.5`** 공식으로 변경 → 단일 강한 신호 반영 + 동반 시 가산
- Design 문서도 동기화

### R151: Document Redaction Engine
- 정규식 처리 순서가 **핵심**: phone(0XX-XXX-XXXX) → account(숫자-숫자-숫자) 순서 필수
- 6종 PII(rrn/email/phone/account/passport/classified) 단일 파이프라인
- RedactionHit에 원본 값 보존 → 감사 추적 + 역변환 가능

### R152: Output Regression Detector
- Jaccard 유사도(`[\p{L}\p{N}]+` 유니코드 토큰화) 기반 per-case 판정
- `shouldBlock` 플래그로 CI/CD 배포 게이트 역할
- 미제출 케이스는 `reason='missing'`으로 자동 regressed 처리 → 커버리지 누락 방지
