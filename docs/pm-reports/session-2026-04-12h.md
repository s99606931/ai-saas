## Key Decisions & Outcomes

### R76 Agent Dry-Run Simulator (사전 구현 + 보강)
- 전 세션 작성된 설계/구현/테스트 확인 후 사전 존재 인정
- TS strict 오류 1건 수정 (`tools[0]!` non-null assertion)
- 도구 레지스트리 기반 정적 side-effect 추정 + 미등록 도구 즉시 BLOCKED

### R77 Retrieval Chunk Deduplicator
- exact dedup: FNV-1a 32bit 해시 (정규화 포함)
- semantic dedup: 토큰 Jaccard ≥ 0.85 (기본값, 조정 가능)
- 대표 청크 선정: score 내림차순 + text 길이 tie-break
- C/S 등급 청크는 완전 제거 + BLOCKED 감사

### R78 Prompt Variant Experimenter
- R18 `prompt-ab-testing.ts`와 차별화: 경량 러너 + 결정적 할당 + 승자 판정
- FNV-1a(expId:sessionId) / 0xFFFFFFFF → 0~1 균등 할당 (편차 < 15% @ n=200)
- 판정 룰: minSamples 미달=running / Δquality ≥ 0.05 / 무승부=inconclusive
- weight 합계 1±0.001 검증

### R79 Multi-LLM Fallback Router (시크릿 관리 핵심)
- **시크릿 하드코딩 차단**: `sk-[A-Za-z0-9]{20,}`, `[A-Fa-f0-9]{32,}` 패턴 탐지 → throw `SECRET_HARDCODED`
- **envKey 저장만**: ProviderSpec에는 env 변수 이름만, 값 조회는 `resolveKey()` → `process.env[envKey]`
- 3가지 정책 (priority/cost/latency) + tie-break는 priority
- 서킷브레이커: 3회 연속 실패 → open, 30초 쿨다운 후 half-open
- half-open 상태에서 성공 시 closed, 실패 시 다시 open
- 테스트에서 `setClock()` 시계 주입으로 타이밍 의존성 해소

### R80 AI Telemetry Replayer (N2SF 마스킹 핵심)
- 기록 시 C/S 등급 즉시 차단 (`RECORD_GRADE_BLOCKED`)
- PII 마스킹: 이메일/전화/RRN (주민등록번호)
- 마스킹 누락 재탐지 → `MASK_LEAK` 감사 + 재적용
- FNV-1a hex 해시로 응답 동등성 비교
- regression 판정: 해시 불일치 or latency 초과(default 200ms)
- TTL 기반 자동 evict (기본 24h)

## 발견된 이슈 및 해결

1. **R77 정규화 순서 오류** → 구두점 제거 전 공백 정규화 시 토큰 병합 발생
   - 해결: 구두점을 공백으로 치환 후 공백 collapse
2. **R78 record() 메서드명 충돌** → 감사 기록 vs trial 결과 기록이 동일 이름
   - 해결: 내부 헬퍼를 `logEvent()`로 분리, 공개 API는 `recordResult()`로 명확화
3. **R79 타이밍 의존 테스트** → 서킷브레이커 쿨다운 검증이 실시간 기반
   - 해결: `setClock(() => number)` 시계 주입 API 추가
4. **R80 마스킹 정규식 상태** → global regex는 `lastIndex` 상태 유지로 오탐 가능
   - 해결: 매 사용 후 `lastIndex = 0` 재설정 + 재검증 루프
