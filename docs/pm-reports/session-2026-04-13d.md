## 완료 라운드 상세

### R268 — Public API SLA Predictor
- 모듈: `public-api-sla-predictor.ts`
- 기능: API 응답 샘플 기록(최대 1000, 순환 버퍼) → p50/p95/p99 백분위 + 성공률 → EWMA(α=0.3) 기반 latency 예측 → 최근 20개 violationProb → OK/WARN/CRITICAL 심각도
- 테스트: 16개 (C/S 차단, 샘플 부족, CRITICAL/WARN/OK 분기, 성공률, IP 마스킹, clearSamples)

### R269 — DR Runbook Executor
- 모듈: `dr-runbook-executor.ts`
- 기능: 재해복구 런북 등록(의존성 그래프) → 단계별 실행 상태 전이 → 의존 단계 미완료 차단 → 롤백 경로 → 진행률/durationMs
- 테스트: 16개 (C/S 차단, 빈 steps, 잘못된 의존, 순차 실행, 재시도 카운트, PENDING 롤백 차단)

### R270 — Security Event Correlator v2
- 모듈: `security-event-correlator-v2.ts`
- 기능: IP 유효성 검증 → 5분 슬라이딩 윈도우 그룹화 → PRIV_ESC→CRITICAL / BRUTE_FORCE→HIGH / PORT_SCANNING→MED / MIXED_ATTACK→HIGH / SUSPICIOUS_LOGIN→MED 패턴 매칭 → 옥텟 마스킹
- 테스트: 14개 (5종 패턴 분기, 윈도우 경계, IP별 분리, 마스킹)

### R271 — OpenData Quality ETL
- 모듈: `opendata-quality-etl.ts`
- 기능: 스키마 정의(string/number/date/boolean + required + pattern) → 레코드 유효성 검증 → 완전성(40%) + 유효성(40%) + 일관성(20%) 가중 종합 점수 → errorSummary top10
- 테스트: 16개 (중복 필드/스키마, 타입 불일치, 패턴 불일치, 필수 누락, 품질 점수)

### R272 — Budget Execution Anomaly v2
- 모듈: `budget-execution-anomaly.ts`
- 기능: agency:account 예산 한도 → Z-score≥2.0 STATISTICAL 이상치 → 동일 supplier+금액 7일 이내 DUPLICATE → 계정 합계 초과 OVER_BUDGET → 3종 동시 탐지
- 테스트: 14개 (금액 검증, 7일 경계, 극단값, 다중 이상치)

### R273 — Intelligent Doc Search
- 모듈: `intelligent-doc-search.ts`
- 기능: 한/영 토큰화 + 불용어 필터 → 문서별 TF Map → IDF=log(N/df)+1 → TF*IDF 점수 → 태그 필터 + 매칭 시 1.5배 가중 → topN
- 테스트: 15개 (빈 쿼리, 매칭 없음, 태그 필터, 점수 정렬, 삭제)

### R274 — AI Audit Automation
- 모듈: `ai-audit-automation.ts`
- 기능: 감리 체크리스트(clause + severity) 등록 → 증적 PASS/FAIL/PENDING 제출 → HIGH=5/MED=3/LOW=1 가중 리스크 점수 → compliance% → 미준수 항목 목록
- 테스트: 14개 (C/S 차단, 빈 체크리스트, 리스크 점수 계산, 혼합 상태, 증적 재제출)
