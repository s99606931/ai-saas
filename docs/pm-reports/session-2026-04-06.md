## 사용자 테스트 시작 방법

```bash
# 1. 의존 서비스 기동
docker compose up -d

# 2. DB 초기화 + 시드
pnpm prisma migrate deploy
pnpm prisma db seed

# 3. 포털 기동
pnpm --filter @public-saas/portal dev
# → http://localhost:4000

# 4. E2E 자동 테스트
pnpm playwright test
pnpm playwright show-report
```
