## 주요 기술 결정

### R128: 차원별 독립 히스토그램 접근
- 다변량 공분산 대신 각 차원 개별 PSI 평균 사용
- 베이스라인 min/max 고정 → bin 경계 안정화 (sample 추가 시에도 동일 경계)
- 동일 값 구간 대비 `max = min + ε` 방어 코드

### R129: IRV Ranked Choice 결정성 확보
- 1순위 집계 → 과반 달성 즉시 종료
- 최소 득표 다수 시 한꺼번에 탈락 (표준 IRV 규칙)
- 모든 답변 동률 라운드에 도달하면 `alphabetical-survivor` 결정론 tiebreaker
- rankings 미제공 시 각 응답 자신의 answer만 보유한 1요소 랭킹으로 fallback

### R130: 3지표 severity 정책
- 지표 1개 위반 → warning, 2개 이상 → critical (false positive 억제)
- tenantId별 cool-down Map으로 중복 알람 차단
- Q1/Q3 계산에 선형 보간 기반 `quantile()` 사용

### R131: 한국어 2-gram 토큰화
- `[\uac00-\ud7af]` 한글 블록만 추출 후 n=2 슬라이딩
- 영어 단어는 2자 이상 소문자 매칭
- `alerted` 플래그로 세션당 단 1회 알람 emit (알람 피로 방지)

### R132: 원본 불변성 보장
- ingest 시 payload shallow copy + binary insertion (timestamp 기준)
- replay/traceCausality 반환값은 maskSensitive를 거친 새 객체
- exportVisualization 최종 JSON deep copy로 외부 mutation 완전 격리
- 시크릿 키 (`secret/password/token/apiKey/credential`) 자동 `[REDACTED]`
