- 순수 수학 모델 사용 — AI 외부 호출 없음 (O등급 메타데이터만)

### R139: WCAG 준수 제약
- `required: true` 컴포넌트는 어떤 경우에도 `visible=false` 금지
- 접근성 우선 원칙으로 heuristic 판정보다 선행

### R140: 탐욕 클러스터링
- Union-Find 대신 O(n²) 탐욕법 선택 (소규모 배치 가정)
- 대표 선택: 최장 텍스트 → 동률 시 최신 (정보량 최대화 + 최신성)
- 3-gram 기본값, 임계값 0.7 (F1 0.85+ 목표)

### R141: 민원인 식별자 해시 강제
- 정규식 `^[a-f0-9]{8,}$` 으로 평문 이름/ID 차단
- Personal Information Protection Act 준수 설계
- terminal 플래그로 상태 전이 명시적 종료

### R142: Baseline 이중 판정 전략
- Baseline 존재: 드리프트 점수(accDelta×0.7 + confDelta×0.3) 기반
- Baseline 부재: 절대 정확도(0.5/0.8) 임계값 fallback
- 롤링 버퍼 FIFO shift로 메모리 누수 방지
