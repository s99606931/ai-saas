## 기술 하이라이트

**R113 Retrieval Quality Scorer**
- 3지표(정확도/다양성/신선도) 가중 합산 0.5/0.3/0.2
- 다양성 = 1 - pairwise 코사인 평균
- 신선도 = exp(-age/halfLife) 평균
- 가중치 합 검증(생성자) — 0.9999~1.0001 허용

**R114 Agent Memory Consolidator**
- Union-find O(n²) 클러스터링 (n ≤ 1000 가정)
- 신뢰도 가중 평균 = Σ(conf²) / Σconf
- 등급 상승 차단: callerGrade < entry.grade 제외

**R115 AI Governance Dashboard Backend**
- In-memory `Map<category, Map<name, MetricPoint[]>>`
- 버킷 rollup: `Math.floor(ts/bucketSize) * bucketSize`
- RBAC matrix: viewer/auditor/admin

**R116 Streaming Response Assembler**
- 복구 JSON 파서: 미종료 문자열 `"` 추가, 괄호 카운트 `}`/`]` 추가, trailing comma 제거
- PII 패턴 3종(email/RRN/phone) 실시간 치환
- onPartial 발행은 복구 성공 시에만

**R117 Cross-Lingual AI Bridge**
- 유니코드 범위 기반 언어 감지: AC00-D7AF(한글), 3040-30FF(カナ), 4E00-9FFF(한자)
- 8개 공공기관 고유명사 사전 내장
- glossaryApplied × 0.01 confidence 가산
