## 목적

본 문서는 공공기관 SaaS 프레임워크를 처음 접하는 사용자가 **15분 이내**에 본인 역할에 맞는 핵심 문서에 도달하도록 안내합니다.

3가지 경로 중 본인에게 맞는 경로를 선택하세요.

---

## 경로 선택 가이드

| 나는... | 선택할 경로 |
|---------|-----------|
| 사업 전체를 파악해야 하는 CTO/팀장 | **경로 A: 경영진 경로** |
| CSAP 인증을 준비하는 PM/기획자/보안 담당 | **경로 B: 인증 경로** |
| 개발 환경을 구성하는 개발자/DevOps | **경로 C: 개발 경로** |

---

## 경로 A: 경영진 경로 (CTO/팀장)

> **목표**: 프레임워크 전체 구조 파악 + CSAP 인증 로드맵 이해
> **소요 시간**: 15분

### 단계 1: 프레임워크 전체 구조 파악 (5분)

[README.md](README.md)의 **섹션 2: 프레임워크 구조**를 읽으세요.

**확인 사항**:
- [ ] 8개 모듈(00~07) + 참조(99) 구조 파악
- [ ] 5개 Phase 로드맵 확인
- [ ] 전체 35개 MTU 규모 이해

### 단계 2: CSAP 등급 체계 이해 (5분)

`02-csap-simple/quick-start-guide.md`의 **등급별 비교표**를 읽으세요.

**확인 사항**:
- [ ] 일반/표준/중요 3등급 차이 파악
- [ ] 귀사에 적합한 등급 결정
- [ ] 인증 소요 기간 확인 (1개월~6개월)

### 단계 3: 사업계획서 템플릿 확인 (5분)

`03-audit-docs/T01-business-plan.md`의 **필수 섹션 목록**을 스캔하세요.

**확인 사항**:
- [ ] 감리 필수 산출물 구성 파악
- [ ] 사업 범위(In Scope/Out of Scope) 작성 방향 이해

### 경로 A 완료

이 경로를 마치면 다음을 알게 됩니다:
- 프레임워크가 커버하는 범위 (CSAP + N2SF + 감리)
- 귀사에 적합한 CSAP 등급
- 감리 산출물 준비 규모

**다음 단계**: `02-csap-simple/quick-start-guide.md` 전체 읽기 -> CSAP 자가진단 시작

## 경로 B: 인증 경로 (PM/기획자/보안 담당)

> **목표**: CSAP 일반등급 자가진단 시작점 도달
> **소요 시간**: 15분

### 단계 1: CSAP 등급 비교 (3분)

`02-csap-simple/quick-start-guide.md`의 **등급별 비교표**를 읽으세요.

**확인 사항**:
- [ ] 일반등급 30개 항목 vs 표준등급 79개 항목 차이 이해
- [ ] 일반등급부터 시작하는 것이 적합한지 판단

### 단계 2: 자가진단 체크리스트 시작 (7분)

`02-csap-simple/checklist-simple.md`의 **영역 A: 정보보호 정책** 5개 항목을 읽으세요.

**확인 사항**:
- [ ] 체크리스트 형식 이해 (항목 ID, 확인 방법, 증거 자료)
- [ ] 영역 A 5개 항목의 현재 준수 상태 자가 판단
- [ ] 3일 자가진단 계획 구조 파악

### 단계 3: 감리 T02 요구사항 확인 (5분)

`03-audit-docs/T02-requirements.md`의 **요구사항 ID 체계**를 읽으세요.

**확인 사항**:
- [ ] FR/NFR/INFR/AI-REQ/CC-REQ 5종 ID 체계 이해
- [ ] CSAP 항목과 요구사항 교차 참조 방법 이해

### 경로 B 완료

이 경로를 마치면 다음을 알게 됩니다:
- CSAP 일반등급 30개 항목의 구체적 내용
- 자가진단 진행 방법
- 요구사항 정의서 작성 체계

**다음 단계**: `02-csap-simple/checklist-simple.md` 영역 A~G 전수 자가진단 (예상 3일)

## 경로 C: 개발 경로 (개발자/DevOps)

> **목표**: 개발 표준 이해 + 사전 요건 확인
> **소요 시간**: 15분

### 단계 1: 사전 요건 확인 (5분)

[prerequisites.md](prerequisites.md)의 체크리스트를 확인하세요.

**확인 사항**:
- [ ] WSL2 + Ubuntu 22.04+ 설치 상태
- [ ] k3s 설치 가능 여부
- [ ] Gitea + Claude Code 준비 상태

### 단계 2: 코딩 스타일 가이드 (5분)

`01-dev-standards/coding-style-guide.md`의 **핵심 규칙**을 읽으세요.

**확인 사항**:
- [ ] 들여쓰기/네이밍/함수 크기 규칙 파악
- [ ] CSAP 보안 패턴(입력 검증, 암호화, 감사 로그) 이해
- [ ] Dead Code 금지 정책 확인

### 단계 3: 리뷰 체크리스트 확인 (5분)

`01-dev-standards/review-checklist.md`를 스캔하세요.

**확인 사항**:
- [ ] PR 코드리뷰 항목 파악
- [ ] OWASP Top 10 체크 항목 확인
- [ ] 문서 리뷰 항목 확인

### 경로 C 완료

이 경로를 마치면 다음을 알게 됩니다:
- 프레임워크 개발 환경 구성 요건
- 코딩 스타일 및 보안 패턴
- PR 리뷰 절차

**다음 단계**: [prerequisites.md](prerequisites.md)의 미충족 항목 설치 -> `01-dev-standards/` 전체 읽기
