## 개요

본 문서는 공공기관 SaaS 프레임워크를 활용하여 **감리(행안부 고시 제2023-1호)** 및 **CSAP 표준등급 인증(KISA)**을 실제로 취득하기 위한 단계별 제출 가이드입니다.

**현재 프레임워크 상태**:
- CSAP 79개 통제항목 체크리스트: 완비 (템플릿)
- 감리 T01~T07 산출물 템플릿: 완비
- N2SF 6개 영역 통제 가이드: 완비
- **비즈니스 서비스별 실제 내용 입력**: 미완 → 아래 지침에 따라 작성

> **중요**: 모든 템플릿 파일의 `{중괄호}` 및 `[TODO]` 항목은 실제 사업 정보로 반드시 교체해야 합니다. 이를 교체하지 않으면 감리 불통과 및 CSAP 심사 반려가 발생합니다.

### 1.6 T06 시험결과서 완성 가이드

**파일**: `06-audit-compliance/templates/T06-test-result.md`

> **주의**: 이 문서는 실제 시험 실행 후 작성합니다. 가상의 수치를 기입하면 감리 불통과 원인이 됩니다.

#### 실제 시험 실행 절차

1. **T05 시험계획서**의 시험 일정대로 시험 실행
2. 시험 유형별 실행:
   - 문서 검토(DOC): 각 정책서·절차서 검토 후 결과 기록
   - 설정 검토(CFG): k3s/Gitea/Harbor 설정값 확인 후 기록
   - 기능 시험(FUN): 실제 RBAC, 암호화, 감사 로그 동작 확인
   - 자동화 검증(AUT): CI/CD 파이프라인 실행 결과 캡처
3. 각 항목 `PASS/CONDITIONAL/FAIL/N/A` 판정 기록
4. FAIL 항목은 T07에 즉시 등록

### 1.7 T07 결함관리대장 완성 가이드

**파일**: `06-audit-compliance/templates/T07-defect-management.md`

> **운영 지침**: T07은 프로젝트 시작부터 종료까지 **상시 관리** 문서입니다.

#### 결함 등록 기준

- [ ] **CRITICAL**: 24시간 이내 조치 후 즉시 재시험
- [ ] **HIGH**: 3영업일 이내 조치, 감리 전 전수 종결 필수
- [ ] **MEDIUM**: 1주일 이내 조치
- [ ] **최종 감리 기준**: CRITICAL/HIGH 미결 0건 달성 필수

#### 주요 예상 결함 유형 (사전 준비)

| 예상 결함 영역 | 심각도 | 사전 점검 방법 |
|-------------|--------|------------|
| JWT 토큰 만료 설정 미적용 | HIGH | 접근 통제 설정 확인 |
| TLS 1.3 미적용 (TLS 1.2 사용) | HIGH | openssl s_client로 확인 |
| 감사 로그 일부 이벤트 누락 | MEDIUM | audit.jsonl 샘플 검토 |
| 비밀번호 정책 미준수 | HIGH | 시스템 설정 확인 |
| 정보보호 정책서 미승인 | HIGH | 경영진 서명 확인 |

## 2. CSAP 표준등급 인증 제출 가이드

### 2.1 CSAP 심사 신청 전 필수 준비 목록

- [ ] `02-csap/standard-grade/checklist-master.md` 79항목 전수 자가진단

- [ ] 미충족 항목 우선순위 분류 (필수/권고)

#### Phase 2: 증거 자료 수집 (D-day 기준 6주 전)

각 분야별 필수 증거 자료:

**D-01 정보보호 정책 (관리 담당)**
- [ ] 정보보호 정책서 (최신 경영진 승인본) — 별도 작성 필요
- [ ] 정책 검토 회의록 (연 1회 이상)
- [ ] 법령 준수 매트릭스 (`99-references/regulations-index.md` 활용 가능)

**D-02 조직 보안 (HR/경영 담당)**
- [ ] 조직도 (보안 전담 조직 포함)
- [ ] CISO 임명장
- [ ] 부서별 보안 담당자 목록

**D-03 인적 보안 (HR 담당)**
- [ ] 보안 서약서 양식 및 징구 대장

**D-04 자산 관리 (IT 자산 담당)**

**D-05 공급망 보안 (DevOps)**

**D-06 침해사고 관리 (보안/운영)**

```
1주차: 자가진단
  → 02-csap/simple-grade/checklist-simple.md
  → 30항목 전수 체크 (☐ → ☑)
  → 미충족 항목 개선

2주차: 증거 자료 수집
  → 각 항목 "증거 자료" 열의 파일 준비
  → 핵심: 정보보호 정책서, 조직도, 보안 서약서

3주차: 심사 신청
  → KISA 포털 신청 + 체크리스트 + 증거 파일 제출

4주차: 현장 심사
  → 심사관 인터뷰 대응
```

**일반등급 vs 표준등급 차이**:

| 항목 | 일반등급 | 표준등급 |
|------|---------|---------|
| 통제 항목 수 | 30개 | 79개 |
| 준비 기간 | 3~4주 | 3~6개월 |
| 대상 서비스 | 비중요 공공 서비스 | 중요 정보 처리 공공 서비스 |
| 비용 | 낮음 | 높음 |
| 갱신 주기 | 2년 | 2년 |

## 8. 자주 묻는 질문 (FAQ)

### Q1. 감리와 CSAP 인증을 동시에 진행해도 되나요?

**A**: 가능합니다. 감리 T01~T04 산출물과 CSAP 증거 자료는 상당 부분 중복됩니다. 순서 권장:
1. T01~T02 작성 (감리 준비와 동시에 CSAP 자가진단 시작)
2. CSAP 마스터 체크리스트 완성 (약 5일)
3. T03~T04 작성 (감리 1차와 CSAP 증거 수집 병행)
4. T05~T07 작성 (감리 2차와 CSAP 최종 준비 병행)

### Q2. {중괄호} 항목을 채우지 않고 제출하면 어떻게 되나요?

**A**: 감리관이 즉시 반려합니다. 감리 체크리스트 CL-01(산출물 완비)에서 불통과 판정을 받습니다. 모든 `{중괄호}` 및 `[TODO]` 항목을 교체해야 합니다.

### Q3. 프레임워크 문서만으로 CSAP 표준등급 취득이 가능한가요?

**A**: 프레임워크 문서는 **기술 구현 증거와 절차 문서의 90%를 커버**합니다. 단, 다음 문서는 별도 작성이 필요합니다:
- 정보보호 정책서 (경영진 승인 필요)
- CISO 임명장
- 보안 교육 이력 (실제 교육 실시 필요)
- BCP/DR 절차서
- 모의 훈련 결과

### Q4. ISMS-P 의무화 시기는 언제인가요?

**A**: 2027년 7월 1일입니다. CSAP 취득 후 중복 항목(40개)이 자동 대응되므로, CSAP를 먼저 취득하는 것이 효율적입니다.

### Q5. N2SF 준수는 별도 인증이 필요한가요?

**A**: 현재(2026년 기준) N2SF는 별도 인증이 아닌 **CSAP D-13 공공기관 추가 보호조치**에 포함되어 심사됩니다. 2026년 하반기 본격 시행 후 별도 심사 도입 여부를 모니터링하십시오 (`03-n2sf/n2sf-change-monitoring.md`).
