## 1. 개요

CSAP 표준등급 79항목과 ISMS-P 101항목의 중복 영역을 통합 관리하기 위한 상세 매핑 문서입니다. CSAP 인증 선행 취득 시 증적 재활용으로 ISMS-P 심사 준비 공수를 40% 절감합니다.

### 1.1 매핑 요약

| 유형 | 항목 수 | 증적 재활용 방법 |
|------|--------|----------------|
| 완전 중복 | 36 | CSAP 증적 그대로 제출 |
| 부분 중복 | 9 | CSAP 증적 + 보완 증적 추가 제출 |
| ISMS-P 고유 | 56 | 신규 증적 수집 필요 |

## 5. 증적 버전 관리 규칙

### 5.1 버전 체계

```
증적 버전: v{CSAP버전}.{ISMS보완버전}

예시:
- v1.0.0: CSAP 최초 작성
- v1.0.1: ISMS-P 보완 사항 추가
- v1.1.0: CSAP 갱신 심사 반영
- v1.1.1: ISMS-P 사후심사 반영
```

### 5.2 동시 업데이트 절차

1. CSAP 증적 변경 시 -> ISMS-P 매핑 항목 영향도 분석
2. 영향 있는 ISMS-P 증적도 동시 업데이트
3. 변경 이력에 양쪽 ID 교차 기록
4. 매핑표(`csap-isms-mapping.md`) 버전 갱신

### 5.3 변경 추적 규칙

- 모든 증적 변경은 Git 커밋으로 추적
- 커밋 메시지에 `CSAP-{ID}` 또는 `ISMS-{ID}` 태그 필수
- 연간 증적 변경 이력 보고서 자동 생성 (Gitea CI)
