## 1. 개요

CSAP 표준등급 79항목과 ISMS-P 101항목 간의 중복 항목을 매핑합니다. CSAP 인증 선행 취득 시 증적을 재활용하여 ISMS-P 심사 준비 부담을 최소화합니다.

### 1.1 매핑 결과 요약

| 유형 | 항목 수 | 설명 |
|------|--------|------|
| **완전 중복** | 36 | CSAP 증적을 ISMS-P에 직접 제출 가능 |
| **부분 중복** | 9 | CSAP 증적 + 추가 보완 증적 필요 |
| **ISMS-P 고유** | 56 | 신규 증적 수집 필요 |
| **합계** | 101 | |

### 1.2 효과

- CSAP 인증 선행 시 ISMS-P 증적 **45%** (45/101) 재활용 가능
- 심사 준비 예상 공수 **40% 절감**
- 관리적 통제 영역 최대 중복 (정책/조직/인적 보안)

## 5. 증적 재활용 가이드

### 5.1 재활용 절차

```
1. CSAP 증적 패키지에서 해당 증적 복사
2. ISMS-P 항목별 폴더에 배치
3. 부분 중복 항목: 추가 증적 보완
4. 증적 매핑 테이블 업데이트
5. 자가진단 체크리스트 업데이트
```

### 5.2 주의사항

- CSAP 증적의 유효 기간 확인 (심사일 기준 1년 이내)
- 조직 변경 사항이 있으면 증적 갱신 필요
- 개인정보 처리 관련 항목은 CSAP에 없으므로 반드시 신규 작성
