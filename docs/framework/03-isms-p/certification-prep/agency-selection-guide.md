## 1. 국내 ISMS-P 인증 심사기관 목록

### 1.1 인증기관 현황 (2026년 기준)

ISMS-P 인증 심사는 과학기술정보통신부 및 개인정보보호위원회가 지정한 인증기관에서 수행합니다.

| 인증기관 | 유형 | 설립 | 주요 실적 | 연락처 |
|---------|------|------|---------|--------|
| **한국인터넷진흥원(KISA)** | 정부 기관 | 2009 | ISMS-P 인증 총괄, 직접 심사 가능 | 118 (인증센터) |
| **한국정보통신기술협회(TTA)** | 민간 심사기관 | 1988 | 다수 공공기관 심사 실적 | 031-724-0114 |
| **한국정보보호산업협회(KISIA)** | 민간 심사기관 | 1997 | 클라우드 SaaS 심사 전문 | 02-3495-0600 |
| **금융보안원(FSI)** | 금융 전문 | 2015 | 금융권 특화 (해당 시) | 02-3495-9700 |

### 1.2 인증기관별 비교표

| 비교 항목 | KISA | TTA | KISIA |
|---------|------|-----|-------|
| 심사 비용 | 중간 | 중간~높음 | 중간 |
| 클라우드 SaaS 경험 | 높음 | 중간 | 높음 |
| 심사 대기 기간 | 2~3개월 | 1~2개월 | 1~2개월 |
| 사전 컨설팅 | 제한적 | 가능 | 가능 |
| 공공기관 실적 | 매우 많음 | 많음 | 많음 |
| 갱신 심사 연속성 | 보장 | 보장 | 보장 |

### 1.3 권장 선택 기준

1. **클라우드 SaaS 심사 경험**: 클라우드 환경 이해도가 높은 기관 우선
2. **공공기관 심사 실적**: 공공기관 특수 요건(N2SF, 감리 등) 이해도
3. **일정 가용성**: 2027-07 의무화 데드라인 준수를 위한 심사 가능 시기
4. **비용**: 기관 규모에 적합한 비용 범위
5. **부가 서비스**: 사전 컨설팅, 모의 심사 제공 여부

## 2. 심사 신청 절차

### 2.1 사전 준비 사항

| 순서 | 항목 | 설명 | 기한 |
|------|------|------|------|
| 1 | 인증 범위 확정 | 인증 대상 시스템/서비스/조직 범위 정의 | D-180 |
| 2 | 관리체계 구축 | 정보보호 정책/조직/자산관리 체계 수립 | D-150 |
| 3 | 위험 평가 완료 | 자산 식별 -> 위협 분석 -> 위험 평가 -> 보호대책 선정 | D-120 |
| 4 | 101항목 자가진단 | 체크리스트 기반 현황 점검 + 결함 보완 | D-90 |
| 5 | 증적 수집 완료 | 101항목별 증적 자료 수집 및 정리 | D-60 |

### 2.2 신청 양식 작성

ISMS-P 인증 신청서에 포함해야 할 주요 정보:

1. **신청 기관 정보**: 기관명, 대표자, 사업자등록번호, 주소
2. **인증 범위**: 대상 시스템, 서비스, 조직, 물리적 범위
3. **조직 현황**: 임직원 수, 정보보호 조직 구성, CISO 임명 현황
4. **시스템 현황**: 서버/네트워크/보안장비 현황, 클라우드 환경 정보
5. **이전 인증 이력**: CSAP, ISO 27001 등 기인증 현황
6. **희망 심사 일정**: 서류 심사/현장 심사 희망 기간

### 2.3 심사 계약 체결

1. 인증기관에 심사 신청서 + 부속 서류 제출
2. 인증기관 접수 확인 + 심사팀 구성 통보 (1~2주)
3. 심사 비용 산정 + 계약서 체결
4. 심사 일정 확정 (서류 심사 -> 현장 심사)

### 2.4 심사 흐름

```
신청서 제출 → 접수 확인 → 계약 체결 → 서류 심사 → 현장 심사 → 결함 보완 → 인증서 발급
   D-90         D-80        D-70       D-45       D-14~D-0     D+14       D+30
```

## 3. 예상 비용 산정표

### 3.1 규모별 심사 비용 (추정치, 부가세 별도)

| 규모 | 인원 | 시스템 수 | 심사 비용 (추정) | 컨설팅 비용 (선택) |
|------|------|---------|----------------|-----------------|
| 소규모 | 50인 미만 | 10개 미만 | 2,000~3,000만원 | 1,000~2,000만원 |
| 중규모 | 50~200인 | 10~30개 | 3,000~5,000만원 | 2,000~3,000만원 |
| 대규모 | 200인 이상 | 30개 이상 | 5,000~8,000만원 | 3,000~5,000만원 |

### 3.2 비용 구성 요소

| 항목 | 비율 | 설명 |
|------|------|------|
| 심사원 인건비 | 60% | 심사원 수 x 심사일 x 일당 |
| 관리비 | 20% | 인증기관 운영비 |
| 인증서 발급비 | 10% | 인증서 발급 + 등록 |
| 기타 | 10% | 교통비, 숙박비 등 |

### 3.3 비용 절감 방안

1. **CSAP 인증 선행**: CSAP 증적 45% 재활용으로 심사 범위 축소 가능
2. **사전 컨설팅 생략**: 자체 역량 충분 시 컨설팅 비용 절감
3. **조기 신청**: 인증기관 비수기(1~3월) 활용 시 우선 배정
