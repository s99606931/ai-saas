# ISMS-P 심사 일정 템플릿

> **문서 ID**: ISMS-P-AUDIT-SCHEDULE
> **버전**: 1.0.0 | **일자**: 2026-04-06 | **작성자**: PM Agent

## 1. 개요

ISMS-P 인증 심사 준비를 위한 표준 일정 템플릿입니다. D-Day(현장 심사일)를 기준으로 역산하여 각 마일스톤을 정의합니다.

---

## 2. 전체 타임라인 (D-180 ~ D+30)

```
D-180 ████ 인증기관 선정 + 계약
D-150 ████ 인증 범위 확정 + 관리체계 점검
D-120 ████ 101항목 증적 수집 (80% 목표)
D-90  ████ 자가진단 완료 + 결함 목록 확정
D-60  ████ 결함 보완 완료 + 증적 패키지 정비
D-45  ████ 서류 심사 (인증기관 원격)
D-30  ████ 서류 심사 결과 보완 + 현장 심사 준비
D-14  ████ 현장 심사 일정 확정 + 사전 회의
D-7   ████ 최종 리허설 (모의 심사)
D-0   ████ 현장 심사 (3~5일)
D+14  ████ 결함 보완 기한 (결함 발견 시)
D+30  ████ 인증서 발급
```

---

## 3. 단계별 상세

### 3.1 D-180: 인증기관 선정 및 계약

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 인증기관 후보 선정 (3개 이상) | CISO | 비교표 | 3개 기관 비교 완료 |
| 견적 요청 및 비교 | CISO | 견적서 | 비용 확정 |
| 인증기관 최종 선정 | 경영진 | 선정 보고서 | 경영진 승인 |
| 심사 계약 체결 | CISO | 계약서 | 서명 완료 |

### 3.2 D-150: 인증 범위 확정

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 인증 범위 정의 (시스템/서비스/조직/물리) | CISO | 범위 정의서 | 인증기관 합의 |
| 관리체계 현황 점검 | 보안담당 | 현황 보고서 | 16항목 점검 |
| 개인정보 처리 현황 파악 | CPO | 처리 현황표 | 21항목 파악 |

### 3.3 D-120: 증적 수집 (80% 목표)

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 관리체계 증적 (16항목) | CISO | 증적 폴더 | 80% 수집 |
| 보호대책 증적 (64항목) | 보안담당 | 증적 폴더 | 80% 수집 |
| 개인정보 증적 (21항목) | CPO | 증적 폴더 | 80% 수집 |
| CSAP 중복 증적 이관 (45항목) | 보안담당 | 이관 확인서 | 45항목 이관 |

### 3.4 D-90: 자가진단 완료

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 101항목 자가진단 체크 | 전원 | 자가진단서 | 101항목 전수 |
| 결함 목록 확정 | CISO | 결함 목록 | 결함 0건 목표 |
| 결함 보완 계획 수립 | 보안담당 | 보완 계획서 | 기한 배정 |

### 3.5 D-60: 결함 보완 완료

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 결함 보완 실행 | 각 담당 | 보완 결과서 | 결함 0건 |
| 증적 패키지 최종 정비 | 보안담당 | 증적 패키지 | 101항목 100% |
| 모의 심사 실행 (내부) | CISO | 모의심사 결과 | 통과 |

### 3.6 D-45: 서류 심사

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 증적 패키지 제출 | CISO | 제출 확인서 | 인증기관 접수 |
| 서류 심사 대응 | 전원 | 보완 서류 | 지적사항 0건 |

### 3.7 D-14: 현장 심사 준비

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 심사 장소 확보 (회의실) | 총무 | 장소 예약 | 3~5일 확보 |
| 심사 대응 인원 배정 | CISO | 배정표 | 영역별 담당 |
| 시스템 시연 준비 | 개발팀 | 시연 스크립트 | 리허설 완료 |
| 증적 인쇄물 준비 (요청 시) | 보안담당 | 인쇄물 | 필요 시 |

### 3.8 D-0: 현장 심사 (3~5일)

| 일차 | 내용 | 참석자 |
|------|------|--------|
| 1일차 | 착수 회의 + 관리체계 심사 | CISO, 경영진 |
| 2일차 | 보호대책 심사 (기술/물리) | 개발팀, 인프라팀 |
| 3일차 | 개인정보 처리단계 심사 | CPO, 법무 |
| 4일차 | 보완 심사 + 시스템 시연 | 전원 |
| 5일차 | 종료 회의 + 결함 통보 | CISO, 경영진 |

### 3.9 D+14: 결함 보완

| 작업 | 담당 | 산출물 | 완료 기준 |
|------|------|--------|---------|
| 결함 보완 계획 수립 | CISO | 보완 계획서 | 3일 이내 |
| 결함 보완 실행 | 각 담당 | 보완 증적 | 14일 이내 |
| 보완 결과 제출 | CISO | 보완 보고서 | 인증기관 확인 |

### 3.10 D+30: 인증서 발급

- 인증위원회 심의 -> 인증서 발급 -> ISMS-P 인증 마크 사용 가능

## 4. 체크리스트 템플릿

### 4.1 주간 체크 (D-180 ~ D-0)

```markdown
## 주간 ISMS-P 준비 현황 (YYYY-MM-DD)

- [ ] 이번 주 계획 작업 완료 여부
- [ ] 증적 수집 진행률: ___%
- [ ] 결함 보완 현황: 잔여 __건
- [ ] 다음 주 주요 작업:
- [ ] 블로커/이슈:
```

### 4.2 현장 심사 당일 체크

```markdown
## 현장 심사 D-Day 체크리스트

- [ ] 심사 장소 준비 (프로젝터, 네트워크, 다과)
- [ ] 증적 USB/노트북 준비
- [ ] 시스템 접속 계정 준비 (심사원용 읽기 전용)
- [ ] 담당자 연락처 공유
- [ ] 착수 회의 자료 준비
- [ ] 종료 회의 후 결함 수령 확인
```
