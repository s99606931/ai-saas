## 1. 대응 원칙

### 1.1 기본 원칙

1. **즉시 답변 원칙**: 증적을 즉시 제시할 수 있도록 사전 준비
2. **정확성 원칙**: 모르면 "확인 후 답변드리겠습니다" (거짓 답변 절대 금지)
3. **과잉 답변 금지**: 질문 범위 내에서만 답변 (불필요한 정보 노출 방지)
4. **문서 기반 답변**: 구두 설명보다 문서/증적 기반 답변 우선

### 1.2 답변 유형별 전략

| 질문 유형 | 대응 전략 | 예시 |
|---------|---------|------|
| 존재 확인 | 문서/시스템 즉시 제시 | "정책서를 보여주세요" -> 정책서 제시 |
| 운영 확인 | 로그/기록 제시 | "교육 실적은?" -> 교육 출석부 제시 |
| 기술 확인 | 시스템 시연 | "암호화 설정은?" -> 설정 화면 시연 |
| 이해도 확인 | 담당자가 직접 설명 | "RBAC란?" -> 담당자 설명 |

## 2. 관리체계 수립 및 운영 (Q1~Q16)

### 2.1 관리체계 기반 마련 (Q1~Q4)

**Q1: 경영진이 정보보호에 어떻게 참여하고 있습니까?** (1.1.1)
- **답변 방향**: 정보보호 정책서에 경영진 승인 서명, 정기 보고 회의록 제시
- **증적**: 정보보호정책서 (경영진 서명), 경영진 보고 회의록
- **프레임워크 참조**: `docs/framework/01-security-policy/` 정책서

**Q2: 정보보호 최고책임자(CISO)는 누구이며 임명 근거는?** (1.1.2)
- **답변 방향**: CISO 임명장 + 조직도상 위치 + 전문성 증빙
- **증적**: CISO 임명장, 조직도, 이력서
- **CSAP 재활용**: D02-02 증적 직접 제출

**Q3: 정보보호 전담 조직은 어떻게 구성되어 있습니까?** (1.1.3)
- **답변 방향**: 조직도 + 역할/책임 매트릭스 + 인원 현황
- **증적**: 정보보호 조직도, R&R 매트릭스
- **CSAP 재활용**: D02-01 증적 직접 제출

**Q4: 인증 범위는 어떻게 설정하였습니까?** (1.1.4)
- **답변 방향**: 범위 정의서 (시스템/서비스/조직/물리적 범위 명시)
- **증적**: 인증 범위 정의서
- **프레임워크 참조**: 신규 작성 필요 (템플릿 제공)

### 2.2 위험 관리 (Q5~Q8)

**Q5: 정보자산은 어떻게 식별하고 관리합니까?** (1.2.1)
- **답변 방향**: 자산 식별 절차 + 자산 목록 (유형/중요도/관리자)
- **증적**: 자산 식별 가이드, 자산 목록
- **CSAP 재활용**: D04-01 증적

**Q6: 데이터 흐름은 어떻게 분석하였습니까?** (1.2.2)
- **답변 방향**: 시스템 간 데이터 흐름도 + 개인정보 흐름도
- **증적**: 데이터 흐름도 (시스템 아키텍처 기반)
- **프레임워크 참조**: 아키텍처 문서 기반 작성

**Q7: 위험 평가는 어떤 방법론으로 수행하였습니까?** (1.2.3)
- **답변 방향**: 위험 평가 방법론 (자산x위협x취약점) + 위험 등급 기준
- **증적**: 위험 분석 보고서
- **CSAP 부분 재활용**: D04-02 + 추가 상세 분석

**Q8: 보호대책은 어떤 기준으로 선정하였습니까?** (1.2.4)
- **답변 방향**: 위험 수준별 보호대책 선정 근거 + 잔여 위험 수용 기준
- **증적**: 보호대책 선정 근거서
- **프레임워크 참조**: 신규 작성 필요 (템플릿 제공)

### 2.3 관리체계 운영 (Q9~Q12)

**Q9: 보호대책은 어떻게 구현되어 있습니까?** (1.3.1)
- **답변 방향**: 시큐어코딩 규칙 + 보안 설정 기준 + 구현 현황
- **증적**: 시큐어코딩 정책, 보안 설정 가이드
- **CSAP 재활용**: D12-01 증적

**Q10: 정보보호 정책이 조직 내에 공유되고 있습니까?** (1.3.2)
- **답변 방향**: 정책 공표 절차 + 공표 이력 + 인지 확인
- **증적**: 정책 공표 이력, 직원 서명
- **CSAP 재활용**: D01-02 증적

**Q11: 운영 현황을 어떻게 관리하고 있습니까?** (1.3.3)
- **답변 방향**: 보안 대시보드 + 정기 모니터링 + 이상 탐지
- **증적**: 모니터링 대시보드 스크린샷, 정기 보고서
- **프레임워크 참조**: security-monitor-service

**Q12: 관련 법령 준수를 어떻게 검토하고 있습니까?** (1.3.4)
- **답변 방향**: 법령 인덱스 + 정기 검토 일정 + 변경 추적
- **증적**: 법령 인덱스, 법령 검토 회의록
- **CSAP 재활용**: D01-04 증적

### 2.4 관리체계 점검 및 개선 (Q13~Q16)

**Q13: 법적 요구사항 준수를 정기적으로 검토합니까?** (1.4.1)
- **답변 방향**: 분기/반기별 검토 일정 + 검토 결과
- **CSAP 재활용**: D01-03 증적

**Q14: 관리체계 내부 점검은 어떻게 수행합니까?** (1.4.2)
- **답변 방향**: 내부 감사 절차서 + 감사 결과 보고서
- **증적**: 내부 감사 절차서 (신규)

**Q15: 발견된 결함의 개선 절차는?** (1.4.3)
- **답변 방향**: 결함 등록 -> 분석 -> 보완 -> 검증 절차
- **증적**: 개선 조치 계획서 (신규)

**Q16: 경영진에게 정기적으로 보고합니까?** (1.4.4)
- **답변 방향**: 분기/반기별 보고 일정 + 보고서 양식
- **증적**: 경영진 보고 양식 (신규)

**Q19: 정보자산 관리 절차는?** (2.1.3)

## 4. 개인정보 처리단계별 요구사항 (Q81~Q101)

### 4.1 개인정보 수집 (Q81~Q86)

**Q81: 개인정보 수집 시 동의 절차는?** (3.1.1)
- **답변**: 명시적 동의 화면 + 동의 내용 기록 + 철회 기능
- **증적**: 동의 화면 스크린샷, 동의 로그

**Q82: 개인정보 수집 목적은 명확합니까?** (3.1.2)
- **답변**: 수집 항목별 목적 명시 + 개인정보처리방침에 고지
- **증적**: 개인정보처리방침

**Q83: 주민등록번호 처리 제한은?** (3.1.3)
- **답변**: 주민등록번호 수집하지 않음 (법적 근거 없음)
- **증적**: 시스템 입력 필드 확인

**Q84: 민감정보/고유식별정보 처리는?** (3.1.4~5)
- **답변**: 해당 시 별도 동의 + 암호화 저장
- **증적**: 암호화 설정 확인

**Q85: 간접 수집 시 고지는?** (3.1.6)
- **답변**: 해당 시 수집 출처 + 처리 목적 고지
- **증적**: 고지 화면/문서

**Q86: 영상정보처리기기 운영은?** (3.1.7)
- **답변**: SaaS 서비스에서 영상 처리 없음 (해당 없음)

### 4.2 개인정보 이용 및 제공 (Q87~Q92)

**Q87: 개인정보 이용 제한은?** (3.2.1)
- **답변**: 수집 목적 범위 내에서만 이용 + 목적 외 이용 금지
- **증적**: 접근 통제 정책, API 레벨 데이터 접근 제어

**Q88: 개인정보 제3자 제공 절차는?** (3.2.2)
- **답변**: 제공 시 정보주체 동의 + 제공 기록 관리
- **증적**: 제3자 제공 동의서, 제공 기록

**Q89: 개인정보 처리 위탁은?** (3.2.3)
- **답변**: 위탁 계약서 + 수탁자 관리감독
- **증적**: 위탁 계약서, 관리감독 기록

**Q90: 개인정보 국외 이전은?** (3.2.4)
- **답변**: 국외 이전 없음 (온프레미스/국내 클라우드 전용)
- **증적**: 시스템 구성도 (국내 소재 확인)

**Q91~Q92: 기타 이용/제공**
- **답변 방향**: 마케팅 활용 동의, 추가 동의 절차

### 4.3 개인정보 보관 및 파기 (Q93~Q97)

**Q93: 개인정보 보유 기간은?** (3.3.1)
- **답변**: 목적 달성 시 즉시 파기 + 법적 보존 기간 준수
- **증적**: 개인정보 보유 기간표

**Q94: 개인정보 파기 절차는?** (3.3.2)
- **답변**: 소프트 삭제(30일) -> 하드 삭제 + 파기 기록
- **프레임워크 참조**: user-service 소프트 삭제 구현

**Q95: 개인정보 파기 방법은?** (3.3.3)
- **답변**: DB 완전 삭제 + 암호화 키 폐기 + 백업 데이터 파기
- **증적**: 파기 절차서, 파기 기록

**Q96~Q97: 기타 보관/파기**
- **답변 방향**: 분리 보관 절차, 임시 파일 관리

### 4.4 정보주체 권리 보장 (Q98~Q101)

## 5. 공통 대응 원칙

### 5.1 심사 당일 행동 수칙

1. 심사원 질문에 **경청** 후 정확히 답변
2. 증적은 **미리 태블릿/노트북에 정리**하여 즉시 제시
3. **담당자가 직접 답변** (대리 답변 지양)
4. 모르는 질문: "해당 담당자에게 확인 후 __(시간) 내 답변드리겠습니다"
5. 심사원 지적사항은 **메모 후 즉시 보완 계획 수립**

### 5.2 심사원 질문 유형별 대응

| 유형 | 특징 | 대응법 |
|------|------|--------|
| 직접 질문 | "~가 있습니까?" | 있으면 제시, 없으면 인정 후 보완 계획 |
| 확인 질문 | "~를 보여주세요" | 즉시 시연/제시 |
| 시나리오 질문 | "~상황에서 어떻게?" | 절차서 기반 단계별 설명 |
| 함정 질문 | 관련 없는 영역 유도 | 인증 범위 내에서만 답변 |
