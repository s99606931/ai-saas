# ISMS-P 개인정보 처리단계별 보호조치: I-08~I-14 처리 단계

> MTU-C6b | FR-2.4-I | 적용 기준일: 2026-04-05
> 참조: 개인정보 보호법 제29조~제33조

---

## 개요

ISMS-P 개인정보 생명주기 중 처리(이용·제공·위탁) 단계 7개 항목입니다.
개인정보 처리 기록, 접근 권한 관리, 암호화, 수탁자 관리 등을 구현합니다.

---

## 항목별 구현 가이드

### ISMS-P-I-08: 개인정보 처리 기록

| 항목 | 내용 |
|------|------|
| ID | ISMS-P-I-08 |
| 요구사항 | 개인정보 처리 내역 기록 |
| 핵심 요건 | 처리 목적·항목·기간·방법 기록, 6개월 이상 보관, audit.jsonl 자동 기록 |
| CSAP 중첩 | CSAP-D06-01 (감사 로그 생성) 부분 연계 |

**구현 패턴**:
```typescript
// 개인정보 처리 시 자동 감사 로그
async function processPersonalData(
  processor: User, subjectId: string, action: string, fields: string[]
): Promise<void> {
  await auditLog({
    actor: processor.id,
    action: 'PERSONAL_DATA_ACCESS',
    target: subjectId,
    details: { action, fields, purpose: processor.assignedPurpose },
    ismsPIControls: ['ISMS-P-I-08'],
    csapControls: ['CSAP-D06-01'],
    result: 'SUCCESS',
  })
}
```

| 항목 | 내용 |
|------|------|
| ID | ISMS-P-I-10 |
