## 1. 개요

### 1.1 ISMS-P 인증 유효 기간

- **유효 기간**: 인증서 발급일로부터 3년
- **사후심사**: 매년 1회 의무 (인증 유효기간 내)
- **갱신심사**: 인증 만료 6개월 전 신청 필수
- **인증 실효**: 사후심사 미이행 또는 갱신 미신청 시 인증 자동 실효

### 1.2 인증 주기 흐름

```
연도 1          연도 2          연도 3          갱신
├─────────────┼─────────────┼─────────────┤
│ 최초 인증    │ 사후심사 1   │ 사후심사 2   │ 갱신심사
│ (본 심사)    │ (연간 점검)  │ (연간 점검)  │ (만료 전)
└─────────────┴─────────────┴─────────────┘
     D+0          +12개월       +24개월       +30개월
```

## 2. 갱신 D-Day 카운트다운 체크리스트

### D-180: 갱신 준비 착수

- [ ] 갱신 준비 TF팀 구성 (CISO + 보안담당 + 개발팀 + CPO)
- [ ] 인증 유효기간 및 갱신 기한 확인
- [ ] 전회 심사 결함 보완 이행 현황 확인
- [ ] 인증 범위 변경 사항 확인 (변경 시 사전 신고)
- [ ] 갱신 예산 확보 (심사 비용 + 보완 비용)

### D-150: 자가진단 착수

- [ ] 101항목 자가진단 착수 (체크리스트 기반)
- [ ] 전년도 사후심사 결함 보완 완료 확인
- [ ] 관리체계 문서 최신화 확인 (정책/조직/절차)
- [ ] 위험 평가 갱신 (자산 변경/신규 위협 반영)

### D-120: 증적 수집 80% 달성

- [ ] 관리체계 16항목 증적 갱신/수집 (80%)
- [ ] 보호대책 64항목 증적 갱신/수집 (80%)
- [ ] 개인정보 21항목 증적 갱신/수집 (80%)
- [ ] CSAP 공유 증적 최신성 확인 (36항목)
- [ ] 부분 중복 9항목 보완 증적 확인

### D-90: 갱신 심사 신청

- [ ] 자가진단 완료 (101항목 전수)
- [ ] 결함 목록 확정 및 보완 계획 수립
- [ ] 인증기관에 갱신 심사 신청서 제출
- [ ] 심사 비용 납부 + 계약 체결
- [ ] 심사 일정 1차 협의

### D-60: 결함 보완 + 모의 심사

- [ ] 자가진단 결함 전수 보완 완료
- [ ] 증적 패키지 100% 완성
- [ ] 내부 모의 심사 실시 (심사원 역할 배정)
- [ ] 모의 심사 결함 보완
- [ ] 증적 인쇄물/디지털 패키지 최종 점검

### D-30: 서류 제출 + 현장 준비

- [ ] 갱신 심사 증적 패키지 제출
- [ ] 서류 심사 대응 (인증기관 질의 응답)
- [ ] 현장 심사 장소 확보 (회의실 3~5일)
- [ ] 심사 대응 인원 배정표 확정
- [ ] 시스템 시연 준비 (리허설)

### D-14: 최종 점검

- [ ] 현장 심사 일정 최종 확정
- [ ] 담당자 연락처 심사팀에 공유
- [ ] 심사 당일 장소/장비 최종 점검
- [ ] 증적 최종 검증 (누락 항목 확인)
- [ ] 심사원 대응 Q&A 리뷰

### D-7: 리허설

- [ ] 시스템 시연 최종 리허설
- [ ] 주요 질문 모의 응답 연습
- [ ] 긴급 연락 체계 확인

### D-0: 갱신 현장 심사 (2~3일)

- [ ] 착수 회의 참석 (CISO + 경영진)
- [ ] 영역별 심사 대응 (담당자별)
- [ ] 결함 통보 수령 (종료 회의)
- [ ] 결함 보완 기한 확인

### D+14: 결함 보완

- [ ] 결함 보완 계획서 제출 (3일 이내)
- [ ] 결함 보완 실행 (14일 이내)
- [ ] 보완 결과 보고서 제출
- [ ] 인증기관 확인 완료

### D+30: 갱신 인증서 발급

- [ ] 인증위원회 심의 통과
- [ ] 갱신 인증서 발급 확인
- [ ] 인증 마크 갱신 (유효기간 업데이트)
- [ ] 다음 3년 주기 리마인더 설정

## 5. 예외 상황 대응

### 5.1 갱신 기한 임박 (D-30 미만)

1. 인증기관에 긴급 심사 요청
2. 최소 증적으로 서류 심사 선 제출
3. 현장 심사 일정 최대한 조기 확보
4. 결함 보완 기간 활용하여 누락 증적 보완

### 5.2 인증 범위 대폭 변경

1. 변경 사유 발생 즉시 인증기관 사전 신고 (30일 이내)
2. 변경 영향도 분석 (추가 심사 필요 여부)
3. 필요 시 변경 심사 별도 수행
4. 증적 전면 재정비

### 5.3 인증기관 변경

1. 기존 인증기관과 계약 종료 절차
2. 신규 인증기관 선정 및 계약
3. 기존 증적 인수인계 (인증 이력 연속성)
4. 신규 인증기관 기준에 맞춘 증적 재정비
