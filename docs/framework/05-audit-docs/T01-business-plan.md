## 8. 품질 보증 계획

> **작성 지침**: 산출물 검토 절차와 Q-Gate 기준을 명시합니다.

### 8.1 산출물 검토 절차

```
산출물 작성 → 자체 검토(작성자) → 동료 검토(리뷰어) → 품질 승인(PM) → 감리 제출
```

### 8.2 Q-Gate 기준 (CC 하네스)

| Gate | 명칭 | 통과 기준 | 시점 |
|------|------|---------|------|
| G1 | 요구사항 FR ID 전수 | 모든 산출물에 FR-X.Y ID 매핑 | 각 Phase 완료 시 |
| G2 | 설계 완전성 | Plan + Design 문서 완비 | 구현 착수 전 |
| G3 | 코드 품질 | 정적분석 102규칙 통과 | 코드 리뷰 시 |
| G4 | 테스트 커버리지 80%+ | 단위/통합 테스트 커버리지 | 개발 완료 시 |
| G5 | OWASP Top 10 통과 | 보안 취약점 10항목 점검 | 보안 검증 시 |
| G6 | CSAP Phase 100% | 해당 Phase CSAP 항목 전수 | Phase 완료 시 |
| G7 | 감사 추적 완비 | audit.jsonl 필수 이벤트 전수 | 최종 감리 전 |
