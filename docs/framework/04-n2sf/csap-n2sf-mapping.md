## 목적

CSAP 표준등급 79개 통제항목과 N2SF(국가사이버안전관리규정) 6개 보안 영역 간 전수 매핑을 제공합니다.
이 매핑은 **CSAP 인증과 N2SF 준수를 동시에 달성**하기 위한 통합 관점을 제시합니다.

---

## N2SF 6개 보안 영역 개요

| 영역 코드 | 영역명 | 설명 | 핵심 통제 |
|---------|--------|------|---------|
| **N01** | 관리적 보안 | 정보보호 정책, 조직, 교육 | 정책 수립, 조직 구성, 인력 관리 |
| **N02** | 인증 | 사용자 식별, 인증, 접근 통제 | RBAC, MFA, 세션 관리 |
| **N03** | 격리 | 네트워크 분리, 시스템 격리 | 세그멘테이션, 방화벽, 가상화 격리 |
| **N04** | 암호화 | 데이터 암호화, 키 관리 | AES-256, TLS, 키 수명 주기 |
| **N05** | 데이터 | 데이터 분류, 처리, 폐기 | C/S/O 등급 분류, 국내 저장, 데이터 주권 |
| **N06** | 운영 | 취약점 관리, 감사, 복구 | 패치, 로그, 사고 대응, 재해 복구 |
