## 1. 영역 개요

N01 관리적 보안은 N2SF 6개 보안 영역의 최상위 거버넌스 계층입니다.
정보보호 정책 수립, 보안 조직 구성, 교육 훈련, 사고 보고 체계를 포함하며,
CSAP D01(정보보호 정책), D02(조직 보안), D03(인적 보안) 분야와 직접 대응됩니다.

### 핵심 원칙

- **정책 우선**: 기술 통제보다 정책 수립이 선행
- **경영진 참여**: 정보보호 정책은 경영진 승인·서명 필수
- **증적 기반**: "정책이 있는가?"뿐 아니라 "운영 증적이 있는가?" 확인

## 2. C/S/O 등급별 통제 요건

| 통제 항목 | C 등급 (기밀) | S 등급 (민감) | O 등급 (공개) |
|---------|-------------|-------------|-------------|
| 정보보호 정책 수립 | 연 2회 검토 + 경영진 서명 | 연 1회 검토 + 경영진 승인 | 수립 확인 |
| 정보보호 조직 구성 | 전담 조직 필수 (CISO 직속) | 겸직 조직 허용 (담당자 지정) | 담당자 1인 이상 지정 |
| 보안 교육 | 분기별 필수 교육 + 평가 시험 | 반기별 필수 교육 | 연 1회 교육 |
| 보안 서약서 | 입사 시 + 연 1회 갱신 | 입사 시 + 직무 변경 시 | 입사 시 1회 |
| 인력 변동 관리 | 퇴직 즉시 접근 권한 회수 + 24시간 이내 전수 감사 | 퇴직 즉시 접근 권한 회수 | 퇴직 시 접근 권한 회수 |
| 보안 사고 보고 | 1시간 이내 보고 (CISO + 경영진) | 4시간 이내 보고 | 24시간 이내 보고 |
| 외부 인력 관리 | 전담 보안 교육 + 접근 범위 제한 + NDA | 보안 교육 + NDA | NDA 체결 |

## 4. 구현 가이드

### 4.1 정보보호 정책서 작성 요령

```
정보보호 정책서 구성 (최소 필수)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 목적 및 적용 범위
2. 용어 정의
3. 정보보호 원칙 (기밀성·무결성·가용성)
4. 조직과 역할
5. 정보 자산 분류 및 관리
6. 접근 통제 정책
7. 암호화 정책
8. 사고 대응 정책
9. 교육 및 인식 제고
10. 위반 시 제재
11. 정책 검토 주기 및 절차
12. 승인 및 시행일

[부록] CSAP 통제항목 매핑 테이블
[부록] N2SF 보안 영역 매핑 테이블
```

### 4.2 보안 교육 프로그램 설계

| 교육 구분 | 대상 | 주기 | 내용 | 평가 |
|---------|------|------|------|------|
| 신규 입사자 | 전 직원 | 입사 시 | 정보보호 정책, 보안 서약, 기본 보안 수칙 | 퀴즈 |
| 정기 교육 | 전 직원 | 등급별 상이 | 최신 보안 위협, 정책 변경 사항, 사례 학습 | 평가 시험 |
| 전문 교육 | IT/보안 담당 | 분기별 | CSAP 통제항목, N2SF 영역별 기술 구현 | 실습 평가 |
| 사고 대응 훈련 | 사고 대응팀 | 반기별 | 모의 침해사고 대응 훈련 (테이블탑 연습) | 대응 시간 측정 |

### 4.3 보안 사고 보고 체계

```
사고 발생
    │
    ▼
┌─────────────────────────────┐
│ 1차 보고 (발견자 → 담당자)    │
│ C등급: 즉시 / S등급: 1시간   │
│ O등급: 4시간                 │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 2차 보고 (담당자 → CISO)     │
│ C등급: 1시간 / S등급: 4시간  │
│ O등급: 24시간                │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 3차 보고 (CISO → 경영진)     │
│ + 국정원 / KISA 신고 (의무)  │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│ 사후 조치                    │
│ - 원인 분석 보고서            │
│ - 재발 방지 대책              │
│ - audit.jsonl 기록            │
└─────────────────────────────┘
```
