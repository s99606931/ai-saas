## 목적

프레임워크에서 사용하는 6가지 문서 유형의 구조와 작성 지침을 정의합니다. 새 문서를 작성할 때 아래 유형 중 가장 적합한 것을 선택하고, 해당 빈 템플릿을 복사하여 시작하세요.

---

## 유형 선택 가이드

| 문서 내용 | 선택할 유형 |
|---------|-----------|
| 항목별 점검이 필요한 경우 | **유형 1: 체크리스트형** |
| 단계별 구축/설치 절차 | **유형 2: 구현 가이드형** |
| 업무 처리 절차 정의 | **유형 3: 절차서형** |
| 시스템 구조/설계 설명 | **유형 4: 아키텍처 레퍼런스형** |
| 감리 제출 산출물 | **유형 5: 감리 템플릿형** |
| 항목 간 대응 관계 정�� | **유형 6: 매핑 테이블형** |

## 유형 1: 체크리스트형 (Checklist)

**적용 파일 예시**: `checklist-simple.md`, `review-checklist.md`, ISMS-P 체크리스트

### 빈 템플릿

```markdown
# [문서명]

| 항목 | 내용 |
|------|------|
| 문서 ID | [예: CHK-001] |
| 버전 | [예: 1.0.0] |
| 작성일 | [YYYY-MM-DD] |
| CSAP 연관 항목 | [예: CSAP-D08-03] |

---

[체크리스트 사용 목적, 대상 독자, 사용 시나리오]

---

## 체크리스트

| # | 항목 | 확인 방법 | 증거 자료 | 필수 | 확인 |
|---|------|---------|---------|------|------|
| 1 | [항목 설명] | [구체적 확인 방법] | [필요 증거] | 필수 | ☐ |
| 2 | [항목 설명] | [구체적 확인 방법] | [필요 증거] | 필수 | ☐ |

[전수 통과 조건, 조건부 통과 기준]

---

## 변경 이력

| 버전 | 일자 | 내용 | 작성자 |
|------|------|------|--------|
```

### 작성 지침

- 각 항목에 **확인 방법**과 **증거 자료**를 반드시 명시
- 항목 ID는 해당 규정 ID를 사용 (예: CSAP-D08-01)
- 합격 기준에 정량적 통과 조건 명시 (예: 30/30 통과)

## 유형 6: 매핑 테이블형 (Mapping Table)

**적용 파일 예시**: CSAP 마스터 체크리스트, CSAP-N2SF 매핑, 추적성 매트릭스

### 빈 템플릿

```markdown
# [문서명] 매핑 테이블

| 항목 | 내용 |
|------|------|
| 문서 ID | [예: MAP-001] |
| 버전 | [예: 1.0.0] |
| 작성일 | [YYYY-MM-DD] |
| 추적성 방향 | [예: CSAP -> N2SF] |
| 매핑 완결 기준 | [예: 공백 0개] |

---

## 매핑 원칙

- 공백(미매핑) = 감리 결함 처리
- 1:N 매핑 허용 (하나의 출발 항목이 여러 도착 항목에 매핑)
- N:1 매핑 허용 (여러 출발 항목이 하나의 도착 항목에 매핑)

---

## 매핑 테이블

| 출발 ID | 출발 항목명 | 도착 ID | 도착 항목명 | 매핑 유형 | 비고 |
|---------|-----------|--------|-----------|---------|------|
| [ID] | [항목명] | [ID] | [항목명] | [1:1/1:N/N:1] | [비고] |

---

## 미매핑 항목 목록

| 미매핑 ID | 항목명 | 미매핑 사유 | 조치 계획 |
|---------|--------|---------|---------|
| [ID] | [항목명] | [사유] | [조치] |

---

## 변경 이력

| 버전 | 일자 | 내용 | 작성자 |
|------|------|------|--------|
```

### 작성 지침

- 매핑 완결 기준 명시 (미매핑 0개 목표)
- 미매핑 항목은 반드시 사유와 조치 계획 기록
- 매핑 유형(1:1, 1:N, N:1) 명시
