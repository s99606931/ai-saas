# 프레임워크 버전 관리 가이드

> MTU-E3 | FR-8.6 | 적용 기준일: 2026-04-05
> 참조: MTU-A7 (N2SF 모니터링), CLAUDE.md 절대 제약

---

## 1. 개요

공공기관 SaaS 프레임워크의 시맨틱 버저닝 체계와 CHANGELOG 관리 기준입니다.
CSAP/N2SF/ISMS-P 규정 변경이 기존 인증에 미치는 영향을 체계적으로 관리합니다.

---

## 2. 시맨틱 버저닝 체계

```
vMAJOR.MINOR.PATCH

MAJOR: 규정 개정으로 하위 호환 불가
  예) CSAP 79항목 → 85항목, N2SF 등급 체계 변경
  영향: 기존 인증 재심사 필요 여부 사전 안내

MINOR: 신규 기능 추가, 하위 호환 유지
  예) 새 가이드 문서, 새 MTU 추가
  영향: 기존 인증 무영향

PATCH: 오류 수정, 설명 보완
  예) 체크리스트 오류, 코드 버그 수정
  영향: 기존 인증 무영향
```

---

## 3. 변경 분류 기준

| 분류 | 트리거 | 인증 영향 | 승인 | SLA |
|------|--------|---------|------|------|
| MAJOR | 규정 기준 개정 (항목 추가/삭제) | 재심사 검토 필요 | CTO 승인 | 30일 |
| MINOR | 신규 가이드/기능 추가 | 없음 | 팀장 승인 | 14일 |
| PATCH | 오류/오탈자 수정 | 없음 | 자동 병합 가능 | 3일 |

## 4. CHANGELOG 관리 기준

### 4.1 CHANGELOG 형식 (Keep a Changelog 기반)

```markdown
# Changelog

## [vX.Y.Z] - YYYY-MM-DD

### Added (추가)
- 새 MTU 또는 산출물 파일

### Changed (변경)
- 기존 문서 내용 변경 (영향 분석 결과 포함)

### Deprecated (폐기 예정)
- 다음 MAJOR에서 제거 예정 항목

### Removed (제거)
- 삭제된 항목 (MAJOR 변경 시에만)

### Fixed (수정)
- 오류 수정

### Security (보안)
- 보안 관련 변경사항
```

### 4.2 규정 변경 연계 기록

```markdown
### Changed
- CSAP-D08-03 → CSAP-D08-03a/b 분할 (CSAP 2026-Q3 개정 반영)
  - 규정 출처: KISA 고시 제2026-XX호
  - 탐지일: 2026-07-15 (MTU-A7)
  - 영향 분석: D-08 접근 통제 분야 1항목 추가 → 총 80항목
  - 인증 영향: MINOR (기존 D-08-03 하위 호환)
```

## 5. 버전 릴리스 절차

### 5.1 PATCH 릴리스

```
오류 발견 → PR 생성 → Reviewer 검증 → 자동 병합 → Git 태그 생성
```

### 5.2 MINOR 릴리스

```
신규 기능 설계 → 구현 → Reviewer → Auditor (G6 선택) → 병합 → Git 태그
```

### 5.3 MAJOR 릴리스

```
규정 변경 탐지 (MTU-A7)
  → CTO 영향 분석 승인
  → 설계 문서 작성
  → 구현 (Plan → Design → Do)
  → Reviewer + Auditor 전수 검증
  → Q-Gate G1~G7 통과
  → Git 태그 생성 (vX.0.0-pre-upgrade 포함)
  → 사용 기관 알림 (3개월 준비 기간)
  → 단계적 배포
```

## 6. 인증 영향 불변 원칙

| 원칙 | 설명 |
|------|------|
| 불변 증적 보존 | 기존 audit.jsonl 및 CSAP 증적 수정 금지 |
| 버전 격리 문서 | 각 산출물 "적용 기준일: YYYY-MM-DD" 메타데이터 필수 |

| 롤백 포인트 | MAJOR/MINOR 배포 전 Git 태그 필수 |
