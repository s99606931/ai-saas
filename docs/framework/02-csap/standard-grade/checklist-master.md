## 목적

CSAP 표준등급 인증을 위한 13개 분야 79개 통제항목 전수를 기계 판독 가능한 형식으로 정의합니다. 이 파일은 프레임워크 전체의 **보안 요건 원천 레이어(Single Source of Truth)**입니다.

**후속 MTU 참조 관계**:
- MTU-C2a/C2b/C3: 구현 가이드 (D01~D13 항목별 구현 예시)
- MTU-C4: N2SF 등급 매핑 (79항목 x 6영역)
- MTU-C6a: ISMS-P 교차 참조
- MTU-A4: OSCAL 호환성 레이어 (기계가독형 변환)
- MTU-A6: 준수 현황 대시보드

---

## 사용 방법

1. 각 분야별 테이블에서 항목의 "확인 방법"을 따라 현재 상태를 확인합니다
2. 충족 시 확인란에 체크(v)를 표시합니다
3. 미충족 시 비고란에 미비 사유와 개선 계획을 기록합니다
4. 전체 완료 후 하단의 "자가진단 결과 요약"을 작성합니다
5. 후속 MTU에서 특정 항목을 참조할 때는 `#csap-dxx-yy` 앵커를 사용합니다

**OSCAL 변환**: MTU-A4에서 이 파일의 테이블을 자동 파싱하여 OSCAL XML/JSON으로 변환합니다. 테이블 형식을 임의로 변경하지 마십시오.
