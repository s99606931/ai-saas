## 분야 개요

정보보호 정책은 CSAP 인증의 **최상위 관리 통제**입니다. 경영진이 승인한 정보보호 정책서를 기반으로 조직 전체의 보안 활동이 수행됩니다. 심사 시 정책서의 존재, 승인, 공표, 정기 검토, 법령 반영을 확인합니다.

**핵심 키워드**: 정책서 수립, 경영진 승인, 공표, 정기 검토, 법령 준수

## CSAP-D01-01: 정보보호 정책 수립

> **중요도**: 상 | **구분**: 필수

### 구현 목표

조직의 정보보호 방침과 원칙을 담은 정보보호 정책서를 수립하고 경영진의 승인을 받는다.

### 구현 방법

**단계 1: 정책서 초안 작성**

정보보호 정책서에 포함해야 할 필수 항목:

| 섹션 | 필수 내용 |
|------|---------|
| 목적 | 정보보호의 목적과 적용 범위 |
| 적용 범위 | 대상 시스템, 데이터, 인력 |
| 용어 정의 | 핵심 보안 용어 |
| 정보보호 원칙 | 기밀성, 무결성, 가용성 원칙 |
| 역할과 책임 | CISO, 보안담당자, 사용자 역할 |
| 위반 시 조치 | 보안 정책 위반 시 제재 사항 |
| 검토 주기 | 연 1회 이상 정기 검토 |
| 시행일 | 정책 시행 시작일 |

**단계 2: 경영진 검토 및 승인**

- 정보보호위원회 또는 경영회의에서 검토
- 대표이사(또는 기관장) 서명 승인
- 승인 일자 기록

**단계 3: 문서 관리**

- 버전 관리 (변경 이력 기록)
- 원본 보관 (문서관리시스템 또는 승인 서류함)

### 필요 증거 자료

| 증거 | 형태 | 보관 위치 |
|------|------|---------|
| 정보보호 정책서 (최종 승인본) | PDF/문서 | 문서관리시스템 |
| 경영진 승인 문서 (서명본) | 스캔/원본 | 승인 서류함 |
| 정책서 변경 이력 | 표 | 정책서 내 부록 |

### 샘플 템플릿: 정보보호 정책서 (발췌)

```
==============================================
[기관명] 정보보호 정책서
==============================================

버전: 1.0
시행일: 20XX년 XX월 XX일
승인자: [대표이사/기관장] (서명)

제1장 총칙
제1조(목적) 본 정책은 [기관명]의 정보자산을 보호하기 위한
  기본 원칙과 방향을 정한다.
제2조(적용 범위) 본 정책은 [기관명]의 모든 정보시스템,
  데이터, 임직원 및 외부 인력에게 적용된다.
제3조(용어 정의)
  1. "정보자산": 조직의 업무 수행에 필요한 모든 정보 및 시스템
  2. "보안 사고": 정보자산의 기밀성, 무결성, 가용성이 침해된 사건

제2장 정보보호 원칙
제4조(기밀성) 인가된 자만 정보에 접근할 수 있도록 통제한다.
제5조(무결성) 정보의 정확성과 완전성을 보장한다.
제6조(가용성) 인가된 자가 필요한 시점에 정보에 접근할 수 있도록 한다.

제3장 역할과 책임
제7조(정보보호 최고책임자) CISO는 정보보호 정책의
  수립·시행·검토를 총괄한다.
제8조(정보보호 담당자) 부서별 보안 담당자를 지정하여
  정보보호 활동을 수행한다.

제4장 위반 시 조치
제9조(위반 처리) 정보보호 정책 위반 시 사내 징계 규정에 따라 처리한다.

제5장 검토 및 개정
제10조(검토 주기) 본 정책은 연 1회 이상 정기 검토한다.
제11조(개정 절차) 정책 변경 시 정보보호위원회 심의를 거쳐
  경영진 승인을 받는다.

부칙
제12조(시행일) 본 정책은 20XX년 XX월 XX일부터 시행한다.

경영진 승인
─────────────────────────────
승인자: _____________ (서명)
직위:  대표이사/기관장
일자:  20XX년 XX월 XX일
─────────────────────────────
```

### 심사 시 주의사항

- 정책서가 "형식적"으로만 존재하면 불합격 판정될 수 있음
- 경영진 서명이 반드시 원본에 존재해야 함
- 최근 법령 개정(예: 2024년 개인정보보호법 개정)이 반영되었는지 확인

## CSAP-D01-02: 정보보호 정책 공표

> **중요도**: 중 | **구분**: 필수

### 구현 목표

수립된 정보보호 정책을 전 임직원에게 공표하고 인지 여부를 확인한다.

### 구현 방법

1. **공표 채널 선정**: 인트라넷 게시, 이메일 발송, 전사 교육
2. **수신 확인**: 정책 수령 확인서 또는 전자 서명
3. **신규 입사자**: 입사 시 정책 안내 및 확인서 징구
4. **정기 재공표**: 정책 개정 시 재공표

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 정책 공표 이력 (일자, 방법, 대상) | 기록 문서 |
| 수신 확인서 (임직원 서명) | 서명본/전자서명 |
| 인트라넷 게시 화면 캡처 | 스크린샷 |

### 심사 시 주의사항

- 단순 게시만으로는 불충분, **수신 확인** 증빙이 핵심
- 외부 인력에게도 공표해야 함

## CSAP-D01-03: 정보보호 정책 검토

> **중요도**: 상 | **구분**: 필수

### 구현 목표

정보보호 정책을 연 1회 이상 정기 검토하고 필요 시 개정한다.

### 구현 방법

1. **연간 검토 일정 수립**: 예) 매년 1월 또는 정보보호위원회 정기회의 시
2. **검토 수행**: 정책 현행화 여부, 법령 변경 사항 반영, 조직 변경 반영
3. **검토 결과 기록**: 회의록 작성 (참석자, 검토 항목, 변경 결정, 서명)
4. **개정 시**: 정책서 버전 업데이트 + 재승인 + 재공표

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 정책 검토 회의록 | 문서 (참석자 서명) |
| 변경 이력서 | 정책서 내 테이블 |
| 정기 검토 일정표 | 연간 계획 |

### 샘플 템플릿: 정책 검토 회의록

```
정보보호 정책 검토 회의록
─────────────────────────────
일시: 20XX년 XX월 XX일 14:00~15:30
장소: 본사 3층 회의실 A
참석자:
  - [CISO] 홍길동 (서명: _________)
  - [보안담당] 김보안 (서명: _________)
  - [IT운영] 이시스 (서명: _________)

검토 항목:
1. 정보보호 정책서 v1.2 현행화 여부 → 적정
2. 2024년 개인정보보호법 개정 반영 → 제3조 수정 필요
3. 조직 개편 반영 (보안팀 신설) → 제7조 수정 필요

결정 사항:
- 정책서 v1.3으로 개정 (제3조, 제7조)
- 20XX년 2월 말까지 개정 완료 후 재승인

다음 검토 예정일: 20XX+1년 1월
─────────────────────────────
```

## CSAP-D01-04: 관련 법령 준수

> **중요도**: 상 | **구분**: 필수

### 구현 목표

정보보호 관련 법령을 목록으로 관리하고, 법령 변경 시 정책에 반영하는 절차를 수립한다.

### 구현 방법

1. **법령 목록 관리**: 관련 법령 + 시행일 + 주요 내용 + 정책 반영 여부
2. **법령 변경 모니터링**: 국가법령정보센터(law.go.kr) 정기 확인
3. **변경 시 반영 절차**: 법령 변경 -> 영향 분석 -> 정책 개정 -> 재승인

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 법령 준수 매트릭스 | 테이블 문서 |
| 법령 변경 모니터링 기록 | 이력 문서 |
