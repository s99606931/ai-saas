## 분야 개요

인적 보안은 **사람으로 인한 보안 위협**을 관리하는 통제입니다. 입사 시 보안 서약, 정기 교육, 퇴직 시 보안 조치, 외부 인력 관리가 핵심입니다. CSAP 심사에서 교육 이력과 서약서 증빙이 가장 자주 확인됩니다.

**핵심 키워드**: 보안 서약서, 보안 교육, 퇴직 보안, 외부 인력

---

## CSAP-D03-01: 보안 서약서 징구

> **중요도**: 상 | **구분**: 필수

### 구현 목표

모든 임직원에게 입사 시 보안 서약서를 징구하고 관리한다.

### 구현 방법

1. **보안 서약서 양식 준비** (아래 샘플 참조)
2. **징구 시점**: 입사일 + 정보시스템 접근 권한 부여 전
3. **징구 대장 관리**: 서약일, 성명, 소속, 서명 여부 기록
4. **연간 재서약**: 권장 (연 1회 갱신)
5. **원본 보관**: 인사팀 또는 보안팀 (최소 재직 기간 + 3년)

### 샘플 템플릿: 보안 서약서

```
정보보호 서약서
─────────────────────────────
서약 번호: SEC-OATH-20XX-XXX

본인은 [기관명] 소속으로 업무를 수행함에 있어
다음 사항을 준수할 것을 서약합니다.

1. 업무상 취득한 정보를 외부에 유출하지 않겠습니다.
2. 정보보호 정책 및 지침을 성실히 준수하겠습니다.
3. 비인가 정보시스템 접근을 시도하지 않겠습니다.
4. 개인정보를 관련 법령에 따라 안전하게 처리하겠습니다.
5. 보안 사고 인지 시 즉시 보안 담당자에게 보고하겠습니다.
6. 퇴직 후에도 업무상 취득한 비밀을 유지하겠습니다.
7. 위 사항을 위반할 경우 관련 법령 및 사내 규정에 따른
   제재를 감수하겠습니다.

성명: _______________ (서명: ___________)
소속: _______________
직위: _______________
서약일: 20XX년 XX월 XX일
─────────────────────────────
```

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 보안 서약서 양식 | 문서 |
| 징구 대장 (전 임직원) | 테이블 |
| 서명된 서약서 원본 | 스캔/원본 |

## CSAP-D03-02: 정보보호 교육

> **중요도**: 상 | **구분**: 필수

### 구현 목표

연 1회 이상 전 임직원 대상 정보보호 교육을 실시하고 이력을 관리한다.

### 구현 방법

1. **연간 교육 계획 수립**

| 구분 | 대상 | 주기 | 시간 | 내용 |
|------|------|------|------|------|
| 전사 교육 | 전 임직원 | 연 1회 | 2시간 | 정책 안내, 보안 사고 사례, 개인정보보호 |
| 보안 담당자 교육 | 보안 인력 | 반기 1회 | 4시간 | CSAP 요건, 취약점 분석, 사고 대응 |
| 신규 입사자 교육 | 신규 입사자 | 입사 시 | 1시간 | 정책 안내, 서약서, 보안 규칙 |
| 특별 교육 | 사고 관련자 | 수시 | 1시간 | 재발 방지, 위반 사례 |

2. **교육 실시 및 기록**
   - 교육 자료 준비 (PPT, 동영상 등)
   - 참석자 명단 + 서명 (출석부)
   - 교육 평가 (간단한 퀴즈 또는 설문)
   - 수료증 발급 (선택)

3. **교육 이력 관리**

### 샘플 템플릿: 교육 이력 관리 양식

| 교육명 | 일시 | 장소 | 강사 | 참석자 수 | 서명 | 평가 |
|-------|------|------|------|---------|------|------|
| 2026년 1분기 전사 보안 교육 | 2026.03.15 | 대회의실 | 김보안 | 45/50명 | 출석부 | 평균 85점 |
| 신규 입사자 보안 교육 | 2026.02.01 | 교육실 | 이보안 | 5/5명 | 출석부 | - |

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 연간 교육 계획서 | 문서 |
| 교육 자료 (PPT 등) | 파일 |
| 참석자 명단 + 서명 (출석부) | 서명 문서 |
| 수료증 또는 평가 결과 | 문서 |

### 심사 시 주의사항

- "연 1회 이상" 실시 증빙이 핵심 -- 일자와 참석자 수가 중요
- 온라인 교육도 가능하지만 참석 확인 방법 필요 (로그 등)
- 교육 내용이 "일반적인" 것이 아닌 CSAP 관련 내용 포함 여부 확인

## CSAP-D03-03: 퇴직자 보안 조치

> **중요도**: 상 | **구분**: 필수

### 구현 목표

퇴직 시 계정 삭제, 자산 반납, 접근 권한 회수를 체계적으로 수행한다.

### 구현 방법

1. **퇴직 보안 절차서 수립**

```
퇴직 보안 체크리스트
─────────────────────────────
퇴직자: _______________
퇴직일: 20XX년 XX월 XX일
처리자: _______________

☐ 1. 시스템 계정 비활성화/삭제
     - AD/LDAP 계정: ☐
     - 이메일 계정: ☐
     - VPN 접근: ☐
     - 업무 시스템: ☐
     - 클라우드 서비스: ☐

☐ 2. 물리적 접근 권한 회수
     - 출입카드 반납: ☐
     - 사무실 열쇠 반납: ☐
     - 서버실 접근 권한 삭제: ☐

☐ 3. 자산 반납
     - 노트북/PC: ☐
     - 모바일 기기: ☐
     - USB/외장하드: ☐
     - 보안 토큰: ☐

☐ 4. 데이터 처리
     - 업무 데이터 인수인계: ☐
     - 개인 데이터 삭제 확인: ☐
     - 이메일 데이터 백업/삭제: ☐

☐ 5. 비밀유지 서약서 재확인
     - 퇴직 후 비밀유지 서약: ☐

처리 완료 확인:
보안담당자: _____________ (서명: ___________)
인사담당자: _____________ (서명: ___________)
일자: 20XX년 XX월 XX일
─────────────────────────────
```

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 퇴직 보안 절차서 | 문서 |
| 자산 반납 확인서 | 서명 문서 |
| 계정 삭제 이력 (IT 시스템 로그) | 스크린샷/로그 |

## CSAP-D03-04: 외부 인력 보안 관리

> **중요도**: 상 | **구분**: 필수

### 구현 목표

외주/파견 인력에 대한 보안 서약, 접근 권한 제한, 작업 종료 후 권한 회수를 관리한다.

### 구현 방법

1. **외부 인력 보안 지침 수립**
   - 작업 범위 및 접근 권한 명시
   - NDA + 보안 서약서 징구
   - 물리적 접근 제한 (에스코트 또는 별도 구역)
   - 작업 종료 후 즉시 권한 회수

2. **외부 인력 관리 대장**

| 이름 | 소속업체 | 작업 기간 | 접근 범위 | 서약서 | 권한 회수 |
|------|---------|---------|---------|-------|---------|
| 박외주 | A사 | 2026.01~03 | 개발 서버 | 징구 | 완료 |
| 최파견 | B사 | 2026.02~06 | 테스트 환경 | 징구 | - (진행 중) |

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 외부 인력 보안 지침 | 문서 |
| 보안 서약서 (외부 인력용) | 서명 문서 |
| 외부 인력 권한 관리 대장 | 테이블 |
