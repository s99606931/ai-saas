## 분야 개요

조직 보안은 정보보호를 **전담하는 조직과 인력**을 구성하고 역할을 명확히 정의하는 관리 통제입니다. CISO 지정, 보안 조직도, 외부 전문가 활용이 핵심입니다.

**핵심 키워드**: 보안 조직, CISO, 역할 정의, 외부 전문가

---

## CSAP-D02-01: 정보보호 조직 구성

> **중요도**: 상 | **구분**: 필수

### 구현 목표

정보보호 전담 조직 또는 담당자를 지정하고, 조직도에 보안 역할을 명시한다.

### 구현 방법

1. **보안 조직 유형 결정**

| 조직 규모 | 권장 구조 | 최소 요건 |
|---------|---------|---------|
| 대규모 (100명+) | 정보보호팀 독립 부서 | 전담 팀 |
| 중규모 (30~100명) | IT부서 내 보안 담당 | 전담 인력 1명+ |
| 소규모 (30명 미만) | 겸직 보안 담당자 | 겸직 1명 + 외부 자문 |

2. **조직도에 보안 역할 명시**

```
[대표이사/기관장]
  |
[정보보호위원회] --- [외부 자문]
  |
[CISO (정보보호 최고책임자)]
  |
  +-- [보안 운영팀] -- 보안 정책 수립/운영, 사고 대응
  +-- [보안 기술팀] -- 취약점 점검, 보안 솔루션 운영
  |
[각 부서] -- [부서 보안 담당자]
```

3. **임명 절차**: 임명장 발급 + 직무기술서 작성

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 보안 조직도 (최신본) | 문서/이미지 |
| 보안 담당자 임명장 | 서명 문서 |
| 직무기술서 (보안 역할 명시) | 문서 |

### 샘플 템플릿: 보안 담당자 임명장

```
정보보호 담당자 임명장
─────────────────────────────
임명 번호: SEC-APPOINT-20XX-001

성명: _______________
소속: _______________
직위: _______________

위 사람을 [기관명]의 정보보호 담당자로 임명합니다.

임무:
1. 소속 부서의 정보보호 활동 총괄
2. 보안 사고 발생 시 초기 대응 및 보고
3. 정보보호 교육 참석 및 부서 전파
4. 정보보호 정책 이행 점검

임명일: 20XX년 XX월 XX일

[기관명] 대표이사/기관장
(서명: _______________)
─────────────────────────────
```

## CSAP-D02-02: 정보보호 책임 할당

> **중요도**: 상 | **구분**: 필수

### 구현 목표

정보보호 최고책임자(CISO)를 지정하고 각 부서 보안 담당자의 역할과 책임을 정의한다.

### 구현 방법

1. **CISO 지정**
   - 법적 요건: 정보통신망법 제45조의3에 따라 CISO 지정 의무
   - 자격 요건: 정보보호 관련 경력 또는 자격증 보유 권장
   - 임명 절차: 이사회/경영회의 결의 -> 임명장 발급

2. **3계층 역할 정의**

| 계층 | 역할 | 주요 책임 |
|------|------|---------|
| **CISO** | 정보보호 총괄 | 정책 승인, 예산 확보, 경영진 보고 |
| **보안 담당자** | 실무 운영 | 정책 집행, 취약점 관리, 사고 대응 |
| **일반 사용자** | 정책 준수 | 보안 규정 준수, 이상 징후 신고 |

3. **책임 매트릭스 (RACI)**

| 활동 | CISO | 보안담당 | IT운영 | 사용자 |
|------|------|---------|-------|-------|
| 정보보호 정책 수립 | A | R | C | I |
| 보안 사고 대응 | A | R | R | I |
| 취약점 점검 | I | A/R | R | - |
| 보안 교육 | A | R | C | R |
| 접근 권한 관리 | I | A | R | - |

> A=Accountable, R=Responsible, C=Consulted, I=Informed

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| CISO 임명장 (경영진 서명) | 서명 문서 |
| 부서별 보안 담당자 목록 | 테이블 |
| 역할별 책임 매트릭스 (RACI) | 문서 |

## CSAP-D02-03: 외부 전문가 활용

> **중요도**: 중 | **구분**: 권고

### 구현 목표

보안 전문업체의 자문 또는 감사를 활용하여 정보보호 역량을 보강한다.

### 구현 방법

1. **외부 전문가 활용 계획 수립**
   - 연간 보안 컨설팅 계획
   - 모의 해킹/취약점 진단 외주
   - CSAP 인증 컨설팅

2. **계약 시 보안 요건**
   - NDA(비밀유지계약) 체결
   - 접근 권한 범위 제한
   - 산출물 보안 등급 지정
   - 작업 종료 후 데이터 반환/삭제

### 필요 증거 자료

| 증거 | 형태 |
|------|------|
| 보안 컨설팅 계약서 | 계약 문서 |
| 외부 감사 보고서 | 보고서 |
| NDA 체결 이력 | 계약 문서 |

### 심사 시 주의사항

- "권고" 항목이지만, CSAP 표준등급에서는 사실상 필수에 가까움
- 외부 전문가 미활용 시 자체 역량 증빙을 강화해야 함
