## 목적

CSAP 일반등급(간편등급) 인증을 위한 30개 핵심 통제항목 자가진단 체크리스트입니다. 비기술 PM이 3일 이내 전체 항목을 점검할 수 있도록 확인 방법과 증거 자료를 명시합니다.

---

## 사용 방법

1. 각 항목의 "확인 방법"을 따라 현재 상태를 확인합니다
2. 충족 시 확인란에 체크(v)를 표시합니다
3. 미충족 시 비고란에 미비 사유와 개선 계획을 기록합니다
4. 전체 완료 후 하단의 자가진단 결과 요약을 작성합니다
