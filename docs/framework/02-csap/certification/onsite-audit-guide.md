| 1일차 | 착수 회의 + 관리적 통제 심사 (D01~D07) | 8시간 |

## 3. 분야별 시연 시나리오

### 3.1 D08 접근 통제 시연

| 시나리오 | 시연 내용 | 증적 |
|---------|---------|------|
| **사용자 등록** | 관리자 포털에서 신규 사용자 생성 | Admin Portal 스크린샷 |
| **RBAC 설정** | 역할 할당 (ADMIN/MANAGER/USER) | 권한 설정 화면 |
| **접근 차단** | 권한 없는 API 호출 시 403 반환 | API 응답 로그 |
| **세션 관리** | 15분 미사용 시 자동 로그아웃 | 브라우저 시연 |
| **로그인 실패** | 5회 연속 실패 시 계정 잠금 | 보안 모니터링 로그 |
| **비밀번호** | 복잡도 정책 (8자+, 대소문자+숫자+특수) | 비밀번호 변경 화면 |
| **테넌트 격리** | 기관 A 데이터가 기관 B에서 미조회 | 두 테넌트 동시 시연 |

**시연 절차**:
```
1. 관리자 계정으로 Admin Portal 로그인
2. 사용자 관리 > 신규 사용자 생성 (이름, 이메일, 역할)
3. 해당 사용자로 로그인 > 권한에 맞는 메뉴만 표시 확인
4. 권한 외 API 호출 시도 > 403 Forbidden 확인
5. 15분 대기 > 세션 만료 확인
6. 잘못된 비밀번호 5회 입력 > 계정 잠금 확인
```

### 3.2 D09 암호화 시연

| 시나리오 | 시연 내용 | 증적 |
|---------|---------|------|
| **TLS 확인** | 브라우저 인증서 확인 (TLS 1.3) | 인증서 스크린샷 |
| **DB 암호화** | PostgreSQL sslmode=require 설정 | 설정 파일 |
| **비밀번호 해시** | DB에서 bcrypt 해시 확인 | 쿼리 결과 (해시만) |
| **환경 변수** | .env 파일 미커밋 확인 | .gitignore 설정 |

**시연 절차**:
```
1. 포털 접속 > 브라우저 주소창 자물쇠 클릭 > TLS 1.3 확인
2. DB 접속 > users 테이블 > password 컬럼 bcrypt 해시 확인
3. .gitignore 확인 > .env 제외 확인
4. PostgreSQL 연결 설정 > sslmode=require 확인
```

### 3.3 D06 감사 로그 시연

| 시나리오 | 시연 내용 | 증적 |
|---------|---------|------|
| **로그 기록** | 사용자 작업 수행 > 감사 로그 즉시 확인 | audit.jsonl |
| **로그 검색** | 날짜/사용자/액션 기준 검색 | 대시보드 필터 |
| **무결성** | SHA-256 체인 무결성 확인 | 검증 스크립트 |
| **보존 기간** | 1년 이상 로그 보존 확인 | 파일 타임스탬프 |

### 3.4 D12 시스템 개발 보안 시연

| 시나리오 | 시연 내용 | 증적 |

## 4. 결함 대응 절차

### 4.1 결함 분류

| 등급 | 정의 | 보완 기한 |
|------|------|---------|
| 중결함 | 보안 사고 직접 야기 가능 | 30일 이내 |
| 경결함 | 보안 수준 저하 요인 | 60일 이내 |
| 권고 | 개선 필요 (인증 차단 아님) | 90일 이내 |

### 4.2 결함 대응 프로세스

```
1. 심사원 결함 통보 → 서기 즉시 기록
2. 대응팀 결함 분석 → 원인 파악
3. 보완 계획 수립 → 일정/담당자 배정
4. 보완 조치 실행 → 코드/문서/설정 수정
5. 보완 결과 증적 수집 → 스크린샷/코드/로그
6. KISA 보완 결과 제출 → 증적 패키지
7. 이행 점검 대응 → 재확인
```
