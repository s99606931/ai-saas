### 3. 서비스 개요

#### 3.1 서비스 설명

공공기관에 특화된 SaaS 프레임워크로, CSAP 표준등급 79항목 및 N2SF 6개 보안영역을 기본 내장하여 공공기관의 클라우드 전환을 지원합니다.

#### 3.2 주요 기능

| 기능 | 설명 |
|------|------|
| 멀티테넌시 | 기관별 데이터 격리 (RLS 기반) |
| RBAC | 5단계 역할 기반 접근 통제 |
| 감사 로그 | append-only SHA-256 체인 로그 |
| AI 게이트웨이 | N2SF 등급 기반 데이터 보호 |
| 보안 모니터링 | 실시간 이상 탐지 + IP 차단 |
| 준수 대시보드 | CSAP/N2SF/ISMS-P 준수 현황 |

#### 3.3 기술 아키텍처

| 구성 요소 | 기술 |
|----------|------|
| 프론트엔드 | Next.js 15 (React 19) |
| 백엔드 | Hono (TypeScript) |
| 데이터베이스 | PostgreSQL 16 |
| 캐시 | Redis 7 |
| 파일 스토리지 | MinIO |
| 컨테이너 | Docker + k3s |
| CI/CD | Gitea Actions |
| AI 연동 | LM Studio (로컬) / OpenAI 호환 API |
