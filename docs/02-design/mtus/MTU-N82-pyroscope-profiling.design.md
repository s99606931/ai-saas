# MTU-N82: Pyroscope 연속 프로파일링 — Design

> **MTU ID**: MTU-N82
> **Plan 참조**: docs/01-plan/mtus/MTU-N82-pyroscope-profiling.plan.md
> **작성일**: 2026-04-10

---

## Design Anchor

| 항목 | 결정 |
|------|------|
| 배포 모드 | Monolithic (단일 노드 k3s 환경 최적화) |
| 프로파일러 | Grafana Alloy eBPF (커널 4.9+) |
| 스토리지 | 로컬 PV (7일 보존) |
| 연동 | Grafana 기존 인스턴스에 데이터소스 추가 |

## 아키텍처

```
┌─ Node (k3s) ──────────────────────────────┐
│                                           │
│  ┌─ DaemonSet: Grafana Alloy ────────┐    │
│  │  eBPF Profiler                    │    │
│  │  CPU / Memory / Goroutine 수집    │    │
│  └──────────────┬────────────────────┘    │
│                 │                         │
│  ┌──────────────▼────────────────────┐    │
│  │  Pyroscope Server (Monolithic)    │    │
│  │  - 수집 + 저장 + 쿼리             │    │
│  │  - 7일 데이터 보존                │    │
│  │  - PV: 10Gi                       │    │
│  └──────────────┬────────────────────┘    │
│                 │                         │
│  ┌──────────────▼────────────────────┐    │
│  │  Grafana                          │    │
│  │  - Pyroscope 데이터소스            │    │
│  │  - Flame Graph 시각화             │    │
│  │  - 메트릭/트레이스 연관 분석       │    │
│  └───────────────────────────────────┘    │
└───────────────────────────────────────────┘
```

## 프로파일 유형

| 유형 | 설명 | 용도 |
|------|------|------|
| cpu | CPU 사용 프로파일 | 핫 함수 식별 |
| memory:alloc_objects | 메모리 할당 객체 수 | 메모리 누수 탐지 |
| memory:alloc_space | 메모리 할당 바이트 | 메모리 사용량 분석 |
| goroutine | Go 고루틴 (해당 시) | 동시성 문제 분석 |
| mutex | 뮤텍스 경합 | 락 병목 분석 |
