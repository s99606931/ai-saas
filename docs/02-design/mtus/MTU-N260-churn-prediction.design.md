## §1 사용 패턴 수집 (FR-N260.1)
수집 지표: 로그인 빈도, 일일 활성 사용자(DAU), API 호출 수, 기능별 사용률, 평균 세션 시간, 지원 티켓 수

## §2 이탈 위험 점수 (FR-N260.2)
가중 점수 = SUM(지표별 정규화 점수 * 가중치)
- 로그인 빈도 감소: 가중치 25%
- 기능 사용률 감소: 가중치 20%
- API 호출 감소: 가중치 15%
- 세션 시간 감소: 가중치 15%
- 불만/티켓 증가: 가중치 15%
- 결제 연체: 가중치 10%

## §3 이탈 징후 5패턴 (FR-N260.3)
1. 로그인 빈도 50% 이상 감소 (2주 비교)
2. 핵심 기능 미사용 기간 7일+
3. API 호출량 70% 이상 감소
4. 지원 불만 티켓 3건+/월
5. 결제 연체 1회+

## §4 자동 알림 (FR-N260.4)
위험 등급별 알림: critical(>80) → 즉시, high(60~80) → 24시간 내, medium(40~60) → 주간 보고

## §5 리텐션 액션 (FR-N260.5)
위험 패턴별 맞춤 전략: 온보딩 재안내, 기능 교육, 할인 쿠폰, CS 담당자 배정 등

## §6 대시보드 메트릭 (FR-N260.6)
전체/위험등급별 테넌트 분포, 이탈률 추이, 리텐션 성공률
