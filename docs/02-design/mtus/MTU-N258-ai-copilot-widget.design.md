---

## §1 위젯 레지스트리 (FR-N258.1)

위젯 메타데이터 관리 (등록, 해제, 활성화 상태, 권한)

## §2 컨텍스트 수집기 (FR-N258.2)

페이지 컨텍스트 = 현재 URL, 활성 모듈, 선택 데이터, 사용자 역할, 테넌트 정보

## §3 AI 쿼리 실행 (FR-N258.3)

컨텍스트 + 사용자 질문 → 시스템 프롬프트 조합 → LLM 쿼리 → 구조화 응답

## §4 데이터 요약 위젯 (FR-N258.4)

선택된 데이터를 AI로 요약 (테이블, 차트, 리스트 형식 데이터)

## §5 규정 검색 위젯 (FR-N258.5)

CSAP/N2SF/ISMS-P 규정 RAG 검색 + 조항 인용

## §6 보고서 초안 위젯 (FR-N258.6)

현재 대시보드 메트릭 기반 관리자 보고서 자동 작성

## §7 위젯 권한 (FR-N258.7)

RBAC 기반 위젯 접근 제어
