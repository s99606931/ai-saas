## 2. 파일별 설계

### 공통 구조 (4개 파일 동일)

각 파일은 다음 구조를 따릅니다:

1. **문서 헤더**: 메타데이터, FR 매핑, 마스터 체크리스트 참조
2. **분야 개요**: 분야 성격, 심사 방법, 핵심 키워드
3. **항목별 구현 가이드**: CSAP ID별로
   - 구현 목표
   - 구현 방법 (단계별)
   - 필요 증거 자료
   - 샘플 템플릿/양식
   - 심사 시 주의사항
4. **증거 자료 체크리스트**: 분야 전체 증거 목록
5. **추적성**: 마스터 체크리스트 앵커 링크

### 2.1 D01-policy.md (정보보호 정책, 4항목)

- CSAP-D01-01~04 전수
- 핵심: 정보보호 정책서 수립 절차, 경영진 승인 템플릿, 연간 검토 일정, 법령 준수 매트릭스

### 2.2 D02-org-security.md (조직 보안, 3항목)

- CSAP-D02-01~03 전수
- 핵심: 보안 조직도, CISO/보안담당자/사용자 3계층 역할 정의, 외부 전문가 활용

### 2.3 D03-personnel.md (인적 보안, 4항목)

- CSAP-D03-01~04 전수
- 핵심: 보안 서약서 양식, 교육 계획서, 퇴직 보안 절차, 외부 인력 관리

### 2.4 D04-asset-mgmt.md (자산 관리, 5항목)

- CSAP-D04-01~05 전수
- 핵심: IT 자산 대장 양식, 분류 기준표, 미디어 관리, 폐기 절차
