# SVC-AI-ADV-R30: AI 이상 탐지 DESIGN

> 버전: 1.0.0 | 작성일: 2026-04-12 | 작성자: PM Lead (Opus)

## 아키텍처 선택: Option B -- Pragmatic Balance

통계적 이상치 탐지 + LLM 로그 분석 하이브리드. 통계 기반 1차 필터 → LLM 2차 분류.

---

## §1 통계적 이상치 탐지 (FR-ADV30.1)

3가지 알고리즘 병렬 실행:
- Z-Score: 평균 대비 표준편차 이탈 (임계값: 3.0)
- IQR: 사분위 범위 이탈 (Q1 - 1.5*IQR, Q3 + 1.5*IQR)
- 이동평균 편차: 최근 N개 윈도우 대비 현재 값 편차

투표 방식: 2/3 이상 이상치 판정 시 이상으로 확정

## §2 LLM 로그 분석 (FR-ADV30.2)

구조화되지 않은 로그 분석:
- 로그 배치(최대 50줄) → LLM 프롬프트 전송
- 분석 결과: 이상 여부, 이상 유형, 근거, 심각도
- N2SF 준수: 로그 내 PII/C등급 데이터 마스킹 후 전송

## §3 실시간 스트리밍 (FR-ADV30.3)

슬라이딩 윈도우 기반:
- 윈도우 크기: 60초 (설정 가능)
- 윈도우 슬라이드: 10초
- 윈도우 내 메트릭 집계 → 통계 탐지 실행
- 이벤트 버퍼: 최대 10,000개

## §4 이상 분류 (FR-ADV30.4)

심각도 분류 기준:
- critical: 보안 침해 징후, 데이터 유출 패턴
- high: 비정상 접근 패턴, 대량 에러
- medium: 성능 저하, 임계값 근접
- low: 경미한 편차, 단발성 이상

## §5 자동 알림 (FR-ADV30.5)

알림 채널:
- webhook URL
- 로그 시스템 (stdout/stderr)
- 감사 로그 (필수)

## §6 학습 기준선 (FR-ADV30.6)

정상 패턴 학습:
- 초기 학습 기간: 24시간 데이터
- 기준선 갱신 주기: 6시간
- 계절성 패턴 감지 (시간대별, 요일별)

## §7 감사 로그 (FR-ADV30.7)

모든 탐지 이벤트 기록:
- 탐지 시각, 이상 유형, 심각도, 소스, 판정 근거
