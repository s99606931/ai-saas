# Design: MTU-N178 SLO 위반 자동 에스컬레이션

> 버전: 1.0 | 작성일: 2026-04-10

## 아키텍처

```
Prometheus SLO Alerts ──→ AlertManager ──→ Escalation Controller
                                                │
                         ┌──────────────────────┤
                         ▼                      ▼
                    L1 On-Call              L2 Team Lead
                    (즉시 알림)            (30분 미응답)
                                                │
                                           L3 Engineering Manager
                                           (1시간 미응답)
                                                │
                                           경영진 통보
                                           (2시간 미응답)
```

## 에스컬레이션 정책

| 에러 버짓 소진율 | 단계 | 행동 |
|-----------------|------|------|
| 50% 이하 | 정상 | 모니터링만 |
| 50~75% | 경고 | L1 알림 + 런북 자동 실행 |
| 75~90% | 위험 | L1+L2 알림 + 변경 동결 검토 |
| 90~100% | 긴급 | L1+L2+L3 알림 + 변경 동결 |
| 100% 초과 | SLO 위반 | 경영진 통보 + 포스트모템 강제 |
