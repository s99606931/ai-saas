## 1. 보고서 구조

```
┌────────────────────────────────────────────────┐
│            비용 최적화 보고서                     │
├────────────────────────────────────────────────┤
│ 1. Executive Summary                           │
│    - 총 비용 추정, 전월 대비 변화, 효율성 등급    │
├────────────────────────────────────────────────┤
│ 2. 테넌트별 비용 분석                            │
│    - 네임스페이스별 CPU/메모리/스토리지 비용       │
│    - 비용 구성비 (파이 차트 데이터)               │
├────────────────────────────────────────────────┤
│ 3. 리소스 효율성 분석                            │
│    - 과잉 프로비저닝 서비스 목록                   │
│    - CPU/메모리 요청 대비 사용률                   │
│    - 유휴 리소스 비용 추정                        │
├────────────────────────────────────────────────┤
│ 4. 최적화 권고사항                               │
│    - VPA 적용 권고                               │
│    - 과잉 리소스 축소 권고                        │
│    - 기술 부채 해소 권고                          │
│    - 예상 절감액 산출                             │
├────────────────────────────────────────────────┤
│ 5. 기술 부채 비용 영향                           │
│    - Dead code 유지 비용                         │
│    - 미최적화 쿼리 비용                           │
│    - 운영 효율 개선 효과                          │
└────────────────────────────────────────────────┘
```

## 2. 비용 모델

```
CPU 비용:      0.05 USD/vCPU/h (FinOps 기존 모델)
메모리 비용:    0.01 USD/GiB/h
스토리지 비용:  0.10 USD/GiB/월
네트워크 비용:  0.01 USD/GB (egress)
```

## 3. 효율성 등급

| 등급 | 조건 | 설명 |
|------|------|------|
| A | 효율 > 80% | 리소스 최적화 우수 |
| B | 효율 60~80% | 일부 최적화 여지 |
| C | 효율 40~60% | 최적화 필요 |
| D | 효율 < 40% | 과잉 프로비저닝 심각 |
