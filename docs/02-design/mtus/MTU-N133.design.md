## 1. 통합 품질 게이트 구조

### 1.1 4영역 품질 평가 모델

```
┌─────────────────────────────────────────────────────┐
│              CI/CD 통합 품질 게이트                    │
├─────────────┬──────────┬──────────┬─────────────────┤
│ 보안 (30%)  │테스트(25%)│코드(25%) │ 규정 준수(20%)   │
├─────────────┼──────────┼──────────┼─────────────────┤
│ 시크릿 검출  │ 단위     │ Lint     │ Q-Gate G1~G7   │
│ SQL 인젝션   │ E2E     │ 타입체크  │ CSAP 항목      │
│ XSS         │ 커버리지  │ 복잡도   │ N2SF 준수      │
│ 하드코딩 키  │ 통합     │ Dead code│ 감사 로그      │
│ RBAC 누락   │          │          │                │
└─────────────┴──────────┴──────────┴─────────────────┘
         ↓               ↓              ↓
    보안 점수        테스트 점수     코드 점수       규정 점수
         ↓               ↓              ↓              ↓
         └───────────────┴──────────────┴──────────────┘
                         ↓
                   가중 합산 (100점 만점)
                         ↓
              ┌──────────┴──────────┐
              │ 합격 기준            │
              │ - 전체 >= 80점       │
              │ - 보안 >= 70점       │
              │ - 각 영역 >= 50점    │
              └─────────────────────┘
```

### 1.2 점수 산출 공식

```
전체 점수 = (보안 * 0.30) + (테스트 * 0.25) + (코드 * 0.25) + (규정 * 0.20)
```

### 1.3 영역별 세부 채점

**보안 (100점 만점)**:
- 시크릿 미검출: 25점 (하나라도 검출 시 0점)
- SQL 인젝션 패턴 미검출: 20점
- 하드코딩 API 키 미검출: 20점
- RBAC 검사 존재: 20점
- XSS 새니타이징: 15점

**테스트 (100점 만점)**:
- 단위 테스트 통과: 40점
- 커버리지 >= 80%: 30점 (비례 배분)
- E2E 테스트 존재: 30점

**코드 품질 (100점 만점)**:
- Lint 통과: 30점
- 타입체크 통과: 30점
- Dead code 미검출: 20점
- 파일 크기 800줄 이하: 20점

**규정 준수 (100점 만점)**:
- Plan 문서 존재: 20점
- Design 문서 존재: 20점
- Q-Gate 통과: 30점
- 감사 로그 존재: 15점
- CSAP 매핑: 15점
