## 1. 성숙도 모델

### 1.1 성숙도 단계

| 단계 | 명칭 | 설명 |
|------|------|------|
| 1 | 초기 (Initial) | 수동 프로세스, 도구 미비 |
| 2 | 반복 (Repeatable) | 기본 도구 존재, 수동 실행 |
| 3 | 정의 (Defined) | 자동화 도구 + 프로세스 정의 |
| 4 | 관리 (Managed) | 메트릭 기반 관리 + 지속 개선 |
| 5 | 최적화 (Optimized) | AI/ML 기반 예측 + 자동 복구 |

### 1.2 평가 영역

| 영역 | 평가 기준 도구 |
|------|-------------|
| 모니터링 | Prometheus, Grafana, Recording Rules, 대시보드 |
| 인시던트 | 런북, 포스트모템, 타임라인, 온콜, 알림 |
| 변경 관리 | 변경 영향 분석, CI/CD, GitOps, 배포 검증 |
| 보안 | 보안 스캔, 의존성 감사, RBAC, 암호화 |
| FinOps | 비용 분석, VPA, 용량 계획, 예측 |
| DR | 백업/복원, DR 시나리오, 헬스체크 |
| 자동화 | 스크립트 수, CI/CD, 자동 테스트 |
