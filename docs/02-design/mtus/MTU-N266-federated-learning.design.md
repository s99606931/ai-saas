## §1 연합 학습 코디네이터 (FR-N266.1)

- `FederatedCoordinator` 클래스: 학습 세션 관리
- 참여자 등록/해제, 라운드 시작/종료
- 세션 상태: `initializing` → `recruiting` → `training` → `aggregating` → `completed`
- 최소 참여자 수 충족 시 라운드 시작

## §2 클라이언트 에이전트 (FR-N266.2)

- `FederatedClient` 클래스: 로컬 학습 실행
- 로컬 데이터셋 기반 학습 → 가중치(gradient) 추출
- 원본 데이터는 클라이언트에만 존재 (전송 금지)

## §3 모델 집계 알고리즘 (FR-N266.3)

- FedAvg: 가중 평균 집계 (참여자 데이터 크기 비례)
- FedProx: 근위 항 추가 (비균일 데이터 대응)
- 선택적 집계 전략 (strategy pattern)

## §4 차분 프라이버시 (FR-N266.4)

- 가우시안 노이즈 주입 (epsilon-delta DP)
- 클리핑 규범 제한 (gradient clipping)
- 프라이버시 예산 추적 (누적 epsilon)

## §5 비잔틴 내결함성 (FR-N266.5)

- 이상 가중치 탐지 (코사인 유사도 기반)
- 중앙값 기반 강건 집계 (Trimmed Mean)
- 악의적 참여자 격리 및 보고

## §6 모니터링 및 감사 (FR-N266.6)

- 라운드별 메트릭: 정확도, 손실, 참여율
- 감사 로그: 모든 가중치 교환 이벤트 기록
- 프라이버시 예산 잔여량 경고

## §7 모델 버전 관리 (FR-N266.7)

- 라운드별 글로벌 모델 스냅샷
- 성능 비교 (라운드 간, 중앙 학습 대비)

## Session Guide

1. 코디네이터 + 클라이언트 핵심 구조 구현
2. FedAvg/FedProx 집계 알고리즘
3. 차분 프라이버시 + 비잔틴 내결함성
4. 모니터링 + 감사 로깅
5. 테스트
