# MTU-N261: 데이터 거버넌스 자동화 — 설계 문서

> **버전**: 1.0 | **작성일**: 2026-04-12 | **Plan 참조**: MTU-N261

---

## Design Anchor

| 항목 | 결정 |
|------|------|
| 아키텍처 | DAG 계보 그래프 + 규칙 엔진 + 카탈로그 레지스트리 |
| 패턴 | Graph (계보), Strategy (품질 규칙), Registry (카탈로그) |

## §1 데이터 계보 DAG
노드(데이터셋) + 엣지(변환) 방향 그래프. 영향도 분석(impact analysis) 지원.

## §2 품질 규칙 엔진
4차원 품질 검사: 완전성(null rate), 정확성(범위/형식), 일관성(참조 무결성), 적시성(신선도)

## §3 데이터 카탈로그
메타데이터 관리: 스키마, 소유자, 태그, 설명, N2SF 등급, 사용 빈도

## §4 민감 데이터 분류
패턴 기반 자동 감지: 주민등록번호, 전화번호, 이메일 등 → N2SF 등급 태깅

## §5 품질 점수
데이터셋별 0~100 점수, 차원별 가중 평균

## §6 거버넌스 정책
데이터 접근/보존/삭제 정책 CRUD + 자동 적용
