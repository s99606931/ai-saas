# SVC-AI-ADV-R35: 연합 학습 오케스트레이터 DESIGN

> 버전: 1.0.0 | 작성일: 2026-04-12 | 작성자: PM Lead (Opus)

## 아키텍처 선택: Option B -- Pragmatic Balance

FedAvg 기반 파라미터 서버 패턴. 차등 프라이버시 기본 적용.

---

## §1 라운드 관리 (FR-ADV35.1)

연합 학습 라운드 순서:
1. 서버: 글로벌 모델 파라미터 배포
2. 참여자 선택 (최소 K명)
3. 각 참여자: 로컬 데이터로 학습
4. 그래디언트/파라미터 서버 전송
5. 서버: 집계 + 글로벌 모델 갱신
6. 수렴 검사 → 다음 라운드 또는 종료

## §2 로컬 학습 (FR-ADV35.2)

테넌트별 로컬 학습:
- 로컬 에폭: 기본 5회
- 배치 크기: 32
- 학습률: 0.01
- 데이터는 테넌트 로컬에만 존재 (외부 전송 금지)

## §3 그래디언트 집계 (FR-ADV35.3)

FedAvg 알고리즘:
- 글로벌 파라미터 = 가중 평균(각 참여자 파라미터)
- 가중치 = 참여자 데이터 샘플 수 비율

## §4 차등 프라이버시 (FR-ADV35.4)

DP 메커니즘:
- 그래디언트 클리핑: L2 norm 제한
- 가우시안 노이즈 주입
- 프라이버시 예산(epsilon) 관리
- 모멘트 어카운턴트 기반 프라이버시 손실 추적

## §5 모델 배포 (FR-ADV35.5)

글로벌 모델 배포:
- 각 테넌트에 갱신된 파라미터 전송
- 버전 관리 (라운드 번호 기반)

## §6 참여자 선택 (FR-ADV35.6)

선택 전략:
- 랜덤 선택 (기본)
- 데이터 크기 비례 선택
- 기여도 기반 선택
