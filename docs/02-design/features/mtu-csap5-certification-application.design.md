## Design Anchor

| 항목 | 결정 |
|------|------|
| 인증 등급 | CSAP 표준등급 (SaaS) |
| 인증 기관 | 한국인터넷진흥원 (KISA) |
| 통제 항목 | 13분야 79항목 |
| 유효기간 | 5년 (사후 관리 연 1회) |
| 심사 절차 | 준비 → 신청 → 서류심사 → 현장심사 → 결함보완 → 인증 |

## 2. 신청 준비 체크리스트 설계

### 2.1 사전 준비 항목

| 구분 | 항목 | 설명 |
|------|------|------|
| 조직 | CISO 임명 | 정보보호최고책임자 임명장 |
| 조직 | 보안 담당 조직 | 정보보호 전담 조직 구성 |
| 문서 | 정보보호 정책서 | 경영진 승인 완료 |
| 문서 | 위험 분석 보고서 | 자산 식별 + 위협 분석 |
| 기술 | 79항목 자가진단 | checklist-master.md 체크 완료 |
| 기술 | 취약점 점검 결과 | 0 Critical, 0 High |
| 증적 | 13분야 증적 패키지 | evidence-mapping.md 매핑 완료 |
| 계약 | KISA 보안인증 계약 | 심사 비용 납부 |

### 2.2 현장 심사 대응 시나리오

| 영역 | 심사 시나리오 | 대응 방법 |
|------|-------------|---------|
| D-08 접근 통제 | "관리자 계정으로 로그인하여 권한 설정 시연" | Admin Portal RBAC 데모 |
| D-09 암호화 | "DB 암호화 설정 확인" | AES-256 설정 + TLS 1.3 인증서 |
| D-06 감사 로그 | "최근 7일 감사 로그 조회" | audit.jsonl 조회 + 대시보드 |
| D-12 개발 보안 | "입력값 검증 코드 확인" | Zod 스키마 + SQL 매개변수화 |
| D-10 네트워크 | "방화벽 정책 확인" | k3s NetworkPolicy 설정 |
| D-11 가상화 | "컨테이너 격리 설정 확인" | Docker securityContext |
