# CI 파이프라인 학습 순서

> **목표**: PR 생성부터 머지까지 자동으로 실행되는 모든 검증 과정을 이해한다

---

## 파이프라인이란?

파이프라인(Pipeline)은 코드를 배포하기 전에 자동으로 실행되는 일련의 검사 단계입니다.

```
공장 생산 라인 비유:
  원자재 투입 → 가공 → 검사 → 포장 → 출하
  코드 푸시 → 빌드 → 테스트 → 보안검사 → 배포
```

파이프라인이 없으면 "작동하는 것 같다"로 배포하게 됩니다. 파이프라인이 있으면 "모든 검사를 통과했다"고 확신하고 배포할 수 있습니다.

## 파이프라인 트리거 조건

| 이벤트 | 실행되는 파이프라인 |
|--------|----------------|
| `feat/*`, `fix/*` 브랜치 push | CI (lint + test) |
| PR 생성 (→ main, stg) | CI + Q-Gate + DevSecOps |
| main 브랜치 머지 | CD (배포) |
| `hotfix/*` 브랜치 push | Hotfix 파이프라인 |
| `v*` 태그 push | Release 파이프라인 |
