# CSAP 학습 순서

> **목표**: CSAP가 무엇인지 이해하고 개발 중 준수해야 할 항목을 실천할 수 있다

---

## CSAP를 모르면?

```
시나리오: 개발자 A가 편의를 위해 API에 인증 검사를 뺌
→ 코드 리뷰에서 발견되지 않음
→ CSAP 감사에서 D-08(접근 통제) 위반 발견
→ 인증 취득 실패 또는 취소
→ 공공기관 계약 불가 → 비즈니스 치명타
```

CSAP는 추상적인 규정이 아닙니다. 개발자가 매일 작성하는 코드에 직접 영향을 줍니다.

---

2. **`02-dev-checklist.md`** — 실천 체크리스트: 코딩 중 확인사항, PR 전 점검, 자동화 도구
