---

## 보안 코딩이란?

보안 코딩(Secure Coding)은 단순히 "버그가 없는" 코드가 아니라, 악의적인 공격자에게도 안전한 코드입니다.

```
일반 코딩: "정상적인 사용에서 작동한다"
보안 코딩: "악의적인 입력에도 시스템이 안전하다"
```

---
