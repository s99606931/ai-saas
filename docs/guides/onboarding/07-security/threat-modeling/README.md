## 이 섹션의 목적

코드 수준의 보안 패턴을 배웠다면, 이 섹션에서는 한 단계 위로 올라가 **시스템 전체 관점에서 어떤 공격이 가능한지** 이해합니다. 위협 모델링을 알면 "왜 이 보안 코드가 필요한가"라는 질문에 명확히 답할 수 있습니다.
