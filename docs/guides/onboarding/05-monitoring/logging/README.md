# 로깅 학습 순서

> **목표**: Loki에서 로그를 조회하고 문제 원인을 파악할 수 있다

---

## 로그 vs 메트릭

| 비교 | 메트릭 | 로그 |
|------|--------|------|
| 형태 | 숫자 | 텍스트 |
| 질문 | "얼마나 자주 발생했나?" | "정확히 무슨 일이 있었나?" |
| 용도 | 트렌드 파악, 알림 | 장애 원인 분석, 감사 추적 |
| 예시 | 에러율 5% | `ERROR: DB connection timeout at 09:15:32` |

두 가지를 함께 사용하면 가장 강력합니다. 메트릭으로 이상 감지 → 로그로 원인 파악.
