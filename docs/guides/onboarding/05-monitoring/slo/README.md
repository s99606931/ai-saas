## 이 섹션을 배우면

"서비스가 얼마나 잘 작동하고 있는가"를 **수치로 정의하고 측정**할 수 있습니다. SLO가 위반될 위험이 있을 때 자동 에스컬레이션이 어떻게 동작하는지 이해합니다. 에러 버짓이 소진될 때 배포를 동결하는 정책도 설명합니다.
