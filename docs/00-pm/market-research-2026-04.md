## 2. 기술스택 2026 핵심 트렌드

### 2.1 경량 K8s
| 도구 | 2026 포지션 | 공공기관 적합도 |
|------|-----------|--------------|
| k3s | 리소스 제약 환경 최적화, Linux 중심 | ★★★★★ (기존 선택 검증) |
| Flux | 폐쇄망/AIR-GAPPED 최적, 자율팀 구조 | ★★★★★ (추가 권장) |
| ArgoCD | 웹 UI 강력, 중앙집중식 | ★★★ (대안) |

**신규 추가**: k3s + **Flux GitOps** 조합 → 폐쇄망 CI/CD 완성

### 2.2 Gitea 2026
- 20+ 패키지 형식 지원 (Helm, npm, PyPI, Maven 포함)
- GitHub Actions 호환 YAML
- **Harbor 추가 권장**: 컨테이너 이미지 취약점 스캔 + Sigstore 서명

### 2.3 신규 필수 기술 (기존 Plan에 없음)
| 기술 | 용도 | 우선순위 |
|------|------|---------|
| **Kyverno** | K8s 정책 자동 적용 (Kubernetes 네이티브) | P0 |
| **OPA/Gatekeeper** | 복잡한 컴플라이언스 정책 (Rego DSL) | P1 |
| **SBOM** | 소프트웨어 구성요소 목록 (EU CRA 대비) | P1 |
| **Sigstore (Cosign)** | 컨테이너 이미지 서명/검증 | P1 |
| **OpenTelemetry** | 표준화된 관찰성 (공공기관 COTS 통합) | P1 |
| **Docusaurus** | 문서 포털 (MkDocs Material 유지보수 모드 전환) | P2 |

### 2.4 MkDocs Material 주의사항
- 2025년 11월 유지보수 모드 전환 (신기능 없음)
- Insiders 리포지토리 2026년 5월 1일 삭제 예정
- **권장 대안**: Docusaurus v3 (Meta, React 기반, LLM 친화적)

## 3. 경쟁 솔루션 분석
