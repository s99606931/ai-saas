# PRD: SVC-FILE-R1 -- 파일 관리 서비스 고도화

> 작성일: 2026-04-10 | 버전: 1.0

## WHY
파일 관리 서비스는 현재 기본 CRUD만 지원하며, Rate Limiting 미적용(CSAP D-10 위반),
다운로드 감사 로그 누락(CSAP D-06 위반), 검색/필터 부재, 테넌트별 저장 용량 관리 부재 등
운영 고도화 및 보안 강화가 필요합니다.

## WHO
- 공공기관 SaaS 프레임워크 운영자: 파일 저장소 관리, 테넌트별 용량 모니터링
- 일반 사용자: 파일 검색, 업로드, 다운로드
- 감리 담당자: CSAP D-06 감사 추적 완전성 확인

## RISK
- Rate Limiting 미적용 → 무차별 대입 공격 및 DoS 취약
- 다운로드 감사 로그 누락 → 감리 시 파일 접근 추적 불가
- 테넌트별 용량 제한 없음 → 단일 테넌트의 저장소 독점

## SUCCESS
- FR-FILE.1: Rate Limiting 적용 (읽기 100/60s, 업로드 10/60s, 삭제 5/300s)
- FR-FILE.2: 파일 검색/필터 (이름, MIME 타입, 날짜 범위, 크기 범위)
- FR-FILE.3: 다운로드 감사 로그 (CSAP D-06 완전성)
- FR-FILE.4: 테넌트별 저장 용량 조회
- FR-FILE.5: 파일 통계 (테넌트별 파일 수, 총 용량, MIME 분포)

## SCOPE
- 기존 5개 라우트 유지 + 2개 신규 라우트 추가 (stats, storage-usage)
- Rate Limiting 미들웨어 신규 생성
- 검색/필터 쿼리 파라미터 확장
- 다운로드 핸들러 감사 로그 추가
