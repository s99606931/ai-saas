# PRD: MTU-N33 부하 테스트

| 항목 | 내용 |
|------|------|
| MTU ID | MTU-N33 |
| 작성일 | 2026-04-08 |
| 복잡도 | MED |
| 상태 | 착수 |

## WHY (배경)

API Gateway 및 백엔드 서비스의 성능 기준(TPS, 응답시간, 에러율)을 실측하여 CSAP 비기능 요건(NFR) 준수를 검증. WSL2 환경에서의 실제 처리 능력을 파악하여 프로덕션 용량 계획 기초 자료 확보.

## WHO (이해관계자)

- 성능 엔지니어: 부하 테스트 설계 및 실행
- 운영자: 용량 계획 수립
- 보안 감사관: NFR 준수 증적

## RISK (위험)

- WSL2 리소스 한계로 인한 과도한 부하 시 클러스터 불안정
- 부하 테스트 중 기존 서비스 영향
- 테스트 결과의 프로덕션 환경 대비 차이

## SUCCESS (성공 기준)

- FR-N33.1: k6 또는 autocannon 부하 테스트 도구 설치
- FR-N33.2: API Gateway 부하 테스트 스크립트 작성
- FR-N33.3: 부하 테스트 실행 (10 VUs, 30초)
- FR-N33.4: 결과 분석 (TPS, P95/P99 응답시간, 에러율)
- FR-N33.5: 부하 테스트 보고서 및 가이드 문서

## SCOPE (범위)

- 포함: API Gateway /health 및 서비스 라우팅 부하 테스트
- 제외: 스트레스 테스트, 스파이크 테스트, 브라우저 부하 테스트
