# PRD: MTU-N29 E2E 시나리오 테스트

|------|------|
| MTU ID | MTU-N29 |
| 버전 | 1.0.0 |
| 작성일 | 2026-04-08 |
| 작성자 | PM Lead (Opus 4.6) |
| 복잡도 | MED |

---

## WHY

61개 MTU가 완료되었으나 전 구간 통합 E2E 시나리오 테스트가 부족합니다.
실제 사용자 시나리오(가입 -> 로그인 -> API 호출 -> 데이터 조회 -> 감사 로그 확인)를
k3s 클러스터에서 실행하여 서비스 간 연동을 검증합니다.

## WHO

- QA 담당자
- CSAP 심사 대응팀 (시스템 통합 테스트 증적)

## SUCCESS

1. 사용자 인증 시나리오 (회원가입 -> 로그인 -> JWT 발급 -> 토큰 갱신)
2. 테넌트 격리 시나리오 (테넌트 생성 -> 데이터 격리 확인)
3. API 게이트웨이 시나리오 (라우팅 -> Rate Limit -> 인증 미들웨어)
4. 감사 로그 시나리오 (민감 작업 -> audit 기록 확인)
5. 테스트 스크립트 작성 + 실행 결과 문서화

## SCOPE

### 포함
- k3s 클러스터 내 서비스 간 E2E 테스트 스크립트
- 시나리오별 테스트 케이스
- 실행 결과 리포트

### 제외
- UI 브라우저 테스트 (Playwright/Cypress)
- 성능 부하 테스트
